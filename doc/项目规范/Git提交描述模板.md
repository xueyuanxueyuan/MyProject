# Git 提交描述模板

## 1. 适用范围
- 适用于当前 `Gjj` 工作区内所有代码、文档、脚本与规范类提交。
- 默认用于 AI 参与的提交留痕与审计。

## 2. 标题格式
- 默认标题格式如下：

```text
feat: 你的提交标题（AI生成提交）
```

- 如果不是功能类提交，可将 `feat` 替换为实际类型，例如 `fix`、`docs`、`refactor`，但 `（AI生成提交）` 后缀必须保留。

## 3. 描述格式
- 提交描述必须严格按以下顺序编写：

```text
AI辅助：true
AI工具：Trae

1. 改了什么
2. 为了解决什么问题
```

## 4. 完整模板
```text
feat: 你的提交标题（AI生成提交）

AI辅助：true
AI工具：Trae

1. 改了什么
2. 为了解决什么问题
```

## 5. 示例
```text
fix: 修正结算核算分页查询条件丢失问题（AI生成提交）

AI辅助：true
AI工具：Trae

1. 修正查询条件在翻页后未正确回填的问题
2. 为了解决用户分页后结果集与筛选条件不一致的缺陷
```

## 6. 注意事项
- 提交标题与描述必须具体，禁止使用“修复问题”“优化代码”“调整一下”等空泛表述。
- 提交前仍需遵守“先同步远端主线、解决冲突、再本地提交”的既有流程要求。
- 默认仅提交本次修改涉及的源码文件；非源码文件是否提交，以当前项目规范和用户指令为准。
