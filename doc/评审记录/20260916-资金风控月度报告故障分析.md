## 原因与方案
- 查询 SQL 已返回 10 条记录，随后 AuthTools 查询历史创建人姓名失败。DocumentServiceImpl.java:1351 只处理空返回值，没有局部异常兜底。需核对接口真实响应和 AuthTools 是否向外抛出异常，不能仅凭内部 ERROR 断言整个查询失败。检查用户、租户/中心范围、认证服务与缓存；展示姓名允许在异常时保留原用户名，不改历史归属、不绕过鉴权。
- 动态数据源 ID=1 建池发生 Connect timed out。排查实际 Hikari 日志所示连接目标，从业务 Pod 检查 TCP、路由、防火墙、网络策略和目标监听。不能由此认定密码或 SQL 错误，也不能直接替换为日志中的另一个地址。
- MinIO 模板下载发生 UnknownHostException，调用点 DocumentServiceImpl.java:570。核对实际 endpoint、Service 名称和命名空间；配置正确时再排查 Pod DNS、CoreDNS、网络策略。恢复后验证模板读取、报告写入和下载。
- 最终 rollback-only 是连带事务异常，首次标记位置未确认。generateReport 在事务内捕获异常返回 R.fail，SQL 数据项失败又返回 null 继续执行。应让必需指标失败立即终止、统一异常传播，并考虑外部取数和文件操作移出数据库长事务，短事务负责落库，配套孤立文件清理。
