## 复评结论

**认可业务方向，不通过完整实施契约冻结，不批准正式链路编码及投产。** `v2` 是新接口版本，并不替代旧 API；前端可选私有/AI/双模式，双方结果留存、可明确配对比较，正式生效仍只有一套。设计已写明单次冻结输入、非正式比较隔离、运行与文件摘要、缺事实快照不得核验等要求；这些是设计意图，不能当成现有实现或验收证据。以下同时列出新增契约缺口、前轮 P0 的继承风险，以及已设计但待实现的门禁，避免重复判定。

## 继承阻断与已设计待实证项

- **P0 正式写者旁路（前轮 A1）**：补充稿第34、63、74行已要求同锁和迁移，不能再称“方案完全未写”；但 `PredictionResultServiceImpl.savePredictionResults`、`applyOptimization` 及 `YcjgJob` 两处调用尚可绕过新正式决策。Java/DBA/任务负责人列全写者、投影 SQL、唯一域/修订规则、双签版本与回滚栅栏；目标达梦双连接竞态、旧按钮/任务旁路和回滚撞保存负例通过后才可审议 D。
- **P0 模型回测污染（前轮 M1）**：旧 ARIMA 有全序列拟合、GRU 缩放器在分割前拟合、SVR 完整序列切窗等风险；补充稿第18、26、73、77行已承接统一回测，不代表旧历史指标合格。模型/风控按 R7 遮蔽未来值，并以预注册阈值核定可比资格。
- **P0 Python 未知提交与出域撤权（前轮 A2/S1）**：补充稿第51、59行已有对账/发送前校验方向；Python 自建任务 ID 与清理机制、实际网关竞态仍须实测。任务/安全负责人冻结组级与分支级幂等、未知态权威查询、清理豁免；已受理后超时/任务清理不盲重发；撤权竞态不发送。
- **P1 不可变制品与数据边界**：补充稿第28行明确制品不可覆盖，但现有 Python 相同机构/指标/类型可能同名重训；旧预测取数和 GRU 回退也不自动服从单快照。模型/Python/Java 提供不可变对象键、真实制品摘要及回退标记；同范围连续重训后旧权重可加载复算，旧路径被替换则失败闭环。
- **P0 比较/正式隔离（本稿已有要求）**：第11、32、34、63、65行已写明 `COMPARISON_ONLY` 不参与正式预警/报告及报告分析只读；只在合成负例验证正式表零变化和权限/取数隔离后才能声称实现。这里是交付验收项，不重复计为新的设计缺口。
