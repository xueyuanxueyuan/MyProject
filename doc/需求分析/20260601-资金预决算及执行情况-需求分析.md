# 资金预决算及执行情况 - 需求分析文档

## 1. 业务背景与目标
嘉兴市住房公积金管理服务中心（全市）需要建立资金的预算、执行情况、决算及增值收益的闭环管理系统。
系统需覆盖 13 张核心报表的在线填报、自动计算、市县两级数据汇总以及报表导出功能。通过系统化，解决原有手工 Excel 填报易出错、公式勾稽核对繁琐、市县数据汇总效率低的问题。

## 2. 报表体系与结构分析
通过对 `资金预决算及执行情况.xlsx` 的深度解析，13 张表主要分为 **6 大业务场景**：

### 2.1 资金使用预算（总表、附表）
- **总表指标**：上年预算数、上年实绩数、本年预算数、为上年实绩％。
- **附表指标**：按机构（全市、市本级、嘉善县、平湖市、海盐县、海宁市、桐乡市）分解“本年预算数”。
- **核心行次（Line 1-15）**：
  - 归集提取：1.年初余额，2.当年归集数，3.当年提取数，4.年末余额(1+2-3+4当年统筹)。
  - 个人贷款：6.年初余额，7.当年发放，8.当年收回，9.当年“公转商”转出，10.年末余额(6+7-8-9)。
  - 国债投资：12.年初余额，13.当年增加，14.当年回收，15.年末余额。

### 2.2 业务收支预算（总表、附表）
- **核心行次（Line 1-12）**：
  - 一、业务收入 (行次1 = 行次2至6之和)
  - 二、业务支出 (行次7 = 行次8至11之和)
  - 三、增值收益 (行次12 = 行次1 - 行次7)
- 附表按照市县区维度横向铺开录入与汇总。

### 2.3 执行情况表（月度/季度）
包含《资金使用预算执行情况表》、《业务收支预算执行情况表》。
- **特征**：加入时间维度（年月），包含指标如“本年归集预算数”、“本年归集实绩数”、“归集完成预算数（%）”、“上年同期数”、“同比增长（%）”。
- **数据来源**：部分指标（如实绩数）由财务科目（如201科目、401科目等）直接取值或手工填报。

### 2.4 归集使用决算（总表、附表）
与预算表行次结构高度一致，主要比对指标为：上年同期数、本年预算数、本年实绩数、预算完成率、比上年同期增长。

### 2.5 业务收支决算（总表、附表）
与业务收支预算结构高度一致。比对指标同决算。

### 2.6 增值收益分配情况（总表、附表）
- **核心行次（Line 11-20）**：
  - 11.待分配增值收益
  - 贷款风险准备金（12.年初余额、13.当年分配、14.当年支出、15.年末余额）
  - 管理费用（16.当年分配）
  - 城市廉租住房补充资金（17.年初、18.分配、19.上缴、20.年末余额）

### 2.7 扩面工作完成情况表
- **指标**：本年实缴、上年实缴、本年净增(1-2)、净增长率(3/2)、目标任务、完成率(1/5)。

## 3. 表间关系与数据流转规则
1. **附表汇总总表**：附表中的“全市”列必须等于各县市区（市本级、嘉善、平湖、海盐、海宁、桐乡）之和。总表的“本年预算数”或“本年实绩数”直接取自对应附表的“全市”列。
2. **上年结转本年**：总表中的“上年预算数”需取自上一年度同一表单的“本年预算数”。“年初余额”应等于上一年度决算表对应的“年末余额”。
3. **表内公式自动计算**：
   - 合计项（如收入合计=各明细收入相加）。
   - 余额项（如期末余额=期初+增加-减少）。
   - 比率项（完成率=实绩/预算，增长率=本期/同期-1，占比=某项/总额）。
4. **填报与锁定机制**：
   - 预算表通常在每年 3 月份编制，审批后锁定。
   - 决算表在次年 1 月份编制。
   - 执行表每月/季度编制。

## 4. 权限与管控需求
- **县市填报**：各县（市）区网点（wdbh/hsjgbh）只能填报本机构的列数据。
- **市本级汇总与调整**：市中心可以查看所有县区数据，系统自动汇总“全市”数据，市中心可对汇总数据进行调整和终审。
- **只读字段控制**：公式计算单元格、自动提取单元格（如取自往年数据）在前端严格锁定为只读。
