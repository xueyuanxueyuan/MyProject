# 资金风控接入第三方大模型可行性分析

日期：2026-10-12。范围：`prod/IdeaProject/capinfo-gjj-busi-zjfk` 的预测和报告生成。仅做静态代码及官方资料核查；未调用真实数据、模型接口或生产环境。

## 结论

**技术上可接入，但不建议让通用语言模型直接取代资金预测和财务计算。**建议先试点“经核验指标驱动的报告文字草稿和风险解释”，保留现有数值计算、预测服务和 DOCX 模板为权威来源；LLM 数值预测仅作离线候选，滚动回测合格且业务审批后才考虑使用。

**公网 API 可调用不等于真实业务数据可以外传。**DeepSeek 开放平台协议第 4.1 条要求输入不涉及国家秘密、商业秘密等，第 3.5 条要求开发者依法处理用户数据。对账户、交易明细、客户信息、内部策略及可能构成商业秘密的汇总指标，在数据分类、法务/安全审查和合同确认前不发送公网 API。若数据不能外传，应另评估经批准的隔离部署、模型许可和专项合同；不可套用公网 API 条款。

## 方案对比

| 方案 | 价值及判断 |
| --- | --- |
| A 保持现状 | 现有预测和模板是回退/验收基线；没有新叙述能力。 |
| B 现有计算 + LLM 叙述（推荐首试） | 对经许可的指标摘要生成趋势解释、报告草稿；逐项核验数字、出处、日期和单位，人工签核。 |
| C LLM 直接预测数值 | API 可试验，但精度、复现性、合规性无实证；只能离线与现有模型比较，不能直接用于调度。 |
| D 专项时序模型 + LLM 解释 | 与现有架构分工一致；先回测当前模型，必要时优化统计/时间序列模型。 |

建议数据流：**受控取数 → 分类与允许字段白名单 → 现有模型/公式计算 → LLM 生成结构化叙述草稿 → 数字/来源/敏感信息校验 → 人工审阅 → 现有模板生成 DOCX**。不授权模型访问原始附件、数据库连接或执行任意 SQL；超时、空返回、无效输出、数据缺失或审批失败时跳过 AI 草稿并回退现有模板。

如获准接入，可在服务端新增可替换供应商的叙述接口、配置开关及密钥托管，设置 TLS、超时/限流/有限重试/熔断/费用限额；记录报告 ID、源数据时点/版本、模型及提示词版本、校验状态、审阅人。日志只留脱敏元数据，前端明确标记“AI 草稿/已复核”。这些是设计建议，不是现有功能。

## 试点与验收门禁

1. **数据审批**：完成字段分级、权属、业务许可和法务/安全审批；第一轮仅用合成或经确认可公开的样例。存在协议排除数据时停止公网 API 试点，评估隔离方案。
2. **报告基线**：先核实数据源、SQL 参数、月/季模板及指标口径；建议准备至少 50 份允许使用的样本，覆盖零/空值、异常波动和取数失败。这是拟定试验量，不是现有数据规模。
3. **质量门槛（待业务负责人确认）**：金额、比率、日期、单位与已核验来源逐条一致率 100%；无杜撰引用、敏感信息泄漏或越权取数；空返回/超时/无效 JSON 可拦截回退；保留审计记录和人工签核。测量延迟、重试与单篇实际费用，再按单位 SLA 定性能阈值。
4. **预测门槛**：按时间切分做滚动回测，对比当前模型、季节性朴素基线、候选模型的 MAE、WAPE、偏差、预警召回/误报率；避免未来信息泄漏。业务方确定容忍阈值，未过门槛只显示研究结果，不自动用于资金调度。
5. **上线门槛**：经数据/法务/安全、业务、采购与运维审批，完成限额、模型版本变更、供应商故障演练及回滚。本分析不授权传输真实数据或自动发布报告。

未验证：生产网络、接口 SLA/限流、真实成本与精度、线上数据/模板质量、合同条款及部署资源；本次未修改代码、配置或数据库，不声称已联调、构建或上线。
