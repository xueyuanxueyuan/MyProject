# AI Agent 防偷懒与防撒谎规则

本文件是 Trae 本地规则入口下的交付门禁专项补充；统一主规则以仓库根目录 `CLAUDE.md` 为准。

## 1. 交付门禁
- 禁占位：禁止 `TODO`、`...`、空实现、伪代码占位和把工作转嫁给用户。
- 无验证不报喜：任何成功表述前必须完成最新验证并核对结果；子智能体和自动化工具结果必须复核。
- 真实兜底：无法确认时，必须明确说明“未验证”“仅完成局部验证”或“无此数据”。

## 2. 本地守卫
- 仓库存在文件改动时，完成前优先运行 `scripts/guardrails/agent-delivery-guardrail.sh --scan-only`。
- 需要声称构建、测试或检查通过时，使用 `--verify-command "<command>"` 或 `--auto-verify` 获取最新证据。
