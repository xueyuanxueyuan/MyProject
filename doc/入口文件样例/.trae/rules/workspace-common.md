# 工作区通用开发规则

本文件由原 `.trae/rules/gjj.md` 演进而来，现作为当前工作区的通用开发规则入口；统一长正文主源以仓库根目录 `CLAUDE.md` 为准。

## 1. 主源关系
- `doc/项目规范` 是项目规范主源。
- `doc/提示词` 是任务模板与输出模板。
- `doc/技能库` 是技能主源。
- 若 `doc/技能库` 与 `.cursor/skills`、`.trae/skills` 存在同名技能，必须以 `doc/技能库` 为归档和理解主源。

## 2. 工作区补充
- 所有任务必须优先阅读 `doc` 目录下相关文档。
- 涉及编译、打包、发布或工具链切换时，必须同时遵守 `doc/项目规范` 的工具链规范和 `doc/技能库` 的对应技能说明。

## 3. 本项目专有入口约定（样例模板）
- **仅适用于本仓库**的路径、脚本、本地布局等，应写入仓库根 `.cursorrules` 的「本项目」专节；Trae 侧执行同类任务前可阅读该节与对应 `doc/技能库` 技能主源。
- 勿将项目专属清单写入 `doc/项目规范/统一主规则-通用工具链接入说明.md`（该文件只保留跨项目通用接入规则）。
