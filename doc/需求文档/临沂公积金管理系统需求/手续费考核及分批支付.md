# 一、**手续费支付**

1、手续费考核页面，在手续费后新增‘考核比例（%）’列，可手动输入0到100之间的数字，银行考核金额列为手续费*考核比例得出的数据，保留2位有效数字，同时保留修改功能，后续修改输入的金额无需与前面的比例挂钩。参考效果图如下：

![img](file:////tmp/wps-source/ksohtml/wpsLzMzSy.jpg) 

2、手续费考核完成后，同步进行差额部分冲减对应科目的操作。

3、手续费支付允许多次支付，支付申请时默认考核后的结果数据，可手动修改，修改后的金额不可大于当条明细的考核金额。每次支付完成后可自动生成凭证。

4、多次支付后需将考核结果数据支付完毕。
