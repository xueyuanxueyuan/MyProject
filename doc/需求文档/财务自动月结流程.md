***\*财务自动月结流程 –\**** ***\*流程\*******\*说明书\****

***\*一、需求概述\****

**·** ***\*任务名称\****：财务自动月结与检测提醒

**·** ***\*执行时间\****：每月1日 ***\*07:30\****

**·** ***\*执行频率\****：每月一次

**·** ***\*任务类型\****：定时任务

***\*二、前置条件（必须全部满足，否则终止）\****

| 序号 | 条件说明                                                     | 验证方式           |
| ---- | ------------------------------------------------------------ | ------------------ |
| 1    | 日结已完成（业务日期已到当月1日）                            | 系统内部状态标志   |
| 2    | 若上月为季度末月（3/6/9/12月），需已生成个贷预提凭证 + 定期预提凭证+公积金预提凭证 | 凭证表存在对应记录 |
| 3    | 上月所有资金已入暂收暂付                                     | SQL见下方3.1       |
| 4    | 上月所有日记账已记账                                         | SQL见下方3.2       |
| 5    | 上月所有业务流水已经记账                                     | SQL见下方3.3       |

***\*3.1 暂收暂付检查SQL\****

select count(1) 

from zjjs_zj_zhbdtz 

where jyrq between replace(?yjny,'-','')||'01' 

​        and replace(?yjny,'-','')||'31' 

 and dzzt='0'

· ?yjny：上个月，格式 YYYY-MM

· 结果 = 0 表示通过；> 0 表示有未入暂收暂付数据

***\*3.2 日记账记账检查SQL\****

select count(1) 

from cwhs_yhckrjz 

where ztbh='01' 

 and jzrq between ?yjny||'-01' 

​        and last_day(?yjny||'-01') 

 and rzzt='02'

· 结果 = 上月总日记账数 等于0表示通过；否则有未记账

***\*三、月结状态判断（08:00执行）\****

***\*判断SQL\****

sql

select count(1) 

from cwhs_ztsx 

where ztbh='01' 

 and yjny = to_char(sysdate-1, 'yyyy-mm')

**·** ***\*结果 = 1\****：月结已完成 ✅

**·** ***\*结果 ≠ 1\****：月结未完成 ⚠️
