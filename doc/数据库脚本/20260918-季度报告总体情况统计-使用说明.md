# 季度报告总体情况统计 SQL 使用说明

## 交付物与边界

完整脚本：`20260918-季度报告总体情况统计-达梦候选修正版.sql`。这是基于仓库季度模板配套指标SQL的候选修正版，不是用户原SQL的纯语法等价改写，也未在目标达梦实例执行验证。没有修改线上模板、数据库或原始指标SQL文件。

## 页面配置

- 数据项编码：`ztqktj`；类型：对象；配置类型：SQL查询。
- 数据源：实际包含脚本所需表的连接；不能仅因ID=10能连通就认为它具备全部指标表。
- 结果类型：单行列表（`first_row`）；依赖参数：`ssnd,ssjd`；不通过运行时输入覆盖该数据项。
- 所属年度传四位数字，所属季度传1至4的整数；例如2025和1。
- 整个SQL文件复制到SQL查询框。脚本无前置注释、无末尾分号，适配现有查询入口的语句检查；只读，不包含写库语句。

## 与用户附件的口径差异

1. 按仓库季度报告配套口径统计年初至所选季度末累计，不是仅统计该季度。年度平均增长沿用仓库前三个完整年度同比增幅的平均值，不沿用原附件包含本年的两年复合增长率。
2. 季度表 `tjzq` 按YYYYQ处理，月度表按YYYYMM处理，先转整数再取年/周期；月度提取和放款使用 `_mfm` 表，历史年度增长使用 `_qfq` 表。必须核验环境表字段和周期实际编码。
3. 期末余额沿用仓库 `dws_fin_bal_em` 的季度末月份快照，归集科目201、贷款科目121；年初比较值取上年12月。没有继续把整个季度每天的余额相加。
4. 结息金额沿用仓库 `dws_fin_per_stl_int_yfm` 的7月记录，自第三季度起纳入。这个月份及表内金额是否可求和需由实际数据口径验证，不能当成所有地区通用的结息规则。
5. 提前还贷类型保留用户附件的02、03；仓库配套SQL为03、04，两者不一致。执行前必须核对实际 `hkywlx` 字典，不可默认仓库版本对当前环境正确。
6. `zfxfe` 按仓库定义为提取金额加贷款发放金额（亿元），`zfxftb` 为同比增加额（亿元），不是增长率；`zfxfjsnpjzzl` 为历史年度增长率。此前对话把这些字段解释为支付利息有误，以此更正。
7. 存贷比输出百分数，变化输出相对上年末的百分点差；提前还贷占比输出百分数，其变化沿用仓库的占比相对变化百分比。应与实际模板文字单位一致。
8. 分母为零及无汇总值时主要沿用仓库返回0的约定。这不能证明源数据完整；正式报表必须另行确认数据已入仓且期间完整。

## 修正内容

- 补齐模板所需jxje、zfxftb、zfxfjsnpjzzl，最终返回37列，含日志引用的32个总体情况字段。
- 同比计算使用差额除以上年值，加入分母为零保护；不使用裸数值拼接布尔条件。
- 财务数据独立汇总后与其它单行聚合结果关联，避免原附件当年/去年明细笛卡尔积。
- 去掉未使用的MySQL日期表达式；使用MOD、COALESCE；参数CTE加FROM dual；输出列别名用双引号保留小写。
- 不返回测试常量指标；但源数据缺失后的零值仍需业务验收。

## 已做与未做的验证

已检查参数仅为ssnd、ssjd、模板32个字段均有输出别名、括号平衡、UTF-8无BOM、无末尾分号，长度低于现有20000字符限制。这是静态检查，不是SQL解析器或数据库执行验证。

未确认实际表是否存在、字段类型、科目和还款字典、年月编码、结息累计口径、数据完整性及目标数据库执行计划。首次应在测试数据源使用已知期间执行只读查询，核对原始金额及同比基数，再用于报告。若需要保持用户原附件的单季度口径，应另行确认，不能直接用此累计版替代。
