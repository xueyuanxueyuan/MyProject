# 20260522 MemSearch 通用记忆库接入

## 1. 用户目标

用户希望参考 MemSearch 思路，但记忆库必须是通用的，放在 `doc` 下，任何 Agent 都能读取使用。

## 2. 执行结论

- 创建 `doc/记忆库` 作为通用长期记忆事实源。
- 创建 `AGENT_MEMORY.md` 作为所有 Agent 的入口。
- 创建 `项目记忆`、`决策记录`、`会话记录`、`检索指南` 四类目录。
- MemSearch 配置调整为索引 `doc/记忆库`，隐藏目录仅作为可选缓存。

## 3. 验证状态

- Markdown 记忆库结构已创建。
- 文件位于 `doc` 下，可被当前仓库跟踪。
- ONNX 端到端索引受 HuggingFace 网络影响，需网络恢复后验证。

## 4. 后续建议

- 每次形成可复用结论时，优先写入 `doc/记忆库/项目记忆` 或 `doc/记忆库/决策记录`。
- 每次工具接入或跨会话交接时，可在 `doc/记忆库/会话记录` 新增简明记录。
- 如果 Agent 支持 RAG，应索引 `doc/记忆库`，而不是索引隐藏目录。
