# Gjj 通用记忆库

## 1. 定位

本目录是 Gjj 工作区的通用长期记忆库，面向所有 AI Agent、开发工具和人工协作场景开放读取。

它的核心原则是：

- `doc/记忆库` 是记忆事实源，所有 Agent 都应优先读取这里。
- Markdown 文件可读、可改、可审计，可随 `doc` 一起纳入版本管理。
- 向量库、缓存、索引只作为可重建的检索加速层，不是事实源。
- 任何工具都可以基于本目录建立自己的 RAG，但不得把私有索引反向当作唯一记忆。

## 2. 目录结构

```text
doc/记忆库/
├── README.md
├── AGENT_MEMORY.md
├── 项目记忆/
│   └── 000-项目长期记忆.md
├── 决策记录/
│   └── 000-架构与工具决策.md
├── 会话记录/
│   └── 20260522-MemSearch通用记忆库接入.md
└── 检索指南/
    └── MemSearch使用指南.md
```

## 3. Agent 读取顺序

任何 Agent 进入 Gjj 工作区后，建议按以下顺序读取：

1. `doc/记忆库/AGENT_MEMORY.md`
2. `doc/记忆库/项目记忆/000-项目长期记忆.md`
3. 与当前任务相关的 `doc/记忆库/决策记录/*.md`
4. 必要时读取 `doc/记忆库/会话记录/*.md`
5. 若需要语义检索，再使用 MemSearch 或其他 RAG 工具索引 `doc/记忆库`

## 4. 写入规则

适合写入记忆库的内容：

- 稳定的项目约束、流程规则、跨会话常用结论。
- 已验证的重要技术决策及其原因。
- 多个 Agent 或后续会话需要继承的上下文。
- 容易重复踩坑的环境问题、工具链问题、业务约束。

不适合写入记忆库的内容：

- 密钥、Token、账号密码、私有连接串。
- 一次性临时日志、未验证猜测、无结论的中间过程。
- 大段原始命令输出、构建产物、二进制文件。
- 当前任务 Todo 进度，进度应写入操作记录或任务系统。

## 5. RAG 接入原则

- 推荐索引范围：`doc/记忆库`。
- 推荐源文件格式：Markdown。
- 推荐检索方式：先搜索摘要与项目记忆，再展开决策记录和会话记录。
- 推荐本地索引位置：用户目录或工具私有目录，避免把向量库提交进仓库。

## 6. 与 MemSearch 的关系

MemSearch 可以索引本目录，但本目录不依赖 MemSearch 才能使用。

- 没有 MemSearch：Agent 直接读取 Markdown。
- 有 MemSearch：Agent 用语义检索召回 Markdown 片段。
- 换其他 RAG：只要索引 `doc/记忆库` 即可复用同一套事实源。
