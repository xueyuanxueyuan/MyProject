- 通用住建部交易接口自动化测试工具，由 **OpenAPI/Swagger + 银行 Excel** 驱动，可批量生成并真实发起接口用例，覆盖收款/付款/扣款/签约等全量接口。

## 3. 三种运行模式

- `dry-run`：只生成用例和报告，不请求服务（默认，适合先检查请求数据）。
- `run`：真实请求目标服务。
- `template`：生成银行测试数据 Excel 模板。

## 4. 命令行参数约定

| 参数 | 说明 |
|------|------|
| `--city` | 城市键，读取 `city-config.json` 固定参数；不传用 `defaultCity` |
| `--tag-filter` | 按 OpenAPI 标签筛选（如 `住建部`） |
| `--summary-filter` | 按接口摘要/名称筛选（如 `新增批量收款请求`） |
| `--excel` | 银行测试数据 Excel 路径 |
| `--output-dir` | 报告/用例输出目录 |
| `--bank-name` / `--bank-code` | 银行名称 / 银行代码（如无法从 Excel 取则必传） |
| `--mode` | `dry-run` / `run` / `template` |
| `--base-url` | 临时覆盖服务地址（优先级高于配置文件） |
| `--xtlx` / `--ywlx` | 系统类型 / 业务类型快捷覆盖（等价 `--set-field`） |
| `--set-field name=value` | 递归覆盖请求体里同名字段 |
| `--account-type` | `private` / `public` / `both`（对私/对公/由模板决定） |
| `--expect-http` / `--timeout` | 期望 HTTP 状态 / 超时秒数 |

## 5. 城市固定参数配置（city-config.json）

- 每个城市节点含 `fixedParams`：`zxbh, jbjgbh, jbjgmc, qdlx, qdbm, wdbh, wdmc, ywjbjgbh, ywqd`；以及 `serviceBaseUrl`、`hsjgbh`（嘉兴有）。
- 脚本按 `--city` 读取并递归覆盖请求体同名字段；**新增城市只需复制节点改 `fixedParams`/`serviceBaseUrl`**。
- 服务地址优先级：`--base-url` 命令行 > `city-config` 当前城市 `serviceBaseUrl` > 缺失则 `run` 模式报错。
- 当前已配置城市（已核对文件）：
  - `zaozhuang`（枣庄）：`serviceBaseUrl=http://100.70.1.0:31108`，`fixedParams` 为 Apipost 示例值。
  - `jiaxing`（嘉兴）：`serviceBaseUrl=http://k8s.gjj.jxgjj:31129`，`zxbh=330400000000000`、`jbjgbh=0101`、`jbjgmc=市本级`、`hsjgbh=0101`。
- `defaultCity` 当前为 `zaozhuang`。

## 9. 账户类型处理（对私/对公）

- Excel 分对私/对公区；用 `--account-type private/public/both` 控制。
- 历史坑：接口模板明细自带 `zhlx=2`（对公）会**覆盖** `--account-type private`，导致传到对公账户。已修复为：明确指定 `private/public` 时**强制按指定类型取数**，只有 `both` 才允许模板值决定。
- `zhlx=1` 对私、`zjlx=01`；`zhlx=2` 对公。
