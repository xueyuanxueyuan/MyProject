# 架构与工具决策

## ADR-0001：记忆事实源放在 doc/记忆库

- 日期：2026-05-22
- 状态：已采纳
- 决策：将跨 Agent 长期记忆事实源放在 `doc/记忆库`，而不是 `.memsearch/memory`。

### 背景

用户要求记忆库必须通用，并且位于 `doc` 下，任何 Agent 都能读取使用。

### 原因

- `doc` 是当前仓库已跟踪、可审计、可同步的知识目录。
- 隐藏目录更适合放工具缓存，不适合作为跨 Agent 的事实源。
- Markdown 记忆源放在 `doc` 下后，即使没有 MemSearch，Agent 也能直接读取。

### 影响

- MemSearch、其他 RAG、人工阅读都应索引或读取 `doc/记忆库`。
- `.memsearch` 仅保留为可选工具私有缓存目录。

## ADR-0002：向量索引不提交仓库

- 日期：2026-05-22
- 状态：已采纳
- 决策：Milvus Lite、模型缓存、向量索引等均放在用户目录或工具私有目录，不提交仓库。

### 原因

- 向量库是可重建缓存，不是事实源。
- 索引文件可能体积大、平台相关、包含派生数据。
- 保持仓库干净，降低跨 Agent 使用门槛。

## ADR-0003：默认优先 ONNX，但允许替换 provider

- 日期：2026-05-22
- 状态：已采纳
- 决策：默认使用 MemSearch ONNX embedding；如网络或模型下载受限，可切换到 OpenAI、Ollama、Zilliz/Milvus 或其他 RAG。

### 原因

- ONNX 不需要 OpenAI Key，适合作为安全默认方案。
- 当前环境访问 HuggingFace 可能失败，因此必须保留替代方案。
- 记忆源在 Markdown，替换检索后端不影响事实源。
