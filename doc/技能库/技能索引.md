# Gjj 技能库索引（Skill Registry）

更新时间：2026-08-14
用途：本项目 `doc/技能库/` 全部技能的**可寻址索引**。AI 助手进入工作区后，先用本文件快速定位技能，再 Read 对应 `SKILL.md` 深读并遵循其流程。

## 使用方式

- **主源**：每个技能的正文以 `doc/技能库/<name>/SKILL.md` 为准，本索引只做路由与一句话定位。
- **加载约定（WorkBuddy）**：WorkBuddy 内置 `Skill` 工具加载的是市场技能；本项目技能需 **Read 对应 `SKILL.md`** 后遵循其流程使用。
- **工具适配**：技能原文含 `TodoWrite`、`.trae/rules` 等工具专有名；在 WorkBuddy 中映射为 `TaskCreate/TaskUpdate/TaskList` 与 `doc/项目规范/`、`doc/记忆库/`。
- **非核心技能**：下表一句话定位依据技能名与路由表推断，精确流程以深读 SKILL.md 为准。
