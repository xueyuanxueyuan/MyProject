# Agency Agents 速查

基于 `agency-agents-zh` 的本地精选速查，不追求列出全部 `215` 个角色，而是优先覆盖当前工作区高频、好用、容易选错的角色。

## 怎么选

| 任务类型 | 主推荐角色 | 备选角色 | 适用说明 |
|----------|------------|----------|----------|
| 页面开发、交互优化 | `前端开发者` | `高级开发者`、`UI 设计师` | 适合组件实现、响应式布局、前端性能和体验问题 |
| 接口设计、服务拆分、表结构 | `后端架构师` | `软件架构师`、`数据库优化师` | 适合 API、数据库、边界建模和扩展性设计 |
| 小步快改、低风险修复 | `最小变更工程师` | `高级开发者` | 适合补丁式修改、减少改动面和回归风险 |
| 代码阅读、仓库上手 | `代码库入职引导工程师` | `软件架构师` | 适合快速理解模块边界、入口和数据流 |
| 代码审查、风险把关 | `代码审查员` | `现实检验者` | 适合识别 bug、回归风险、缺失测试和设计隐患 |
| 上线前验收、质量门禁 | `现实检验者` | `证据收集者`、`API 测试员` | 适合做证据驱动的严格验收和生产就绪判断 |
| 界面验收、缺陷留痕 | `证据收集者` | `无障碍审核员` | 适合截图、复现步骤、视觉比对和 QA 留证 |
| 接口测试、联调验证 | `API 测试员` | `性能基准师` | 适合接口正确性、鉴权、异常流和性能基线 |
| 多角色协作编排 | `智能体编排者` | `工作流架构师`、`项目牧羊人` | 适合多人并行、阶段门禁、交接与流水线规划 |
| MCP、Agent 工具扩展 | `MCP 构建器` | `AI 工程师`、`提示词工程师` | 适合 MCP Server、工具协议和 AI 集成 |
| 飞书、钉钉、微信生态 | `飞书集成开发工程师` | `钉钉集成开发工程师`、`微信小程序开发者` | 适合国内企业协作与微信生态相关需求 |
| 小红书、抖音、私域增长 | `小红书运营专家` | `抖音策略师`、`私域流量运营师` | 适合中国平台内容运营和获客策略 |
| 政务、招投标、ToG | `政务数字化售前顾问` | `高管摘要师` | 适合方案、标书、售前汇报与合规表达 |

## 常用角色对照

| 中文名称 | 英文/规则名 | 典型触发词 |
|----------|-------------|------------|
| 前端开发者 | `Frontend Developer` | 页面、组件、交互、样式、性能 |
| 后端架构师 | `Backend Architect` | API、数据库、服务、表结构 |
| 代码审查员 | `Code Reviewer` | review、审查、风险、回归 |
| 现实检验者 | `Reality Checker` | 验收、上线、证据、生产就绪 |
| 代码库入职引导工程师 | `Codebase Onboarding Engineer` | 仓库结构、模块说明、快速上手 |

| MCP 构建器 | `specialized-mcp-builder` | MCP、工具扩展、协议集成 |

## 中文口令示例

- 切换到前端开发者，看看这个页面布局和交互问题
- 切换到后端架构师，评估这个接口设计和库表关系
- 切换到代码审查员，重点找 bug、回归风险和缺失测试
- 切换到现实检验者，判断这次改动是否达到上线标准
- 切换到智能体编排者，帮我安排这个需求的多人协作流程
- 给我推荐适合做飞书审批集成的角色

## Trae 使用提示

- 全量角色很多，Trae 中更推荐“精选安装 + 显式点名”
- 自动触发常用角色建议控制在 `10-20` 个以内
- 真正需要强制命中时，直接说角色名，或使用 `@规则名`
- 长期开启的少数核心角色才考虑 `alwaysApply: true`
