# 提交准则对齐公司 Commit 规范记录

## 1. 背景
- 公司新增了 `doc/项目规范/第一研发中心-代码Commit提交规范说明.md`，要求所有提交在 commit message 末尾补充 `AI辅助` 与 `AI工具` 两个统计字段。
- 当前仓库仍存在“标题强制追加 `（AI生成提交）`”和“提交描述固定写成 `1. 改了什么 / 2. 为了解决什么问题`”的旧口径，需要统一切换到公司标准格式。

## 2. 本次调整内容
- 将仓库主规则、项目规范、模板样例中的 Git 提交要求统一改为公司标准结构：

```text
<提交类型>: <简短说明>

<可选：补充说明>

AI辅助: true/false
AI工具: <公司规范允许值>
```

- 明确 `AI辅助` 只能填写小写 `true` 或 `false`。
- 明确当 `AI辅助: false` 时，`AI工具` 必须填写 `None`。
- 取消旧规则中对 `（AI生成提交）` 标题后缀和固定两段编号说明的强制要求。
- 保留“提交内容必须具体、可审计”和“提交前先同步远端主线并处理冲突”的既有要求。

## 3. 涉及文件
- `CLAUDE.md`
- `.cursorrules`
- `doc/通用模板/Git提交描述模板.md`
- `doc/项目规范/统一主规则-通用工具链接入说明.md`
- `doc/项目规范/Gjj项目组智能体协同开发规范.md`
- `doc/入口文件样例/CLAUDE.md`

## 4. 使用说明
- 以后提交时优先按 `doc/通用模板/Git提交描述模板.md` 套用。
- 如需确认字段取值、判定边界或公司统计口径，以 `doc/项目规范/第一研发中心-代码Commit提交规范说明.md` 为最终主源。
- 若公司后续调整 `AI工具` 枚举或解析规则，优先同步公司规范，再更新本仓库模板与入口规则。

## 5. 备注
- 公司规范文档中 `AI工具` 枚举在不同章节存在少量表述差异，因此本仓库规则统一采用“引用公司规范主源 + 模板给出常用值示例”的方式，避免在多个入口复制一份可能过时的枚举清单。
