# 20260623-枣庄明细账打印沿用总账关联参数调整记录

## 1. 需求说明

- 页面：`zaozhuang/WebstormProjects/capinfo-gjj-frontend-jshs-gm/src/components/cwhs/zbgl/newmxz.vue`
- 需求：当明细账页面是通过总账关联进入时，打印应当使用总账关联时传入并实际查询过的参数，而不是重新按页面月份条件组装整月参数。

## 2. 问题定位

- 明细账页面通过总账关联进入时，会先自动执行一次按关联参数的制作与查询。
- 这次自动查询后的真实参数会被保存到 `lastQueryCondition`。
- 但 `handlePrint()` 原逻辑直接调用：

```js
const payload = this.buildPayload();
```

- 这样会重新按当前表单月份条件构造参数，导致总账关联进入时，打印口径可能回退成整月范围。

## 3. 本次调整

- 将打印逻辑改为优先使用已查询参数：

```js
const payload = this.lastQueryCondition || this.buildPayload();
```

## 4. 调整效果

- 总账关联进入明细账后：
  - 打印优先使用关联查询时的真实参数
  - 会沿用总账关联传入的具体日期范围
- 普通手工进入页面、且尚未查询时：
  - 仍可回退使用 `buildPayload()` 按当前表单参数打印

## 5. 验证情况

- 已执行静态诊断，未发现本次改动引入的新错误。
- 已复核差异，确认改动范围仅限 `handlePrint()` 的参数来源调整。
