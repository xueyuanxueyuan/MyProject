- 用户已在 `zjjs_zj_zhbdtz` 与 `cwhs_yhckrjz` 两张表新增 `file_path` 字段，类型为 `varchar2(255)`。

- `cwhs_yhckrjz` 对应的新增请求 DTO、实体、DO、Mapper 增加 `filePath <-> file_path` 映射。
- 日记账新增链路与异步补写链路均补充 `filePath` 透传，避免仅主表有值、日记账为空。
