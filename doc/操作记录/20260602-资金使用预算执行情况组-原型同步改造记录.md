# 资金使用预算执行情况组原型同步改造记录

## 1. 问题背景

用户指出：

- 原型界面没改

经核对确认，之前仅完成了：

- 功能设计文档收敛

但实际原型文件：

- [index.html](file:///home/source/Jetbrains/Probject/Gjj/doc/操作记录/20260601-资金预决算及执行情况-交互原型/index.html)

中的 `资金使用执行` 菜单，仍然走旧的通用表格分支，没有落地“资金使用预算执行情况组”的专属页面结构。

## 2. 根因确认

本轮定位到的根因是：

1. `index.html` 只为 `资金使用预算`、`业务收支预算` 提供了专属界面分支。
2. `资金使用执行` 仍复用旧的 `fetchLegacyData()` 通用逻辑。
3. 因此虽然文档中已经定版为“月度单表、市中心统一制表”，但页面仍未体现。

## 3. 本轮改造内容

## 3.1 菜单专属分支

在 `index.html` 中为 `zjsyzx` 新增了专属界面分支：

- 不再走旧的通用表格模板
- 改为按最终设计渲染单页执行情况表

## 3.2 页面结构

本轮实际原型已改造成：

1. 顶部标题与状态区
2. 工具栏区
3. 单表执行情况主表
4. 底部签字区

与最终功能设计保持一致，不再拆分总表/附表。

## 3.3 数据模型

新增原型内模型：

- `zjsyzxData`
- `zjsyzxRows`

其中：

- `zjsyzxData` 模拟主表 + 机构执行明细数组
- `zjsyzxRows` 由固定行配置生成，直接对应 Excel 的 29 行结构

## 3.4 行配置落地

已在原型中落地以下 29 行：

### 归集提取

1. 上年末余额
2. 本年归集预算数
3. 本年归集实绩数
4. 归集完成预算数(%)
5. 上年归集同期数
6. 归集同比增长(%)
7. 本年提取预算数
8. 本年提取实绩数
9. 提取完成预算数(%)
10. 上年提取同期数
11. 提取同比增长(%)
12. 当年统筹调剂资金
13. 期末余额

### 个人贷款

14. 上年末余额
15. 本年发放预算数
16. 本年发放实绩数
17. 发放完成预算数(%)
18. 上年发放同期数
19. 发放同比增长(%)
20. 本年收回预算数
21. 本年收回实绩数
22. 收回完成预算数(%)
23. 上年收回同期数
24. 收回同比增长(%)
25. 当年“公转商”贷款转出
26. 期末余额
27. 逾期贷款
28. 逾期贷款率

### 占比

29. 个人贷款余额占归集余额比(%)

## 3.5 自动计算与全市汇总

本轮在原型中实现了：

- 各机构行明细自动重算公式项
- 全市金额列自动求和
- 全市比例列按汇总后的分子分母重算

未采用：

- 直接平均机构比例

## 3.6 手工项控制

本轮仅保留以下手工输入项：

- `当年统筹调剂资金`
- `当年“公转商”贷款转出`

其余字段均按：

- 自动取数
- 自动计算
- 只读展示

## 3.7 权限与按钮

### 市中心

当前原型中展示为制表视角，可见：

- 自动取数
- 保存草稿
- 提交审核
- 锁定
- 导出完整报表

并允许编辑手工字段。

### 分中心

当前原型中仅保留：

- 导出完整报表

不再显示：

- 保存草稿
- 提交审核
- 审核通过
- 退回
- 锁定

同时所有表格单元格只读，仅查看：

- 全市列
- 本机构列

## 4. 本轮结果

本轮改造后，`资金使用执行` 菜单已与最终功能设计一致：

1. 页面已从旧的通用表格切换为专属单表界面。
2. 行结构已扩展为 29 行。
3. 市中心与分中心权限差异已在页面上体现。
4. 手工项与自动项边界已在页面上体现。
5. 全市汇总和比例重算规则已在原型中体现。
