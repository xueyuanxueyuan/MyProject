# 20260613-枣庄试算平衡后端实现记录

## 1. 任务背景

- 需求名称：试算平衡
- 项目范围：枣庄 `capinfo-gjj-busi-cwhs-jzgl`
- 目标：新增后端试算平衡查询能力，按一级科目余额返回资产、负债、净资产、收入、支出及平衡结果。

## 2. 已确认业务口径

- 资产：`1%`
- 负债：`2%`
- 净资产：`3%`
- 收入：`401%`
- 支出：`411%`
- 限定条件：`kmjb = 1`
- 余额函数：`f_cwhs_getKmye(ztbh, kmbh, jzrq)`
- 平衡公式：`资产 = 负债 + 净资产 + 收入 - 支出`

- 在 `CwhsZbglController` 暴露 `/api/v1/cwhs/querySsphZbgl`
