# 资金使用预算组固定字段到原型映射说明记录

## 1. 本轮补充原因

用户指出：

- 数据库中像 `GJTQ_NCYE_SNYSS` 这样的固定字段已经落库
- 设计文档还需要进一步说明接口和前端如何处理，才能实现当前原型里的表格效果

本轮因此补充了“库表字段 -> 接口 -> 前端 -> 原型”的完整链路说明。

## 3. 本轮补充内容

### 3.1 总表链路

新增说明：

- 总表接口直接返回总表固定字段对象
- 前端通过 `budgetZbRowConfig` 这种行配置把固定字段对象映射为 15 行表格
- 不需要把数据库中的每个字段单独做成一块 UI

### 3.2 附表链路

新增说明：

- 附表接口返回机构明细行
- 每个机构一行，仍然是固定字段对象
- 前端通过 `budgetFbRowConfig` 做业务项行配置
- 再把机构行 Pivot 成横向区县列

### 3.3 保存链路

新增说明：

- 前端保存时不提交整张横向表
- 只提取当前机构列的可编辑字段
- 后端更新本机构固定字段后，再重算附表公式字段和总表汇总字段

## 4. 本轮结论

本轮补充后，预算组文档已经明确：

1. 固定字段为什么可以保留
2. 接口应该怎样返回
3. 前端怎样用行配置和 Pivot 还原原型效果
4. 保存时怎样从前端回写到附表固定字段
