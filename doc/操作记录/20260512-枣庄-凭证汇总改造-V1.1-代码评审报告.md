## 2. 总体结论
- **通过性结论**：当前实现存在**口径级 P0 问题**，不建议按“已满足按 yhzhhm+ywfl 汇总”的口径直接上线。
- **核心原因**：SQL 已引入 `yhzhhm/ywfl`，但服务端汇总组装仍按 `ywlx` 维度拆分与更新，导致“按中心账号+业务分类汇总”的关键目标在最终落库与标记更新环节被破坏。

## 4. P0 问题详述（必须修复）

### 4.1 汇总口径“名义上改了，实际上没改”
- **现象**：
  - SQL 聚合结果仍被 `a.ywlx` 切分（即使同一个 `ywfl` 下包含多个 `ywlx`，也会拆成多组）；
  - 服务端 `zdpzhz` 仍然以 `ywlx` 二次分组与循环，直接把不同 `yhzhhm/ywfl` 的数据合并进同一张汇总凭证。
- **风险后果**：
  - 汇总凭证金额、附件数、摘要、以及 `cwhs_pz.hzpzh` 的回写标记都可能错误；
  - 该错误不是“小概率”，而是只要同一业务类型下存在多个中心账号或多个业务分类（这是改造的典型场景）就会触发。
- **证据位置**：
  - SQL：仍 `GROUP BY a.ywlx`：[JzpzDOMapper.xml:L80-L88](file:///home/source/Jetbrains/Probject/Gjj/zaozhuang/IdeaProjects/capinfo-gjj-busi-jshs/capinfo-gjj-busi-cwhs-jzgl/capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi/src/main/java/cn/capinfo/gjj/busi/cwhs/jzgl/busi/domain/dao/mapper/JzpzDOMapper.xml#L80-L88)
  - Java：仍按 `ywlx` 分组并假设 “同一 ywlx 内 yhzhhm/ywfl 一致”：[CwhsServiceImpl.java:L2122-L2145](file:///home/source/Jetbrains/Probject/Gjj/zaozhuang/IdeaProjects/capinfo-gjj-busi-jshs/capinfo-gjj-busi-cwhs-jzgl/capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi/src/main/java/cn/capinfo/gjj/busi/cwhs/jzgl/busi/service/impl/CwhsServiceImpl.java#L2122-L2145)

### 4.2 汇总标记更新条件仍使用 ywlx
- **现象**：`pzhzJzbjXg` 更新 `cwhs_pz` 的条件仍 `eq(PzDO::getYwlx, n.getYwlx())`。
- **风险后果**：如果按新口径应该一张汇总凭证对应某个 `yhzhhm+ywfl`，此更新会把同 `ywlx` 的其他维度也一起标记，造成汇总凭证号串账。
- **证据位置**：[CwhsServiceImpl.java:L2314-L2322](file:///home/source/Jetbrains/Probject/Gjj/zaozhuang/IdeaProjects/capinfo-gjj-busi-jshs/capinfo-gjj-busi-cwhs-jzgl/capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi/src/main/java/cn/capinfo/gjj/busi/cwhs/jzgl/busi/service/impl/CwhsServiceImpl.java#L2314-L2322)

## 5. P1/P2 问题与建议

### 5.1 配置开关未落到配置文件（P1）
- **现状**：代码提供了默认值，但实施记录宣称“实装 application.yml + @Value 注入”，与实际不一致。
- **建议**：在区域配置（如 `application-city-zaozhuang.yml` 或 Nacos 配置）补齐 `voucher.summary.byYwfl`、`voucher.mapping.strictMode`、`voucher.mapping.fallback.enable`，并在实施记录中明确配置落点。

### 5.2 日志占位符使用不规范（P2）
- **现状**：存在 `log.info("凭证内容1：{}"+pzZdReqDTO)` 这种字符串拼接，会导致日志格式异常且影响排查效率。
- **建议**：统一使用参数化日志。
- **证据位置**：[CwhsServiceImpl.java:L6309-L6311](file:///home/source/Jetbrains/Probject/Gjj/zaozhuang/IdeaProjects/capinfo-gjj-busi-jshs/capinfo-gjj-busi-cwhs-jzgl/capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi/src/main/java/cn/capinfo/gjj/busi/cwhs/jzgl/busi/service/impl/CwhsServiceImpl.java#L6309-L6311)

### 5.3 多入口未注入维度（P1）
- **现状**：实施记录已声明存在其它凭证生成入口未注入 `yhzhhm/ywfl`。
- **建议**：明确这些入口是否在凭证汇总范围内；若在范围内必须补齐注入，否则新口径上线后“其他账号/其他分类”占比会显著上升，影响财务分析。
