# 入口规则第一阶段压缩记录

## 1. 目标
- 压缩高频入口文件，减少会话常驻 token 消耗。
- 保持原有触发语义、主源优先级和验证门禁不变。

## 2. 本次处理范围
- `CLAUDE.md`
- `.trae/rules/anti-laziness-anti-hallucination.md`
- `.trae/rules/workspace-common.md`

## 3. 压缩策略
- 保留“默认触发、主源引用、硬门禁、优先级、guardrail、最终规则”。
- 删除重复解释性段落和与主源正文重复的长描述。
- 继续以 `doc/技能库` 作为详细能力主源，以入口文件作为短规则。

## 4. 保留的关键语义
- 实质性任务默认启用 `anti-laziness-anti-hallucination`。
- 临近交付默认联动 `verification-before-completion`。
- 先查证、先拆解、禁占位、无验证不报喜、无法确认说真实状态。
- 成功表述前必须执行最新验证。
- 子 Agent 结果必须复核。
- 需要通过 `scripts/guardrails/agent-delivery-guardrail.sh` 做本地守卫。
- `doc/项目规范`、`doc/提示词`、`doc/技能库` 的主从定位不变。

## 5. 结果
- `CLAUDE.md` 从“完整解释型入口”压缩为“短入口规则 + 主源引用”。
- `.trae/rules/anti-laziness-anti-hallucination.md` 压缩为规则摘要，不再重复全文门禁说明。
- `.trae/rules/workspace-common.md` 压缩为项目级主源定位和交付底线，不再重复展开解释。

## 6. 风险控制
- 未删除默认触发语义。
- 未改变主源优先级。
- 未移除 guardrail 与验证要求。
