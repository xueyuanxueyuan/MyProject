# yht-mock-server 按账号尾号判定单笔结果规则对比留痕

## 1. 改动前

单笔实时交易终态逻辑位于 `MockRealtimeTradeResultPolicy`，原规则为：

1. 读取 `realtimeTradeSuccessRate`
2. 使用随机数与成功率比较
3. 随机决定成功或失败
4. 失败后从失败原因池中按随机索引选择原因

控制台页面和配置文件也暴露了：

1. “单笔成功率(%)” 滑块
2. `realtime-trade-success-rate` 配置项

## 2. 改动后

### 2.1 策略规则

改为按账号尾号判定：

1. `20601`：看 `DbtrActId`
2. `20602`：看 `CdtrActId`
3. 尾号大于 `6`：失败
4. 尾号小于等于 `6`：成功

失败原因池仍保留，只有在判定为失败后才参与选择失败码和失败描述。

### 2.2 配置口径

移除了概率型成功率配置的使用口径：

1. 删除属性类中的 `realtimeTradeSuccessRate`
2. 删除更新配置时对该字段的接收
3. `application.yml` 改为描述固定判定规则

### 2.3 页面口径

控制台页面不再展示“单笔成功率(%)”：

1. 原滑块删除
2. 改为固定规则说明文本

## 3. 测试对比

### 3.1 改动前测试口径

原测试验证的是：

1. 成功率允许时返回成功
2. 成功率不满足时返回失败
3. 非法失败原因池时回退默认原因池

### 3.2 改动后测试口径

新测试验证的是：

1. `20601 + DbtrActId` 尾号 `6` 成功
2. `20602 + CdtrActId` 尾号 `7` 失败
3. 边界值 `6` 成功
4. 非法失败原因池时仍回退默认原因池

## 4. 一句话对比结论

这次改动本质上是把：

1. **概率驱动**

改成了：

2. **账号尾号规则驱动**
