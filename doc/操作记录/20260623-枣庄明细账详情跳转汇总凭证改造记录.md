# 20260623-枣庄明细账详情跳转汇总凭证改造记录

## 1. 需求目标

- 位置：`zaozhuang/WebstormProjects/capinfo-gjj-frontend-jshs-gm`
- 页面：`newmxz.vue`
- 目标：将前端“明细账详情”从原来的弹窗展示，改为跳转到“汇总凭证查询”页面。

## 2. 现状说明

- `newmxz.vue` 原逻辑：
  - 满足条件时跳转到 `明细凭证查询(mxpzcx)`。
  - 不满足条件时弹出详情框，展示记账日期、凭单号、摘要、借贷发生额、余额等信息。
- `hzpzcx.vue` 原逻辑：
  - 仅识别来自 `kmyeb-table.vue` 的 `from = kmyeb-hzpzcx` 路由参数。
  - 无法直接承接来自明细账页面的跳转条件。

## 3. 本次改造

### 3.1 `newmxz.vue`

- 将以下方法从“明细凭证查询”口径改为“汇总凭证查询”口径：
  - `resolveMxpzcxRoutePath` -> `resolveHzpzcxRoutePath`
  - `canNavigateToMxpzcx` -> `canNavigateToHzpzcx`
  - `navigateToMxpzcx` -> `navigateToHzpzcx`
- 跳转目标改为：`cwhs/sspzhz/hzpzcx`
- 路由参数改为传递：
  - `from = mxz-hzpzcx`
  - `ztbh`
  - `kmbh`
  - `jzrqStart`
  - `jzrqEnd`
  - `xspzh`
  - `jzpzh`
- 删除原详情弹窗逻辑，改为：
  - 能跳则直接跳转
  - 缺少关键字段时给出提示信息

### 3.2 `hzpzcx.vue`

- 扩展路由识别逻辑，除原有 `kmyeb-hzpzcx` 外，新增支持 `mxz-hzpzcx`
- 新增支持从路由中解析：
  - `xspzh`
  - `jzpzh`
  - 可选 `kmbh`
- 在自动回填查询条件时同步设置：
  - `config.condition.jzrqQj`
  - `config.condition.kmbhList`
  - `config.condition.xspzh`
  - `config.condition.pzbhx`
  - `config.condition.pzbhd`

## 4. 改造效果

- 明细账点击“详情”后，不再弹出本地详情框。
- 当前行具备记账日期，且至少存在显示凭证号或记账凭证号之一时，直接跳转到汇总凭证查询页面。
- 汇总凭证查询页面能够自动带入账套、日期区间、显示凭证号、记账凭证号等条件，便于定位对应汇总凭证。

## 5. 验证情况

- 已对 `newmxz.vue`、`hzpzcx.vue` 执行静态诊断。
- `hzpzcx.vue` 无新增诊断问题。
- `newmxz.vue` 仅存在文件原有的未使用参数提示，不属于本次改造新增问题。

## 6. 风险说明

- 当前跳转依赖明细账行中的 `xspzh/jzrq/ztbh` 等关键字段。
- 若后端返回行缺少显示凭证号，则前端会提示无法跳转，不再展示原弹窗详情。
