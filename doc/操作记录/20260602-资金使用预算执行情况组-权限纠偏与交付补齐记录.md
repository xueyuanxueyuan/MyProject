# 资金使用预算执行情况组权限纠偏与交付补齐记录

## 1. 问题来源

用户指出两类问题：

1. `资金使用执行` 原型被做成了“市中心填报、分中心只查”，方向做反。
2. 本组没有产出对应的详细设计文档和独立达梦脚本。

## 2. 本轮核实结果

经核实，问题成立：

- 现有专项功能设计文档把本组错误写成了“市中心统一制表”。
- 现有原型 `index.html` 也按错误权限做成了市中心可录入、分中心只读。
- 本组缺少以下交付物：
  - 详细设计与数据库设计文档
  - 独立达梦执行脚本

## 3. 本轮纠偏原则

本轮统一按以下正确口径重做：

1. 分中心是唯一填报主体。
2. 市中心查看全市和全部机构数据，只负责审核、退回、锁定和导出。
3. 数据库存储继续采用“主表 + 机构执行明细表”。
4. 全市列只做汇总展示，不作为人工录入字段。

## 4. 本轮补齐内容

本轮补齐了以下交付物：

- 更正后的功能设计文档
- 新增详细设计与数据库设计文档
- 新增独立达梦执行脚本
- 更正后的实际原型界面
