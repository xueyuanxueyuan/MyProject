# 20260706-枣庄凭证汇总摘要回退口径修复记录

## 1. 背景
- 用户要求继续修改“枣庄财务核算系统凭证汇总摘要”相关代码。
- 目标：将“其他银行”“其他分类”等默认展示口径统一调整为空串，避免摘要继续展示旧兜底文案。

- `capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi/src/test/java/cn/capinfo/gjj/busi/cwhs/jzgl/busi/service/support/VoucherSummaryDisplaySupportTest.java`

- `capinfo-gjj-busi-cwhs-jzgl-basic-svc-app/src/main/resources/application-city-zaozhuang.yml`

## 3. 修改内容

### 3.1 摘要显示辅助类
- `VoucherSummaryDisplaySupport.buildBranchBusinessSummary()` 中：
  - 银行名称缺失时不再回退为“其他银行”，而是回退为空串。
  - 业务分类名称缺失时不再回退为“凭证汇总摘要”，而是回退为空串。

### 3.2 业务分类回退逻辑
- `CwhsServiceImpl.mapYwfl()` 中：
  - `mappingFallbackEnable=false` 时，由原先回退 `"其他分类"` 改为空串。
  - `mappingFallbackEnable=true` 且 `ywlx` 为空时，也改为空串。

- `CwhsServiceImpl.mapYwflName()` / `mapStoredYwflDisplayName()` 中：
  - 字典未命中时不再回退 `"凭证汇总摘要"`。
  - 对历史遗留值 `"其他分类"` 统一视为空串展示。

### 3.3 SQL 汇总维度归并
- `JzpzDOMapper.xml` 中，`ywfl` 维度统一改为：
  - `NULL`
  - 空串
  - 空白
  - 历史值 `"其他分类"`

以上四类统一归并为 `""`，用于：
- `getJzpzhz`
- `getDjdjsHjByDim`
- `listYwlxByDim`
- `listZdYwlxByDim`

避免历史旧数据继续按 `"其他分类"` 单独成组，与新口径并存。

### 3.4 汇总标记更新兼容
- `pzhzJzbjXg()` 中对空 `ywfl` 维度补充兼容：
  - `ywfl IS NULL`
  - `TRIM(ywfl) = ''`
  - `ywfl = '其他分类'`

避免新口径汇总后，旧口径明细记录漏更新 `hzpzh/jzbj`。

### 3.5 测试与文案
- `VoucherSummaryDisplaySupportTest` 更新断言：
  - `null + 归集业务 + null` 预期为 `归集业务`
  - `null + null + null` 预期为 `""`
- 同步修正 DTO 注释与 YML 配置注释，去掉“缺失时为其他分类”的旧文案。
