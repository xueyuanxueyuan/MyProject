# 20260608-一户通接口调用日志查询开发记录

## 1. 目标
- 参考 `zjlog.vue` 为一户通补齐“接口调用日志查询”能力。
- 支持前端按方向、银行、接口代码、通信标识号、申请号、协议号、时间范围检索。
- 支持点击列表行查看发送报文与返回报文。

## 2. 实现思路
1. 后端沿用现有 `YhtAuditController` / `YhtLogService` 审计查询链路，不新开重复接口。
2. 对查询 DTO 增加 `current/size` 兼容字段，适配前端 `x-table` 分页参数。
3. 对服务查询补齐 `mesgId/reqId/protocolNo` 过滤条件。
4. 对响应 DTO 和详情接口补齐 `jsbw/fhbw` 报文字段透出。
5. 前端新增 `yht-log.vue` 页面，复用 `x-table + 双栏报文详情 + 复制` 交互模式。
6. 在现有一户通三张入口页增加“接口日志查询”跳转按钮。

## 3. 校验结果
- 前端 `GetDiagnostics`：`yht-log.vue`、`router/index.js` 无诊断错误。
- 后端 Java 语法诊断：本地 IDE 仅提示“non-project file”，未发现语法错误。
- Maven 定向单测：未完成执行，受当前仓库镜像配置影响，依赖 `com.tienon:refbdcutil:1.0` 被 `maven-default-http-blocker` 拦截。

## 4. 风险说明
- 当前环境未完成 Maven 依赖解析，因此后端单测属于“因环境阻塞未验证完成”。
- 一户通日志列表仍按审计口径展示，不包含住建部日志中的 `sendseqno/recieveseqno` 字段。
