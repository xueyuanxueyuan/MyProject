## 5. 验证清单（研发完成后必须给证据）

| 验证场景 | 预期结果 |
|---|---|
| 同 `ywlx`、不同 `yhzhhm` | 产生 2 张汇总凭证，且 `hzpzh` 不同 |
| 不同 `ywlx`、同 `ywfl` | 产生 1 张汇总凭证 |
| 同一 `hzpzh` 抽样核对 | 其明细凭证的 `yhzhhm/ywfl` 必须一致 |
| 摘要生成 | 优先取业务分类名称，分类名称缺失再回退 |
| 取消汇总 | 汇总凭证删除、明细回退正确、断号行为符合原需求 |
| 导出 | 列头与数据符合新口径 |
| 配置开关切换 | 新旧汇总路径可控切换 |
