# 资金使用预算组原型与总表行化同步记录

## 1. 本轮背景

预算组最新定版口径已经调整为：

- 总表采用 `主表 + 总表明细行` 模型
- 附表继续采用 `一机构一行固定字段` 模型
- 前端总表应直接消费后端返回的 `details` 数组
- 前端附表继续对机构明细做 Pivot 展示

因此，原型文件 `index.html` 中“资金使用预算”模块需要从旧的“前端汇总拼装总表字段”改为“总表行数组直渲染”。

## 2. 本次改动文件

- 原型文件：
  - [index.html](file:///home/source/Jetbrains/Probject/Gjj/doc/操作记录/20260601-资金预决算及执行情况-交互原型/index.html)

## 3. 关键同步内容

### 3.1 总表 Mock 数据结构调整

原总表原型仍在使用前端本地配置项加汇总结果拼装页面行数据。

本轮调整后，原型内部改为模拟真实后端返回结构：

- `budgetZbData`
  - 主表信息
  - `details` 明细数组
- `budgetFbData`
  - 主表公共信息
  - `details` 机构附表明细数组

其中总表 `details` 每一项包含：

- `HANGXH`
- `FLMC`
- `XMBM`
- `XMMC`
- `SFGS`
- `SNYSS`
- `SNSJS`
- `BNYSS`
- `WSNSJBL`

## 3.2 总表渲染方式调整

总表页签从原来的：

- 页面内按字段配置生成行
- 再拼接上年预算、上年实绩和本年预算

改为：

- 先根据附表明细汇总生成 `budgetZbData.details`
- 前端直接按 `hangxh` 排序渲染 `details`
- 比率行按百分比格式展示
- `SFGS = 1` 的行使用公式色块

这使总表原型与最新接口设计保持一致。

## 3.3 附表保持不变的部分

本轮没有推翻附表模型，仍保持：

- 一机构一行固定字段
- 前端按机构 Pivot 为横向列
- 分中心仅能编辑本机构 6 个输入字段
- 自动带入项、公式项、比率项继续只读

## 3.4 为什么附表不改成数据行

本轮再次确认，附表不改为“一机构一项目一行”，原因是：

- 预算组附表的核心操作是“分中心填本机构一组字段”
- 固定字段模型更符合此前确认的“不过度模板化”原则
- 若附表也行化，接口、校验、前端 Pivot 和导出复杂度都会明显上升

因此本轮继续执行已确认主方案：

1. 总表行化
2. 附表固定字段

## 4. 本轮结果

完成后，预算组原型的数据链路变为：

1. 分中心编辑附表机构字段
2. 原型重算附表公式值
3. 原型按附表汇总生成总表 `details`
4. 总表页签直接展示 15 行明细数组

这样，当前原型已与最新预算组详细设计中的接口口径保持一致。
