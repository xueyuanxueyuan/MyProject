# 20260705-UU加速器本机桥接探测与启动记录

## 1. 背景

用户要求通过 `cli-anything-local-tools` 技能打开本机 `UU加速器`，并尝试为 `Dota` 执行加速。

本次处理遵循“先探测、后调用、再留痕”的本机工具桥接流程。

## 2. 探测结果

### 2.1 安装信息

通过卸载注册表项确认本机已安装：

- 软件名称：`UU加速器`
- 软件版本：`6.11.1.632`
- 启动器路径：`C:\Program Files (x86)\Netease\UU\uu_launcher.exe`

### 2.2 可执行文件

在安装目录中确认存在以下关键文件：

- `C:\Program Files (x86)\Netease\UU\uu_launcher.exe`
- `C:\Program Files (x86)\Netease\UU\uu_agent.exe`
- `C:\Program Files (x86)\Netease\UU\5226\uu.exe`

### 2.3 命令能力

已尝试：

```powershell
& 'C:\Program Files (x86)\Netease\UU\uu_launcher.exe' --help
```

结论：

- 未返回可读帮助文本
- 未检出稳定的协议注册信息
- 说明该工具当前更接近“桌面 GUI 程序”，而不是可复用的 CLI 工具

## 3. 启动结果

已执行：

```powershell
Start-Process 'C:\Program Files (x86)\Netease\UU\uu_launcher.exe'
```

并观察到相关进程存在：

- `uu`
- `uu_launcher`

可判定 `UU加速器` 已被成功拉起。

## 4. 自动化边界

虽然已能稳定探测与启动 `UU加速器`，但本次未发现：

- 可直接指定 `Dota` 的命令行参数
- 可稳定调用的本地 API / 协议
- 可验证成功的无头模式

尝试读取桌面自动化控件树时，仅能获得有限的 WebView 可访问节点，尚不足以安全、稳定地自动完成“搜索 Dota 并点击加速”这一 GUI 操作。

因此，本次能力边界确认如下：

- 可稳定完成：探测安装、确认版本、拉起应用
- 暂不可稳定完成：在桌面应用内自动完成 `Dota` 加速按钮点击

## 5. 产出

已新增单工具桥接说明：

- `doc/技能库/cli-anything-local-tools/UU加速器-TOOL-HARNESS.md`

后续若需要继续深挖，可从以下方向继续：

1. 分析 `userdata.db` / WebView 存储，寻找游戏检索与启动参数
2. 研究 `UU加速器` 是否存在隐藏协议、启动参数或本地服务端口
3. 在明确 UI 结构后，再决定是否补充“受控 GUI 自动化”方案
