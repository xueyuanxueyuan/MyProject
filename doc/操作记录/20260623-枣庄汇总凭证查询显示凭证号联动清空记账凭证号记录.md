# 20260623-枣庄汇总凭证查询显示凭证号联动清空记账凭证号记录

## 1. 需求目标

- 页面：`zaozhuang/WebstormProjects/capinfo-gjj-frontend-jshs-gm/src/components/cwhs/sspzhz/hzpzcx.vue`
- 目标：当用户在汇总凭证查询页面手动清空或修改“显示凭证号”查询条件时，同步将 `jzpzh` 查询条件清空。

## 2. 现状说明

- 页面查询表单中：
  - “显示凭证号”使用 `config.condition.xspzh`
  - 记账凭证号相关条件由 `config.condition.jzpzh`、`config.condition.pzbhx`、`config.condition.pzbhd` 承接
- 原实现中，“显示凭证号”输入框只有 `v-model`，没有在用户修改时同步清空记账凭证号条件。

## 3. 本次改造

- 在“显示凭证号”输入框上新增：

```vue
@input="handleXspzhInput"
```

- 新增方法：

```js
handleXspzhInput() {
  this.config.condition.jzpzh = null
  this.config.condition.pzbhx = null
  this.config.condition.pzbhd = null
}
```

## 4. 改造效果

- 用户手动修改“显示凭证号”时，会同步清空记账凭证号相关条件。
- 用户手动清空“显示凭证号”时，也会同步清空记账凭证号相关条件。
- 路由自动带参回填场景不依赖输入事件，因此不会被误清空。

## 5. 验证情况

- 已执行静态诊断，未发现新增错误。
- 已人工复核改动点，联动范围仅限 `hzpzcx.vue` 当前查询表单。
