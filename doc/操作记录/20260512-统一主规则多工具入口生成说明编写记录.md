# 统一主规则多工具入口生成说明编写记录

## 1. 目标
- 在已有《统一主规则通用工具链接入说明》的基础上，再补一份“如何生成各工具入口文件”的说明。
- 解决跨项目、跨工具迁移时，工具根据 `doc` 标准源生成入口文件容易漏规则的问题。

## 2. 新增文档
- `doc/项目规范/统一主规则-多工具入口生成说明.md`

## 3. 文档覆盖范围
- 标准源与生成物定义
- 必须保留的默认调用方式
- 各入口文件的最小保留内容
- 技能入口生成规则
- 生成顺序
- 防遗漏检查清单
- 可直接交给其他工具的生成指令

## 4. 设计原则
- `doc/项目规范/统一主规则-通用工具链接入说明.md` 是唯一标准源。
- 各工具入口从标准源派生，不反向覆盖标准源。
- 入口写薄，标准源写全。
- 明确“自动生成入口文件”与“仅在行为上接入标准源”之间的真实性边界。

## 5. 预期效果
- 后续在其他工具或其他项目中，只要先拿到 `doc` 下的标准源与生成说明，就更容易稳定复现当前这套规则体系。
- 即便某工具无法自动生成入口文件，也可以直接使用标准源；若具备生成能力，则可按本说明稳定落盘。
