# 结算服务调用一户通批量业务参数透传修复记录

## 1. 背景

前置排查已确认：

1. 直接调用一户通批量接口时，外部 DTO 到内部 DTO 的映射基本完整；
2. 缺口集中在 `YhtYwServiceImpl` 的业务适配层；
3. `addFkywPlfkjy(...)` 未透传批量明细；
4. `addSkywPlskjy(...)` 漏传 `feeNo`、`fileName`、`bankId`、`protocolNo`、`remark` 等关键字段。

## 2. 修复目标

本次修复目标是让“结算服务 -> 一户通批量内部请求 DTO”这层参数组装完整起来，至少满足当前一户通批量校验器和报文构建器的字段要求。

## 3. 实施内容

### 3.1 批量付款修复

在 `YhtYwServiceImpl.addFkywPlfkjy(...)` 中补齐：

1. `feeNo = 00001`
2. `fileName`：优先取 `mxFilepath` 文件名，兜底 `batchNo + ".txt"`
3. `details`
4. 每条明细补齐：
   - `serialNum`
   - `detailSeq`
   - `cdtrActId`
   - `cdtrName`
   - `amount`
   - `bankId`
   - `bankType`
   - `use`
   - `remark`

### 3.2 批量收款修复

在 `YhtYwServiceImpl.addSkywPlskjy(...)` 中补齐：

1. `feeNo = 00001`
2. `fileName`
3. 每条明细补齐：
   - `detailSeq`
   - `bankId`
   - `protocolNo`
   - `use`
   - `remark`
