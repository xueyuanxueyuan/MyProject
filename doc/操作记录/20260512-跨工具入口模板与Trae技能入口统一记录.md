# 跨工具入口模板与 Trae 技能入口统一记录

## 1. 目标
- 产出以 `CLAUDE.md` 为唯一长正文主源的跨工具入口同步模板。
- 统一 `.trae/skills/*/SKILL.md` 的入口骨架，减少风格漂移和重复表达。
- 让技能入口只保留“适用场景 + 核心要求 + 主源位置 + 使用提示”，把长正文留在 `doc/技能库`。

- `doc/通用模板/技能入口统一模板.md`

## 4. 统一后的模板骨架
- frontmatter：`name` + `description`
- 标题：技能名
- `## 适用场景`
- `## 核心要求`
- `## 主源位置`
- `## 使用提示`
- 对高风险或固定流程技能，保留 `## 标准流程` 或 `## 专项细则`

## 5. 本次处理原则
- 不重复 `CLAUDE.md` 的统一主规则全文。
- 不把 `doc/技能库` 的完整案例、长篇原理或一次性叙事搬回 `.trae/skills`。
- 保留本地桥接和高风险技能的必要补充，例如：
  - `using-superpowers` 的本地桥接定位
  - `pingcode-ui-filter` 的稳定成功路径
  - `zzgjj-login` 的验证码人工处理要求
  - `settlement-window-verifier` 的浏览器接管前提

## 6. 效果
- 后续新增或改造技能时有统一模板可依。
- `.trae/skills` 的入口更短、更稳、更易维护。
- 跨工具入口也有统一的“主源 + 薄入口”同步规范，便于后续扩展到 `AGENTS.md`、`GEMINI.md` 等场景。
- 后续将原 `Trae` 专用模板泛化后，可直接复用到其他工具的技能入口或桥接文档场景。
