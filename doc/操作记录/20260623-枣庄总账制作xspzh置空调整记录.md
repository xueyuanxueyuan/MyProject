# 20260623-枣庄总账制作xspzh置空调整记录

## 1. 需求说明

- 目标文件：`zaozhuang/IdeaProjects/capinfo-gjj-busi-jshs/capinfo-gjj-busi-cwhs-jzgl/capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi/src/main/java/cn/capinfo/gjj/busi/cwhs/jzgl/busi/service/impl/CwhsServiceImpl.java`
- 目标方法：`makeZbZz()`
- 需求：科目总账表制作时，`xspzh` 字段需要置空。

## 2. 问题定位

- 总账制作过程中，账表最终统一通过 `saveZb()` 落表。
- 原逻辑中，`saveZb()` 会直接执行：

```java
zb.setXspzh(xspzh);
```

- 因此当总账构建过程中某些行传入了 `xspzh` 值时，会被原样落入总账表。

## 3. 本次调整

- 在 `saveZb()` 中增加总账口径收口：

```java
zb.setXspzh("zz".equals(bbbh) ? "" : xspzh);
```

## 4. 调整效果

- 当 `bbbh = "zz"` 时，表示当前写入的是总账表数据：
  - `xspzh` 强制置空
- 非总账账表仍保留原有 `xspzh` 写入逻辑，不受本次调整影响。

## 5. 验证情况

- 已执行静态诊断，未发现本次改动引入的新错误。
- 已复核差异，确认改动点仅 1 处，影响范围限定在总账落表环节。
