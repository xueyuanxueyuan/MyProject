# agency-agents-zh 技能同步对比

## 对比范围

- `doc/技能库/agency-agents/SKILL.md`
- `doc/技能库/agency-agents/AGENTS_CATALOG.md`
- `.trae/skills/agency-agents/SKILL.md`

## 变更前

### 技能主文档

- 主要是简化版说明
- 只列出少量常用角色
- 偏向“你点名我切换”的单一用法
- 引用了不存在的 `codeworkfiles/agency-agents-source/`

### 速查表

- 只有少量角色清单
- 缺少“任务 -> 角色”的选择路径
- 没有 Trae 实际使用建议

### Trae 技能镜像

- 内容与主源不完全同步
- 未体现 `agency-agents-zh` 的当前规模和中国场景扩展

## 变更后

### 技能主文档

- 升级为“选角与角色适配指南”
- 增加 `215` 角色、`18` 部门、`50` 中国原创角色的基线说明
- 增加选角流程、Trae 使用要点、常用角色分组和口令示例
- 去掉失效路径，改为引用真实主源与外部参考仓库

### 速查表

- 改为“任务类型 -> 主推荐角色 -> 备选角色 -> 适用说明”
- 新增 `最小变更工程师`、`MCP 构建器`、`飞书集成开发工程师`、`政务数字化售前顾问` 等角色
- 新增 Trae 精选安装与显式点名建议

### Trae 技能镜像

- 同步为简洁但一致的版本
- 保留角色推荐、Trae 约束、常用角色分组

## 结论

这次同步把本地 `agency-agents` 从“少量角色口令说明”提升为“基于 `agency-agents-zh` 的本地选角技能”，更适合当前仓库在 Trae 中按场景选角色、切视角和控制触发方式。
