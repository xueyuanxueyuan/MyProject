# 20260707-枣庄汇总凭证辅助核算明细原明细展示调整记录

## 背景

枣庄项目财务核算服务中，汇总凭证辅助核算明细查询 `listHzpzFzmx` 需要展示原明细凭证的辅助核算明细，不再按汇总凭证口径合并展示。

## 调整范围

- 服务模块：`capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi`
- 调整文件：`PzFzmxDOMapper.xml`
- 查询方法：`listHzpzFzmx`

## 调整内容

原 SQL 对 `cwhs_pz_fzmx` 按 6 组辅助核算维度 `flbm1/fzxdm1` 至 `flbm6/fzxdm6` 做 `GROUP BY`，金额字段使用 `SUM`，且将返回的 `jzpzh`、`flbh`、`zhaiyao` 改写为汇总凭证分录信息。

本次调整为直接返回 `cwhs_pz_fzmx` 原明细记录字段，保留以下过滤条件：

- 按当前中心、账套过滤
- 按汇总凭证关联的原始记账凭证号集合过滤
- 按汇总分录科目过滤
- 通过 `cwhs_jzpz` 校验原始凭证分录借贷方向
- 过滤未删除辅助核算明细

排序改为按 `jzrq`、`jzpzh`、`flbh`、`id` 展示原明细顺序。

## 验证结果

执行命令：

```bash
mvn -s settings-tsp.xml -pl capinfo-gjj-busi-cwhs-jzgl/capinfo-gjj-busi-cwhs-jzgl-basic-svc-busi -am -DskipTests compile
```

结果：`BUILD SUCCESS`。

补充说明：直接执行不带 `settings-tsp.xml` 的 Maven 编译时，因默认 HTTP 仓库镜像被 Maven 阻断导致依赖解析失败；改用项目提供的 `settings-tsp.xml` 后编译通过。
