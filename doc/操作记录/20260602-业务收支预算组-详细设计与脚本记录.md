# 业务收支预算组详细设计与脚本记录

## 1. 本轮目标

在完成业务收支预算组首版方案设计后，继续补齐以下 3 类交付物：

1. 前端原型设计
2. 详细设计与数据库设计
3. 独立达梦执行脚本

## 2. 本轮依据

本轮主要依据以下资料继续深化：

- Excel 原表第 4、5 张：
  - 住房公积金业务收支预算总表
  - 住房公积金业务收支预算附表
- 已确认的业务收支预算组首版设计
- 资金使用预算组的成熟交付结构
- 参考脚本中的表名风格：
  - `CWHS_ZJYJS_YWSZYSZB`
  - `CWHS_ZJYJS_YWSZYSFB`

## 3. 本轮关键决策

### 3.1 总表继续采用行化

总表不展开为大量固定业务字段，而是采用：

- `CWHS_ZJYJS_YWSZYSZB`
- `CWHS_ZJYJS_YWSZYSZMX`

原因：

- 总表天然是按行展示
- 与资金使用预算组保持一致
- 更适合前端 `details` 数组和导出

### 3.2 附表保持一机构一行固定字段

附表不改成“一机构一项目一行”，仍采用：

- `CWHS_ZJYJS_YWSZYSFB`

原因：

- 分中心本质是在填一组固定业务收支字段
- 保存接口更清晰
- 前端仍可用 Pivot 还原 Excel 横向机构列

### 3.3 第 5 行国债投资收入保持不适用

本轮继续按当前已确认口径处理：

- 数据库存空值
- 前端显示 `-`
- 不允许人工填写
