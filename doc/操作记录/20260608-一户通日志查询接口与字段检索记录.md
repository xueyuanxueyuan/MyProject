# 一户通日志查询接口与字段检索记录

- 检索范围：`capinfo-gjj-busi-zjjs-ywgl` 后端模块，一户通审计日志、住建部接口日志、银企直联日志。
- 关注字段：`jsbw`、`fhbw`、`sendseqno`、`recieveseqno`、`createdTime`。
- 结论摘要：
  - 传统日志表 `zjjs_zj_log` 与 `zjjs_zj_yq_log` 已提供分页查询接口，响应字段覆盖 `jsbw/fhbw/sendseqno/recieveseqno/createdTime`。
  - 一户通审计模块 `zjjs_zj_yht_log` 已提供 `/yht/audit/query`、`/detail/mesgId/{mesgId}`、`/trace/reqId/{reqId}`、`/trace/protocolNo/{protocolNo}`，但当前查询条件与响应字段不包含 `sendseqno/recieveseqno`，响应也未直接返回 `jsbw/fhbw` 原文。
  - 若前端要按 `sendseqno/recieveseqno` 检索一户通日志，或直接查看原始报文，当前存在接口缺口，需要扩展 DTO/DO/查询条件与展示字段。
