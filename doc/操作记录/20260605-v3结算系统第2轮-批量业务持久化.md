## 四、设计决策

| 决策 | 说明 |
|------|------|
| 批次表使用拼音名 | `zjjs_zj_fkpc`（付款批次）/ `zjjs_zj_skpc`（收款批次）|
| 批次仅持久化头信息 | 明细已各自持久化在 `zjjs_zj_dbfk` / `zjjs_zj_dbsk` 表，批次表仅存聚合统计 |
| 批次状态自动推导 | `deriveBatchStatus()` 根据成功/失败/待处理数推断：YCL/SB/BFYC/BCL |
| HSDWDM 从首个明细提取 | `deriveHsdwdm()` 从 items 列表取第一个非空值 |
