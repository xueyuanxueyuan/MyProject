# 20260705-UU加速器隐藏CLI发现与DOTA2加速记录

## 1. 背景

在上一轮 `UU加速器` 本机桥接探测中，只确认了桌面 GUI 可被拉起，尚未找到稳定的命令行入口，因此未能可靠完成 `Dota` 自动加速。

本轮续探继续沿“可验证自动化”方向推进，目标是避免 GUI 盲操，优先寻找更稳定的本机调用路径。

## 2. 关键发现

在目录 `C:\Users\Sour\AppData\Roaming\Netease\UU` 下发现：

- `netease-uu-booster.7z`

通过 `7za.exe` 查看压缩包内容，确认其内部包含：

- `netease-uu-booster\bin\uu-cli.exe`
- `netease-uu-booster\README.md`
- `netease-uu-booster\reference\commands.md`
- `netease-uu-booster\examples\start-game.md`

这说明当前 UU 客户端实际上内置了一套隐藏 CLI 能力，可通过本地 HTTP 服务控制加速器，而非只能依赖 GUI 操作。

## 3. 验证步骤

### 3.1 解压 CLI 与文档

将压缩包中的 CLI 与文档解压到临时目录：

- `C:\Users\Sour\AppData\Local\Temp\uu-booster-docs\`

### 3.2 环境检测

执行：

```powershell
& 'C:\Users\Sour\AppData\Local\Temp\uu-booster-docs\netease-uu-booster\bin\uu-cli.exe' --json doctor
```

返回结果表明：

- `installed = true`
- `running = true`
- `serviceAvailable = true`
- `status = ready`
- `servicePort = 2013`

说明 UU 的本地控制服务已就绪，可以继续执行游戏搜索与加速控制。

### 3.3 搜索 Dota

执行：

```powershell
& 'C:\Users\Sour\AppData\Local\Temp\uu-booster-docs\netease-uu-booster\bin\uu-cli.exe' --json games --search 'Dota 2'
```

返回两个候选：

- `567b2397a26c7514260263b6` -> `dota2国际服`
- `518cbd94d5a35c9a74000008` -> `dota2`

随后根据用户选择，确认目标为：

- `dota2`
- `gameId = 518cbd94d5a35c9a74000008`

### 3.4 启动加速

执行：

```powershell
& 'C:\Users\Sour\AppData\Local\Temp\uu-booster-docs\netease-uu-booster\bin\uu-cli.exe' --json start --id 518cbd94d5a35c9a74000008
```

返回：

```json
{
  "success": true,
  "data": {
    "gameId": "518cbd94d5a35c9a74000008",
    "message": "Booster started successfully"
  }
}
```

### 3.5 状态校验

第一次校验结果：

- `status = starting`

等待数秒后再次校验：

```powershell
& 'C:\Users\Sour\AppData\Local\Temp\uu-booster-docs\netease-uu-booster\bin\uu-cli.exe' --json status --id 518cbd94d5a35c9a74000008
```

返回结果确认：

- `gameName = DOTA2`
- `status = boosting`
- `nodeName = 无锡联通13208`
- `nodeMode = 进程模式`
- `ping = 29`
- `packetLoss = 0.0`

## 4. 结论

本次已成功通过隐藏 CLI 路径完成 `DOTA2` 加速闭环：

1. 发现隐藏 CLI
2. 验证 UU 服务就绪
3. 搜索目标游戏
4. 启动加速
5. 校验进入 `boosting`

因此，`UU加速器` 在当前环境中不应再被定义为“仅 GUI 可控工具”，而应优先按“隐藏 CLI + JSON 输出 + 本地 HTTP 服务”的桥接模型处理。
