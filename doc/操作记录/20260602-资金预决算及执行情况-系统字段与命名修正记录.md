# 资金预决算及执行情况 - 系统字段与命名修正记录

## 1. 本次修正原因
- 用户重新给出了最终确认版系统字段清单，明确要求以这 15 个字段作为统一标准，而不是之前误用的 13 个字段。
- 用户明确要求把这 15 个系统字段同步写入提示词，避免后续继续按旧口径生成脚本或文档。
- 用户继续要求脚本中的表名和字段名全部改为大写，且不能带引号。

## 2. 最终确认的 15 个系统字段
- `ID BIGINT NOT NULL`
- `ZXBH NVARCHAR(15) NOT NULL`
- `REVISION INT NOT NULL`
- `CREATOR NVARCHAR(100)`
- `CREATED_TIME TIMESTAMP(0) NOT NULL DEFAULT CURRENT_TIMESTAMP()`
- `UPDATOR NVARCHAR(100)`
- `UPDATED_TIME TIMESTAMP(0)`
- `JBJGBH NVARCHAR(30) NOT NULL`
- `JBJGMC NVARCHAR(90) NOT NULL`
- `WDBH NVARCHAR(30)`
- `WDMC NVARCHAR(90)`
- `QDLX NVARCHAR(10)`
- `QDBM NVARCHAR(16)`
- `DEL_FLAG NVARCHAR(1) NOT NULL DEFAULT '0'`
- `HSJGBH NVARCHAR(10) NOT NULL DEFAULT '01'`

## 3. 差异对比
- 废弃旧口径：`CREATE_BY / CREATE_NAME / UPDATE_BY / UPDATE_NAME / REMARK / TENANT_ID`
- 恢复参考口径：`ZXBH / CREATOR / CREATED_TIME / UPDATOR / UPDATED_TIME / JBJGBH / JBJGMC / WDMC / QDLX / QDBM`
- 默认值口径：`CREATED_TIME DEFAULT CURRENT_TIMESTAMP()`、`DEL_FLAG DEFAULT '0'`、`HSJGBH DEFAULT '01'`
- 命名统一：所有表名、字段名、索引引用的表名全部改为大写
- 引号规范：DDL 中不再使用反引号或双引号

## 4. 本次落地范围
- 已修改独立模型达梦脚本中的全部 16 张业务表，统一替换为这 15 个系统字段。
- 已修改详细设计文档中的系统字段说明与 DDL 示例。
- 已把这 15 个系统字段写入：
  - `doc/提示词/Gjj项目组前后端项目开发提示词.md`
  - `doc/提示词/Gjj项目组开发提示词.md`

| 调整项 | 修正前 | 修正后 |
