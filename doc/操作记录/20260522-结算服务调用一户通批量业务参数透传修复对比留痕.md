# 结算服务调用一户通批量业务参数透传修复对比留痕

## 1. 变更文件

1. `capinfo-gjj-busi-zjjs-ywgl-basic-svc-busi/.../YhtYwServiceImpl.java`
2. `capinfo-gjj-busi-zjjs-ywgl-basic-svc-busi/.../YhtYwService.java`

## 2. 修复前

### 2.1 批量付款

修复前 `addFkywPlfkjy(...)` 只透传了：

1. `batchNo`
2. `bizType`
3. `corpAcctNo`
4. `jbjgbh`
5. `yhdm`

缺少：

1. `feeNo`
2. `fileName`
3. `details`
4. 所有批量付款明细字段

### 2.2 批量收款

修复前 `addSkywPlskjy(...)` 只透传了部分字段：

1. `serialNum`
2. `dbtrActId`
3. `dbtrActName`
4. `cdtrActId`
5. `cdtrName`
6. `amount`
7. `bankType`

缺少：

1. `feeNo`
2. `fileName`
3. `detailSeq`
4. `bankId`
5. `protocolNo`
6. `use`
7. `remark`

## 3. 修复后

1. `feeNo = 00001`

3. `details`

2. `detailSeq`
3. `cdtrActId`
4. `cdtrName`
5. `amount`
6. `bankId`
7. `bankType`

### 3.2 批量收款

1. `feeNo = 00001`
2. `fileName`

每条明细新增透传：

1. `detailSeq`
2. `bankId`
3. `protocolNo`
4. `use`
5. `remark`

## 5. 对外效果

修复后，结算服务在路由一户通批量业务时，能把当前业务层已经掌握的核心参数继续传到一户通内部批量请求对象中，避免因为适配层丢字段导致：

1. 批量明细为空
2. 明细开户行号缺失
3. 批量协议号缺失
4. 文件名缺失
5. 备注信息缺失
