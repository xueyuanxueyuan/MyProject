# Git 提交规范归属修正记录

## 1. 变更目标
- 将 Git 提交规范从“项目专属规范”修正为“跨项目通用规范”。
- 保证提交规则挂载在全局主规则与通用接入文档中，而不是只落在 `Gjj` 项目组专属规范中。

## 2. 变更依据
- 参考模板：`doc/通用模板/Git提交描述模板.md`
- 参考现有协同规范：`doc/项目规范/Gjj项目组智能体协同开发规范.md`
- 对齐口径：提交规范与模板要求

## 3. 修正前现状
- `doc/通用模板/Git提交描述模板.md` 已是通用模板主源。
- Git 提交规范曾被补充进 `doc/项目规范/Gjj项目组开发规范.md`，造成其看起来像 `Gjj` 项目专属约束。
- `CLAUDE.md` 与 `doc/项目规范/统一主规则-通用工具链接入说明.md` 中此前未显式声明该规则的全局归属。

## 4. 本次修正内容
- 在 `CLAUDE.md` 中补充 Git 提交规范，明确其为跨项目通用规范。
- 在 `doc/项目规范/统一主规则-通用工具链接入说明.md` 中同步补充该规则，便于其他工具按统一主规则接入。
- 从 `doc/项目规范/Gjj项目组开发规范.md` 中移除这段 Git 提交规范，避免继续表现为项目专属规则。
- 统一保留以下模板口径：

```text
AI辅助：true
AI工具：Trae

1. 改了什么
2. 为了解决什么问题
```

- 提交说明必须具体，不得使用空泛描述。
- 统一引用 `doc/通用模板/Git提交描述模板.md` 作为模板主源。

## 5. 对比说明
- 修正前：Git 提交规则错误地挂在 `Gjj` 项目组专属规范下，归属层级不准确。
- 修正后：Git 提交规则上提至全局主规则与通用接入文档，项目专属规范不再重复承载该通用约束。
