# 通知存款接口实现记录

## 1. 背景
- 需求来源：`doc/需求文档/通知存款接口.md`
- 参考实现：`YwglController` 中现有活期转定期 `hqZdq`、定期支取 `dqckzq`、定期转存方式设定 `dqckZcfssd`，以及已存在的 `BDC121/BDC122` 通知存款查询链路。
- 结论：文档中共定义 4 个待补接口，分别为 `BDC117`、`BDC118`、`BDC119`、`BDC120`；其中 `BDC121/BDC122` 已在仓库中实现，无需重复开发。

## 2. 本次实现范围
- `BDC117` 活期转通知存款
- `BDC118` 通知存款支取
- `BDC119` 通知存款支取设定
- `BDC120` 通知存款支取通知取消

## 3. 设计思路
- 复用现有业务接口层风格：沿用 `api/dto/req`、`api/dto/resp`、`WbjkService`、`YwglController`、`YwglFeignClient` 的接入方式，不额外新增底层报文 DTO 模式。
- 报文发送方式复用 `WbjkServiceImpl`：按 `hqZdq`/`dqckzq` 的模式组装 `ReqHead`、构建请求 XML、调用 `zjbClient.invokeFront`、解析住建部返回。
- 返回结构兼顾通用与差异：
  - `TzckRespDTO` 统一承载 `fhzt`、`fhxx`、`yhjslsh`、`rbk1`、`rbk2`
  - `HqZtzckRespDTO` 在此基础上补充通知存款账号、户名、册号、笔号
- 为避免请求字段组装回归，新增 `WbjkServiceImplNoticeDepositMappingTest`，将 `BDC117~BDC120` 的请求字段映射固化为单测目标。

## 4. 关键实现点
- 新增请求 DTO：
  - `HqZtzckReqDTO`
  - `TzckzqReqDTO`
  - `TzckZqsdReqDTO`
  - `TzckZqtzQxReqDTO`
- 新增响应 DTO：
  - `TzckRespDTO`
  - `HqZtzckRespDTO`
- 新增 Controller 接口：
  - `/hqZtzck`
  - `/tzckzq`
  - `/tzckZqsd`
  - `/tzckZqtzQx`
- 新增 `WbjkService` 与 `WbjkServiceImpl` 方法，并在 `FeignClient/Fallback/FallbackFactory` 中同步补齐。
- 在 `WbjkServiceImpl` 中新增 4 个请求报文映射方法：
  - `buildBdc117ReqMap`
  - `buildBdc118ReqMap`
  - `buildBdc119ReqMap`
  - `buildBdc120ReqMap`

## 5. 字段映射说明
- `BDC117`：
  - 活期账号/户名 -> `ActivedAcctNo` / `ActivedAcctName`
  - 通知账号/户名 -> `FixedAcctNo` / `FixedAcctName`
  - 通知金额 -> `NoticeDepositAmt`
  - 存期 -> `DepositPeriod`
- `BDC118`：
  - 通知账号/户名 -> `FixedAcctNo` / `FixedAcctName`
  - 支取金额 -> `DrawAmt`
  - 支取方式 -> `DrawType`
  - 通知金额 -> `NoticeDepositAmt`
  - 转入活期账号/户名 -> `ActivedAcctNo` / `ActivedAcctName`
- `BDC119`：
  - 通知账号/户名 -> `FixedAcctNo` / `FixedAcctName`
  - 册号/笔号 -> `BookNo` / `BookListNo`
  - 支取金额 -> `DrawAmt`
  - 通知设定日期 -> `NoticeDrawSetDate`
  - 当前余额 -> `Balance`
- `BDC120`：
  - 通知设定序号 -> `NoticeSetSerialNo`
  - 通知标志 -> `NoticeFlag`
  - 通知设定日期 -> `NoticeDrawSetDate`
  - 通知支取日期 -> `NoticeDrawDate`
  - 支取金额 -> `DrawAmt`
  - 通知余额 -> `Balance`
