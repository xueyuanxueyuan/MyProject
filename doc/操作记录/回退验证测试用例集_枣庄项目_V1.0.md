# 回退验证测试用例集_枣庄项目_V1.0

## 1. 目的
- 用于验证“凭证汇总改造”相关提交在执行回退后，系统行为是否与目标版本一致。
- 覆盖代码回退、配置回退、功能回退和数据库联动回退后的关键业务场景。

## 2. 适用范围
- 仓库：`zaozhuang/IdeaProjects/capinfo-gjj-busi-jshs`
- 分支：`zaozhuang/dev-凭证汇总修改`
- 功能范围：
  - 凭证主表/汇总凭证主表新增字段
  - 生成链路 `yhzhhm/ywfl` 注入
  - 汇总口径 `ywlx -> yhzhhm + ywfl`
  - 枣庄区域灰度配置 `voucher.*`

## 3. 执行前置
- 已明确本次回退目标：第 4 笔 / 第 3+4 笔 / 全量 4 笔。
- 已创建备份分支。
- 已完成代码回退并推送到测试分支。
- 已准备一组可复现样例数据：
  - 样例 A：同 `ywfl`、不同 `ywlx`
  - 样例 B：同 `ywlx`、不同 `yhzhhm`
  - 样例 C：`codeZl1` 缺失
  - 样例 D：历史空值 `yhzhhm/ywfl`
