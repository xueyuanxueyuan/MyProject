### 4.2 字典映射工具
```java
private String mapYwfl(String xtlx, String ywlx) {
    R<CsSjzdDTO> r = ParamUtil.getCode(Constants.HSDWDM, xtlx, "ywlx", ywlx);
    if (r != null && r.getIsSuccess() && r.getData() != null
            && StrUtil.isNotBlank(r.getData().getCodeZl1())) {
        return r.getData().getCodeZl1();
    }
    if (mappingStrictMode) {
        throw new BizException(ResultErrorCodeEnum.FAIL.getCode(),
                "业务分类映射缺失: ywlx=" + ywlx + ", xtlx=" + xtlx);
    }
    log.warn("ywfl 映射回退 ywlx={}, xtlx={}, fallback={}", ywlx, xtlx, mappingFallbackEnable);
    return mappingFallbackEnable && StrUtil.isNotBlank(ywlx) ? ywlx : "其他分类";
}
```

### 4.4 `getJzpzhz` 改造（核心）
```xml
SELECT
    a.jzlxfl, a.xtlx, a.ywlx,
    NVL(a.yhzhhm, '其他账号') AS yhzhhm,
    NVL(a.ywfl,   '其他分类') AS ywfl,
    b.kmbh,
    sum(b.jffse) jffse, sum(b.dffse) dffse
FROM cwhs_pz a, cwhs_jzpz b
WHERE a.jzpzh = b.jzpzh AND a.jzbj = 'jz'
  AND a.ztbh = #{ztbh} AND a.jzrq = #{jzrq} AND a.zzbj = #{zzbj}
GROUP BY a.jzlxfl, a.xtlx, a.ywlx,
         NVL(a.yhzhhm,'其他账号'), NVL(a.ywfl,'其他分类'),
         b.kmbh, SIGN(b.jffse), SIGN(b.dffse)
ORDER BY NVL(a.yhzhhm,'其他账号'), NVL(a.ywfl,'其他分类'), b.kmbh
```

### 7.4 已知隐患（P1 后续跟进，不阻塞本次 P0 上线）

**用例 2 暴露**：SQL `MIN(a.ywlx)` 已经在数据库层把同 (yhzhhm, ywfl) 分组内的多个 ywlx 收敛成 1 个，Java 层 `mapYwflName` 的"组内 ywlx 字典名称一致性 WARN"实际无法触发。结果：
- ✓ **数据正确性**：yhzhhm+ywfl 维度的金额、附件数、回写全部正确；
- ✗ **摘要降级**：若同 ywfl 内多 ywlx 的 `codeNameZl1` 存在脏数据不一致，会沉默地取 `MIN(ywlx)` 的字典名，不会告警。

修复方向（P1 单独排期）：
1. 在 `zdpzhz` 前增加一次 `cwhs_pz` 反查（按 yhzhhm+ywfl+jzrq+ztbh 取 distinct ywlx 列表）传给 `mapYwflName` 做一致性校验；或
2. SQL 用 `LISTAGG/GROUP_CONCAT` 输出 ywlx 列表（受方言差异限制需评估）。
