# 20260512 AI Agent 防偷懒防撒谎全局能力落地记录

## 背景

为降低后续智能体在 Gjj 工作区中的偷懒式交付、未验证即宣告完成、凭记忆编造事实等风险，基于 `doc/设计文档/🛠️ AI Agent 防偷懒与防撒谎全场景终极实施方案 (V3.0).md` 进行仓库级落地。

## 落地内容

1. 在 `doc/技能库/anti-laziness-anti-hallucination/` 建立技能主源，沉淀使用场景、硬门禁、本地 guardrail 用法及跨项目模板
2. 在 `.trae/skills/anti-laziness-anti-hallucination/` 建立 Trae 入口，保证工作区可发现该技能
3. 在 `.trae/rules/anti-laziness-anti-hallucination.md` 增加工作区强制规则
4. 在 `.trae/rules/gjj.md` 增补“无验证不宣告完成”和“禁止占位交付”约束
5. 新增 `scripts/guardrails/agent-delivery-guardrail.sh`，提供占位痕迹扫描与真实验证入口

## 关键设计

- 不强制固定三段式输出标签，避免与当前 Trae 回复规范冲突
- 默认以“最小充分验证”为原则，防止文档类任务被整仓重构建阻塞
- 默认跳过 `doc/技能库`、`.trae/skills`、`codeworkfiles` 的占位扫描，减少规则说明文本被误判
- 需要更重验证时，统一通过 `--verify-command` 或 `--auto-verify` 显式触发

## 验证建议

```bash
bash -n scripts/guardrails/agent-delivery-guardrail.sh
scripts/guardrails/agent-delivery-guardrail.sh --scan-only scripts/guardrails/agent-delivery-guardrail.sh .trae/rules/anti-laziness-anti-hallucination.md
```

## 后续维护

- 新出现的偷懒词或占位模式，直接补充脚本正则
- 若规则覆盖过重，可在 `.trae/rules/anti-laziness-anti-hallucination.md` 中调低适用范围
- 若需要推广到其他仓库，可复用 `doc/技能库/anti-laziness-anti-hallucination/global-template.md`
