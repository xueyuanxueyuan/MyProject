# 20260623-枣庄总账跳转明细账按当日查询修正记录

## 1. 需求背景

- 页面：`zaozhuang/WebstormProjects/capinfo-gjj-frontend-jshs-gm/src/components/cwhs/zbgl/newzz.vue`
- 目标：总账页面点击详情跳转到明细账时，应只查询总账当前行对应的具体日期数据，不能把整月明细全部查出。

## 2. 问题定位

- `newzz.vue` 在跳转明细账时，实际上已经传递了当日日期：
  - `jzrqStart = row.jzrq`
  - `jzrqEnd = row.jzrq`
- 问题出在 `newmxz.vue` 的路由承接逻辑：
  - `getRouteJumpPayload()` 将路由中的精确日期转换成了月份
  - `buildPayload()` 再按月份推导为整月起止日期
- 因此最终明细账制作与查询走成了整月范围，而不是总账当前行当天范围。

## 3. 本次改造

### 3.1 保留路由跳转的精确日期

在 `newmxz.vue` 的 `getRouteJumpPayload()` 中，新增保留：

- `jzrqStart`
- `jzrqEnd`

### 3.2 路由跳转场景按精确日期构造查询参数

将 `buildPayload()` 调整为支持接收 `routeJumpPayload`。

- 普通页面查询：仍按月份推导整月起止日期
- 总账跳转场景：优先使用路由传入的精确 `jzrqStart/jzrqEnd`

### 3.3 路由跳转执行时透传精确日期

在 `tryHandleRouteJump()` 中调用：

```js
this.doMakeMxz(null, payload)
```

并在 `doMakeMxz()` 内改为：

```js
const payload = this.buildPayload(routeJumpPayload)
```

## 4. 改造效果

- 从总账点击某一日详情跳转到明细账时，仅制作并查询该日明细。
- 手工在明细账页面按月份查询时，仍保持原有整月逻辑，不受影响。
- 改动范围限定在 `newmxz.vue` 路由跳转处理链路，影响面较小。

## 5. 验证情况

- 已执行静态诊断，未发现本次改动引入的新错误。
- 已复核差异，确认总账页跳转参数本身无需改动，问题已在明细账页承接逻辑修复。
