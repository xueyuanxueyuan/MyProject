# 20260623-枣庄总账明细账按汇总凭证制作改造记录

## 1. 任务背景

- 项目范围：`zaozhuang/capinfo-gjj-busi-cwhs-jzgl`
- 改造目标：不新增接口，仅在现有 `makeZbZz`、`makeZbMxz` 制作方法内完成总账、明细账按汇总凭证口径的制作改造。
- 核心约束：所有金额统计、余额计算、发生额归集必须严格基于汇总凭证与汇总凭证分录，不再直接以记账凭证明细作为账表制作口径。

## 2. 汇总凭证口径梳理

### 2.1 主数据来源

- 汇总凭证主表：`cwhs_hzpz`
- 汇总凭证分录表：`cwhs_hzjzpz`

### 2.2 关键字段映射

| 来源表 | 字段 | 用途 |
| --- | --- | --- |
| `cwhs_hzpz` | `jzpzh` | 汇总凭证号，作为主表与分录表关联键 |
| `cwhs_hzpz` | `xspzh` | 汇总凭证显示号，用于账表展示与追溯 |
| `cwhs_hzpz` | `jzrq` | 汇总凭证记账日期，用于总账/明细账日期归集 |
| `cwhs_hzpz` | `zhaiyao` | 汇总凭证主摘要，分录摘要缺失时兜底 |
| `cwhs_hzjzpz` | `kmbh` | 科目编号，按前缀归集到总账和明细账 |
| `cwhs_hzjzpz` | `zhaiyao` | 分录摘要，作为明细账逐笔展示摘要 |
| `cwhs_hzjzpz` | `jffse` | 借方发生额 |
| `cwhs_hzjzpz` | `dffse` | 贷方发生额 |
| `cwhs_hzjzpz` | `flbh` | 分录序号，用于同日同凭证下稳定排序 |

### 2.3 账表映射规则

#### 总账

- 上年结转/上次结转：按 `年初 -> 开始日前一天` 的汇总凭证分录累计借贷发生额生成。
- 日汇总行：按日聚合 `cwhs_hzjzpz` 借贷发生额，并通过 `cwhs_hzpz.xspzh` 生成“汇总记字自 X 号到 Y 号凭证”摘要。
- 本月合计：按月范围内汇总凭证分录累计。
- 本年合计：按 `年初 -> 截止日` 汇总凭证分录累计。
- 余额：统一调用 `getKmye(..., pzlx = hz)`，确保余额口径与汇总凭证一致。

#### 明细账

- 上年结转/上次结转：同样按汇总凭证分录累计值生成。
- 明细行：逐条读取 `cwhs_hzjzpz`，关联 `cwhs_hzpz.xspzh` 后写入账表，确保每条明细都能追溯到对应汇总凭证。
- 每日小计：按日对汇总凭证分录求和。
- 本月合计：按月对汇总凭证分录求和。
- 本年合计：按年初至当前月末对汇总凭证分录求和。
- 行内余额：按科目余额方向对汇总凭证分录逐笔滚动计算。

## 3. 本次代码改动

- 修改文件：`CwhsServiceImpl.java`
- 改造点：
  - `makeZbZz` 改为通过新增的汇总凭证辅助方法统计发生额。
  - `appendZzRowsLoop` 改为基于 `cwhs_hzpz/cwhs_hzjzpz` 生成日汇总与月合计行。
  - `makeZbMxzByMonth` 改为读取汇总凭证分录列表生成明细账逐笔记录。
  - `buildMxzKmyeReqDTO` 与总账余额兜底逻辑统一切换到 `pzlx = hz`。
  - 新增开始日期大于截止日期的兜底校验。
  - 新增 `HzjzpzMxJl`、`getHzjzpzxxHz`、`listHzjzpzxx` 等私有辅助方法，封装汇总凭证取数逻辑。
  - 新增命名统一按 `doc/项目规范/Gjj项目组开发规范.md` 收敛为“中文拼音缩写 + 驼峰”，避免继续引入英文辅助方法名。
