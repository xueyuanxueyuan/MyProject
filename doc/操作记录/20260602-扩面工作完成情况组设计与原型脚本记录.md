## 3. 本轮确认的关键规则

1. 本组是月度单表，不拆总表/附表。
2. 本组责任主体仍是分中心，市中心负责汇总审核。
3. 页面必须展示截止日期，并以截止日期作为取数口径。
4. `本年实缴`、`上年实缴` 自动取数；`本年净增`、`净增长率`、`完成率` 自动计算。
5. `目标任务` 是唯一手工填报指标。
6. `1 月、2 月` 的 `目标任务` 与 `完成率` 允许为空；`3 月起` 填报并沿用全年。

## 6. 本轮验证结论

1. 已通过浏览器自动化确认 `kmgz` 菜单下存在分中心按钮 `自动取数 / 保存草稿 / 提交审核`，以及市中心按钮 `审核通过 / 退回 / 锁定 / 导出完整报表`。
2. 已通过浏览器自动化确认分中心角色切换链路可用，但 Element UI 角色下拉存在点击命中不稳定现象，需要采用“点击后键盘选择”的方式切换。
3. 针对 `目标任务` 输入框，原实现存在“每次输入即整表重建”的交互风险，已在原型中改为缓冲式输入并在失焦/提交前统一落数。
4. 浏览器自动化工具对清空后重输仍有追加输入现象，当前更像是自动化工具与页面输入控件之间的兼容性问题；该项暂记为“待人工浏览器复核”，不作为已完全验证通过结论。
