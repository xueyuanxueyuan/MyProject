## 3. 本轮确认的关键规则

1. 本组是月度单表，不拆总表/附表。
2. 本组责任主体仍是分中心，市中心负责汇总审核。
3. 本组业务值以自动取数和自动计算为主。
4. `1-2月空值，3月起带预算` 是本组最关键的月度规则。
5. 收入实绩使用 `401收入`，支出实绩使用 `411支出`。
6. 增值收益全部由收入减支出自动计算。

## 6. 原型同步结果

本轮已将 [index.html](file:///home/source/Jetbrains/Probject/Gjj/doc/操作记录/20260601-资金预决算及执行情况-交互原型/index.html) 中的 `ywszzx` 菜单从旧的通用表格分支独立出来，补齐为专属单表执行页，主要改动如下：

1. 新增 `YWSZZX_MAIN_META`、`YWSZZX_ROW_CONFIG`、`YWSZZX_DETAILS` 三组原型数据，按 15 行固定结构还原 Excel 执行情况表。
2. 新增 `ywszzxData`、`ywszzxRows` 以及 `refreshYwszzxView`、`recalculateYwszzxDetailFormulas`、`buildYwszzxRows` 等方法，实现自动计算与全市汇总。
3. 页面增加 `isYwszzxMenu` 专属分支，分中心只展示 `全市 + 本机构`，市中心展示 `全市 + 全部分中心`。
4. 工具栏按钮改为本组专属交互：
   - 分中心：自动取数、保存草稿、提交审核
   - 市中心：审核通过、退回、锁定、导出完整报表
5. 业务单元格统一只读，不再提供人工录入入口；仅保留签字人与按钮流转交互，符合“自动取数和自动计算为主”的既定口径。
