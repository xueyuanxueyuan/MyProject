# 资金使用预算组原型改造记录

## 1. 改造目标

在不改变现有原型整体视觉风格的前提下，将 `资金使用预算` 模块改造成与当前专项设计一致的可演示原型。

改造目标包括：

- 增加 `总表 / 附表` 双页签
- 总表改为固定字段汇总展示
- 附表改为唯一填报来源页
- 前端数据结构与当前数据库设计、接口设计保持一致

## 3. 关键改动点

### 3.1 页面结构

- 保留左侧菜单、顶部信息区、工具栏、表格区、签字区整体骨架
- `资金使用预算` 改为 `总表 / 附表` 两个页签
- 市中心默认进入总表
- 分中心默认进入附表

### 3.2 角色切换

- 角色切换从原来的少量单选按钮改为下拉选择
- 支持：
  - 市中心
  - 市本级
  - 嘉善县
  - 平湖市
  - 海盐县
  - 海宁市
  - 桐乡市

### 3.3 总表

- 总表直接展示：
  - 项目
  - 行次
  - 上年预算数
  - 上年实绩数
  - 本年预算数
  - 为上年实绩%
- 总表全部业务值只读
- 总表不再复用附表的机构列结构

### 3.4 附表

- 附表完整展示 16 行业务项
- 展示：
  - 全市列
  - 各分中心列
- 全市列自动汇总且只读
- 分中心只允许编辑本机构的可填字段
- 自动带入项、公式项、比例项均只读

### 3.5 数据结构

- 原 `zjsyys` 混合结构重构为预算组专用 mock 数据结构
- 附表以机构明细行为基础
- 前端对机构明细做 Pivot 生成区县列
- 总表通过附表汇总结果和历史对比值生成

## 4. 当前原型可演示内容

- 市中心查看总表汇总
- 市中心查看附表全机构明细
- 分中心查看总表只读结果
- 分中心在附表录入本机构可编辑字段
- 附表自动计算：
  - 年末余额
  - 贷款余额占归集余额比
  - 国债投资余额占归集余额比
- 总表随附表数据联动刷新

## 5. 当前仍属于原型阶段的部分

- 按钮目前主要做演示，不连真实后端
- 其他功能组仍沿用旧版占位逻辑
- 预算组当前使用 mock 数据，不连真实接口

## 6. 下一步建议

原型层面后续优先顺序建议为：

1. 继续把预算组原型补到更接近真实接口入参出参
2. 或进入 `业务收支预算组`，按同样方式同步改造原型
