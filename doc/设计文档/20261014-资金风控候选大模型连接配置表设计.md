# 资金风控候选大模型连接配置表设计

日期：2026-10-14。实施范围仅为第一阶段的连接登记与固定合成提示测试。数据库**需要新增一张表** `zjfk_llm_connection`；不改 `zjfk_model`、训练、预测或报告原表。建表与回滚脚本均为待执行交付件，未连接目标数据库。

## 建表与字段字典

- 建表：`doc/数据库脚本/20261014-资金风控候选大模型连接-达梦待执行.sql`
- 回滚：`doc/数据库脚本/20261014-资金风控候选大模型连接-达梦回滚待执行.sql`
- 表所在 schema：使用资金风控服务实际连接的业务 schema，实施前由 DBA 确认；应用 SQL 使用不带 schema 的表名。

| 字段 | 达梦类型 | 约束/默认 | 来源与用途 |
| --- | --- | --- | --- |
| `id` | `VARCHAR(36)` | 主键、非空 | 后端生成 UUID；不与私有模型记录 ID 混用 |
| `provider` | `VARCHAR(64)` | 非空 | 界面录入供应商标识，后端校验格式 |
| `base_url` | `VARCHAR(1024)` | 非空 | 界面录入协议基址；公网 HTTPS 域名或 RFC1918 私有 IPv4 HTTP，拒绝回环、链路本地、元数据地址、查询与片段；最多 255 个字符 |
| `model_name` | `VARCHAR(128)` | 非空 | 界面录入供应商模型名 |
| `api_key_cipher` | `VARCHAR(4096)` | 可空 | 公网连接存 AES-GCM 密文；内网免密连接写入 `NULL`；不回显、不加入列表查询 |
| `test_enabled` | `INT` | 非空、默认 1、只允许 `0/1` | 页面每条连接控制合成测试；更新时保存，服务端测试前再次核对 |
| `version` | `INT` | 非空、`>= 1` | 新建为 1；更新/停用时按 ID 与版本条件原子递增，避免覆盖 |
| `enabled` | `INT` | 非空、默认 0、只允许 `0/-1` | `0` 候选可进行经许可的合成测试；`-1` 停用；当前没有生产启用状态 |
| `updated_by` | `VARCHAR(64)` | 非空 | 后端认证用户 ID，不采信页面自行提交的操作者 |
| `updated_at` | `TIMESTAMP` | 非空 | 新增及更新时由数据库 `CURRENT_TIMESTAMP` 写入 |

主键 `pk_zjfk_llm_connection(id)` 用于按 ID 查询及更新；索引 `idx_zjfk_llm_conn_updated(updated_at)` 对应列表按更新时间排序。当前没有唯一供应商/模型约束：不同账号可配置同一供应商和模型；配置之间以 UUID 区分。数据库约束限制状态和版本，不授予应用侧 `DELETE` 权限。若后续正式启用发布或绑定机构，须单独提交状态迁移、权限与数据隔离设计，不能直接重解释 `enabled=0`。

## 写入与读取约束

| 操作 | 表字段及条件 | 安全边界 |
| --- | --- | --- |
| 新增 | 写入连接字段与 `test_enabled`，`version=1`、`enabled=0` | 校验登录用户与地址格式；公网加密密钥，内网免密字段为 NULL |
| 修改 | `WHERE id=? AND version=?`；版本 `+1`、候选状态 `0` | 公网留空保留已有密文，内网清空密文；内网切换公网须填新密钥 |
| 停用 | `WHERE id=? AND version=? AND enabled=0` | 置 `-1` 且版本 `+1` |
| 列表 | 只读 `id/provider/base_url/model_name/version/enabled/test_enabled` | 不读取 `api_key_cipher`，按 `updated_at DESC` 排序 |
| 合成测试 | 仅按 `id=? AND enabled=0` 读取地址、模型名、密文及测试开关 | 开关为 1 方可测试；重新校验地址，内网免密不发送 Authorization；仅发送固定合成提示，参数按次传入 |

已部署旧建表版本（密文字段 `NOT NULL`）时须由 DBA 单独审阅并执行 `doc/数据库脚本/20261014-资金风控候选大模型连接-达梦免密迁移待执行.sql`；未建表环境只执行更新后的建表脚本，不得重复迁移。2026-10-15 经用户明确批准移除服务端逐地址白名单，协议基址由页面保存；目标库 SQL 尚未执行，需 DBA 验证列可空性及回滚方案。

上表 `?` 表示绑定参数的逻辑语义。具体 SQL 已置于 `prod/IdeaProject/capinfo-gjj-busi-zjfk/capinfo-gjj-busi-zjfk-busi/src/main/resources/mapper/mxgl/LlmConnectionMapper.xml`，实际使用 `#{id}`、`#{version}` 等占位符，不使用 `${}`；Mapper Java 接口在同模块 `mxgl/domain/dao/mapper/LlmConnectionMapper.java`。服务实现不直接拼接或执行 SQL。

## 人工执行与验收门禁

1. DBA 确认目标实例达梦版本、字符集、`VARCHAR` 字节/字符口径、连接 schema、备份及对象命名无冲突；重点核对 `base_url` 和密文列的实际长度。没有目标库实测，不能称该 SQL 已验证可执行。
2. 审核建表、`CHECK` 约束、普通索引与注释后，在受控环境由 DBA 手工执行建表脚本；验证表/索引/注释、`enabled` 非法状态拒绝、乐观锁更新及查询权限。回滚脚本**不得**跟建表脚本自动串行执行。
3. 服务账号按最小权限授予本表 `SELECT/INSERT/UPDATE`，不得授予表删除及明文密钥查看能力；数据库密文仍属敏感数据，需限制表直接查询、备份和 SQL 参数日志访问。公网密钥加密主密钥从受控服务环境配置，不落库或仓库；地址随连接由页面录入。
4. 建表只是配置功能的前置条件；服务端编译和单元测试、前端构建、旧私有模型回归、受控网络负例、出口隔离及目标库联调全部通过后，再由环境负责人决定部署验收。生产预测/报告调用另行设计。
