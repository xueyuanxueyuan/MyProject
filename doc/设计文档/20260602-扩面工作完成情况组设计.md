# 资金预决算及执行情况 - 扩面工作完成情况组设计

## 1. 设计范围

本组仅覆盖以下 1 张表：

- 住房公积金扩面工作完成情况表

本组属于月度单表，不拆总表/附表。

## 2. 最终功能设计结论

本组最终功能设计结论如下：

1. 本表按月生成，页面必须展示截止日期。
2. 本表的责任主体仍是分中心，市中心负责汇总审核。
3. 本表采用 `主表 + 机构完成情况明细表 + 前端固定行配置渲染` 模式。
4. 数据库存储继续按 `HSJGBH` 存机构行，不做“一个机构一列”的物理设计。
5. 前端展示继续还原 Excel 列样式：`全市 + 各分中心`。
6. `目标任务` 是唯一手工填报指标，且仅 3 月起允许填报；`本年实缴`、`上年实缴` 为自动取数，`本年净增`、`净增长率`、`完成率` 为自动计算。
7. `1 月、2 月` 的 `目标任务` 和 `完成率` 允许为空；`3 月` 起分中心手工填报一次，后续月份沿用年初确定值，必要时通过退回后调整。

## 3. Excel 原表结构拆解

## 3.1 表头结构

表头标题：

- `嘉兴市住房公积金扩面工作完成情况表`

表头关键信息：

- 截止日期：如 `2025年10月31日`
- 编制单位：嘉兴市住房公积金管理服务中心（全市）

列头结构：

- 指标
- 单位
- 全市
- 市本级
- 嘉善县
- 平湖市
- 海盐县
- 海宁市
- 桐乡市

## 3.2 行结构

本表业务行共 6 行：

1. 本年实缴
2. 上年实缴
3. 本年净增
4. 净增长率
5. 目标任务
6. 完成率

## 3.3 Excel 明确给出的规则语义

- `本年净增 = 本年实缴 - 上年实缴`
- `净增长率 = 本年净增 / 上年实缴`
- `目标任务 = 1月、2月为空值；3月手工填；维持12月底数据`
- `完成率 = 本年实缴 / 目标任务；1月、2月没有值`
- `全市列 = 各分中心值汇总`
- `全市比率值 = 汇总后的分子 / 汇总后的分母`

## 4. 填报与审核权限设计

## 4.1 分中心填报人

职责：

- 仅查看 `全市 + 本机构` 两类列
- 触发本机构自动取数
- 在允许月份维护本机构 `目标任务`
- 保存草稿并提交审核
- 在退回后重新取数、调整目标任务并再次提交

限制：

- 不能查看其他分中心原始结果
- 不能修改自动取数值
- 不能修改自动计算值
- 不能修改全市汇总值
- 不能锁定报表

## 4.2 市中心审核人

职责：

- 查看全市及全部分中心数据
- 查看系统汇总后的全市口径
- 审核、退回、锁定、导出

限制：

- 不直接改分中心原始结果
- 只能通过退回让责任分中心重新确认
- 不允许人工覆盖全市自动汇总结果

## 4.3 单元格权限规则

按照“单元格类型 + 数据归属 + 状态”控制：

1. 自动取数格
   - 全程只读
2. 自动计算格
   - 全程只读
3. 汇总展示格
   - 全程只读
4. `目标任务`
   - 仅本机构、`3月起`、`草稿/退回` 状态下允许编辑
5. 责任确认类元数据
   - 仅本机构、草稿/退回状态下允许编辑，例如制表人签名

## 5. 页面功能设计

## 5.1 页面定位

本表原型定位为：

- 分中心单表填报页
- 市中心单表汇总审核页
- 截止日期控制下的月报预览页

## 5.2 页面结构

页面采用单页结构：

1. 顶部信息区
2. 工具栏区
3. 扩面工作完成情况主表
4. 底部签字区

## 5.3 分中心视角

展示规则：

- 展示 `全市` 列
- 展示 `当前登录分中心` 列
- 不展示其他分中心列

按钮规则：

- 自动取数
- 保存草稿
- 提交审核

交互规则：

- `本年实缴`、`上年实缴` 只读
- `本年净增`、`净增长率`、`完成率` 只读
- `目标任务` 在 1 月、2 月显示空值只读，3 月起允许填报
- 允许录入或确认本机构制表人信息

## 5.4 市中心视角

展示规则：

- 展示 `全市 + 全部机构` 列
- 所有业务值只读

按钮规则：

- 审核通过
- 退回
- 锁定
- 导出完整报表

## 6. 推荐数据模型

## 6.1 主表

表名：`CWHS_ZJYJS_KMGZWCQKB`

职责：

- 存储月报主单
- 存储年月、截止日期、状态、签字、审核、锁定、取数控制信息
- 作为全部机构完成情况明细的父单据

## 6.2 机构完成情况明细表

表名：`CWHS_ZJYJS_KMGZWCQKFB`

职责：

- 一张月报中一个机构一行
- 存储该机构在本表中的扩面指标
- 作为全市汇总和前端展示的唯一来源

## 7. 核心业务规则

## 7.1 截止日期规则

- 每张月报都必须保存截止日期
- 自动取数和导出都以截止日期作为统计口径
- 截止日期默认取当月月末，可由市中心建单时确定

## 7.2 自动取数值

包括但不限于：

- 本年实缴：截止日期时点本年实缴人数
- 上年实缴：上年同截止日期本年实缴人数

规则：

- 系统自动获取
- 分中心、市中心都不可手工改写
- 取数失败允许保存草稿，不允许提交

## 7.3 自动计算值

包括但不限于：

- 本年净增
- 净增长率
- 完成率
- 全市列

规则：

- 系统自动计算
- 全程只读
- 比率类全市值必须按汇总后的分子分母重算

## 7.4 目标任务规则

- 1 月、2 月：`目标任务` 允许为空
- 3 月：由分中心首次手工录入
- 4 月至 12 月：默认沿用 3 月确定值
- 若需调整，必须在退回后由责任机构修改并重新提报

## 8. 最终功能设计结果

扩面工作完成情况组最终功能设计结果如下：

1. 本组是月度单表，不拆总表/附表。
2. 本组由分中心负责本机构自动取数、目标任务填报与提报。
3. 市中心查看全口径数据并执行审核、退回、锁定。
4. 本组采用 `主表 + 机构完成情况明细表 + 行配置渲染` 模型。
5. 全市列由系统汇总生成，不允许人工调整。
6. `1 月、2 月` 的 `目标任务` 与 `完成率` 允许为空；`3 月起` 按年度目标任务填报并沿用。
7. 前端原型应表现为“分中心填写目标任务、市中心只读汇总审核”。
