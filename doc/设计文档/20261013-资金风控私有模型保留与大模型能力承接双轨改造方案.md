# 资金风控私有模型保留与大模型能力承接双轨改造方案

日期：2026-10-13。状态：待业务、风控、安全、DBA、技术负责人评审；**未实施、未批准真实数据出域或投产**。

## 1. 范围变更与代码依据

用户要求现有私有模型功能全部保持，同时逐步让新模型实现训练、比较、资金预测和报告。此前 `20261013-资金风控第三方大模型详细设计-合并复审稿.md` 仅允许 LLM 生成报告叙述，本稿**另开数值候选路径**；原设计的数据安全、审批、运行凭证和报告事实校验门禁继续适用。旧接口、制品、历史记录和旧路由不删除、不静默改变字段含义。

源码路径基于 `prod/IdeaProject/capinfo-gjj-busi-zjfk/`：

| 现有能力 | 核对入口 |
| --- | --- |
| 训练与任务、Python GRU/LSTM/ARIMA/SVR/MLP 路径 | `capinfo-gjj-busi-zjfk-busi/src/main/java/cn/capinfo/gjj/busi/zjfk/busi/mxgl/controller/ModelTrainingController.java`；`capinfo-gjj-busi-zjfk-model/app/api/routes/models_v2.py`、`app/services/model_service_v2.py` |
| 训练指标比较、加权排名、确认最佳模型 | `capinfo-gjj-busi-zjfk-busi/src/main/java/cn/capinfo/gjj/busi/zjfk/busi/mxgl/service/impl/ModelComparisonServiceImpl.java` |
| 基础预测、正式保存、优化、贷款存款比/提取率/净现金流派生预测 | `capinfo-gjj-busi-zjfk-busi/src/main/java/cn/capinfo/gjj/busi/zjfk/busi/mxyy/ycjg/service/impl/PredictionResultServiceImpl.java` |
| 定时保存、模板报告 | 同一 `.../busi/` 下的 `mxyy/ycjg/job/YcjgJob.java`、`doc/service/impl/DocumentServiceImpl.java` |

以上是定位线索，不代表全部写者和指标已穷尽；阶段 0 须补齐全清单。

## 2. 实施路线与能力矩阵

**文本 LLM** 负责报告叙述/试验性解释；**可版本化的时序基础模型（TSFM）或确有受控训练能力的预测服务**才作为数值候选。调用通用聊天 API 不等于完成训练；未核实供应商真实训练 API、制品和权重契约前，不承诺 DeepSeek 等特定服务可训练或可靠预测金额。通用 LLM 直接输出金额只能做合成数据隔离实验。

| 保留旧能力 | 新模型如何承接 | 不可替代的边界 |
| --- | --- | --- |
| 训练、任务状态、重试、制品 | 冻结数据集与模型版本；TSFM 零样本登记为 `ZERO_SHOT`（不是训练）；如支持适配训练才建 `ADAPT` 任务并记录权重、参数、环境、日志、哈希；文本 LLM 可解释日志 | 旧训练照常运行；无可重现制品不可进入比较 |
| 模型比较、最佳确认 | 新旧制品用同起点滚动回测；程序算分、排序；LLM 只解释差异 | 旧 `modelIds`/旧确认最佳语义不变；新候选独立双签路由 |
| 基础资金预测 | TSFM 适配器结构化输出逐期金额、日期、单位、预测区间（如有）、快照/制品/运行 ID | 影子前不写正式表；正式路由须回测、审批、灰度；失败仅显式调用已批准旧制品 |
| 比率、净流量等派生预测及预警 | 取已批准基础指标，继续 Java 确定性公式/阈值；LLM 解释变动 | 不以生成比率覆盖原公式；变更公式另行审批 |
| 模板报告 | 冻结事实快照，LLM 生成证据 ID 关联的受限叙述 | 数字仍由确定性取数填充，事实校验、双人审阅，失败有条件回退旧模板 |

路线 A：私有模型正式预测 + LLM 报告，优先交付；路线 B：私有模型持续可用 + 内网 TSFM 候选预测 + LLM 报告，推荐逐步承接；路线 C：通用聊天模型直接预测金额，仅隔离 PoC，不自动升级正式路由。B 不依赖将真实资金数据发第三方。

## 3. 组件、配置与安全

Vue/定时任务 → Java 预测编排 → `LegacyPredictionAdapter`（现有 Python）/`TimeSeriesPredictionAdapter`（新候选）；报告服务 → 受控网关 → `TextLlmProviderAdapter`。离线训练工作器只读冻结数据和制品库，不能写正式预测表；新候选/影子结果独立保存。

按环境、机构、指标、预测步长配置 `enabled=false`、`providerKind=INTERNAL_TSF|EXTERNAL_TEXT`、`endpointRef`、`secretRef`、`modelVersion`、`routeMode=LEGACY|SHADOW|CANARY|ACTIVE`、`routeVersion`、超时/并发/费用上限和 `egressPolicyId`。只存密钥托管引用；白名单字段出域、DLP、TLS、固定目的地且禁重定向；敏感资金流水和提示词原文不入日志。撤权、换密钥和路由变更须审计；真实数据出域先经合同、数据分级、留存及训练用途条款核验，否则只用合成或内网数据。

## 4. 新增接口与数据契约草案

独立 v2 API，旧接口请求/响应字段不复用新含义；以下 DTO/错误码须经 API、前端、风控联审。

| 操作 | 输入与状态契约 |
| --- | --- |
| `POST /api/v1/zjfk/forecast/v2/training-jobs`，`GET /training-jobs/{jobId}`，`POST /training-jobs/{jobId}/cancel` | 冻结数据快照、指标/机构/步长、模型族/版本、`ZERO_SHOT|ADAPT`、参数；状态 `QUEUED/RUNNING/RECONCILE_REQUIRED/SUCCEEDED/FAILED/CANCELLED`，取消需确认 |
| `POST /forecast/v2/evaluations`，`GET /evaluations/{id}` | 候选、快照、折次、阈值版本；逐折预测/实际、可比性、分组指标及覆盖率 |
| `POST /forecast/v2/runs`，`GET /runs/{runId}` | 机构、指标、时点、步长、路由版本；服务端冻结快照和制品；影子结果独立且不得写正式表 |
| `POST /forecast/v2/runs/{runId}/save` | 服务端运行 ID、期望路由版本、幂等键；客户端金额不作为权威值；已消费/撤权/过期拒绝 |
| `POST /forecast/v2/routes/{id}/approve|rollback` | 评估 ID、机构/指标/步长、有效期、不同审批人的双签、期望版本；原子切换代际 |
| `POST /api/v1/zjfk/document/aiDraft/create`、`GET /document/aiDraft/{id}`、`POST /document/aiDraft/{id}/review|render` | 报告快照 ID/摘要、正文版本；事实校验、审阅、文件关联成功后才返回报告 ID |

所有状态变更以 `actor+api+Idempotency-Key` 与请求摘要去重；同键不同请求拒绝。内部任务 ID 与对端任务 ID 分开；提交超时而对端是否受理未知时标记 `RECONCILE_REQUIRED`，先查回执或人工对账，不盲目重试。

逻辑新表：提供方配置（不存明文密钥）、冻结数据快照、候选/训练任务/制品、评估主表及逐折明细、路由/双签/回滚事件、预测运行与影子结果、报告草稿/校验/审阅、渲染任务、审计与幂等记录。路由需目标达梦库实测事务互斥和有效版本唯一；金额精度、索引、物理 DDL、升级/回滚脚本由 DBA 签署，本文不是可执行 DDL。

## 5. 训练、比较与资金预测门禁

同机构、指标、预测起点、步长冻结该起点**当时可得**的数据；逐起点滚动回测，新旧使用同口径；预处理只在各折训练窗口拟合，避免未来数据泄漏。适配训练保存随机种子、数据摘要、基础权重许可证/版本、环境镜像、训练时间、参数和新权重哈希。零样本不冒称训练成功。逐期计算 MAE/RMSE、零值安全的 WAPE/绝对误差、极值/风险事件召回、区间覆盖（如有）、P95 延时、成本、可用率；MAPE 无有效分母时不计算。按机构/指标/极值分层。业务和风控在看到候选成绩**之前**签误差、重大漏报及资源阈值；不达标继续私有模型正式服务。

新正式保存由服务端 `runId` 绑定不可变的 `snapshotDigest+artifactDigest+routeVersion+金额/期间`；在持锁短事务校验授权、审批、有效期、路由代际、一次性消费和唯一键。灰度范围必须查清并升级或拦截旧页面、旧 `savePredictionResults`、`YcjgJob` 保存、`applyOptimization` 及其他直接写者；旧 DTO 不变，但**无可信 runId 的灰度范围旧保存必须拒绝**。灰度范围优化先只预览，正式改值另立版本化审批；未灰度旧行为不受影响。不能用客户端金额或缓存“最近预测”伪造凭证。

影子不触发正式预警/调拨；同快照先核对分歧，待真实值/标签成熟才统计漏报误报，未成熟标记 `PENDING_LABEL`。新服务失败只可显式回退同口径、同机构/指标/步长、仍获批准的私有制品；没有则拒绝本次正式保存，禁止静默默认 GRU。回滚原子更新路由代际、失效旧代际在途保存，不删历史数据。

## 6. 报告及故障治理

保留 `DocumentServiceImpl` 模板、SQL 与确定性公式；服务端只读冻结事实快照/证据 ID，LLM 仅输出受限 JSON 叙述，不作为金额权威源。校验 schema、证据引用、机构、日期、单位、敏感信息及缺证据的因果断言；人工编辑使既有校验过期，须重新核验及双人审阅。SQL 取数失败不生成；LLM 失败而事实完整则明确降级旧模板。上传成功但回执丢失/关联失败进入对账态，不返回报告成功。监控数据漂移、版本/路由、漏报、失败率、队列、成本、审计完整性。
