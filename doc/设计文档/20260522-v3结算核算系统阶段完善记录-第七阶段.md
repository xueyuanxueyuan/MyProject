## 1. 阶段目标

1. 复核第六阶段批次模型接入结果，确认批量收付款 Controller 仍承担批次号生成、明细循环和领域服务调用编排。
2. 使用 TDD 新增付款/收款应用用例服务测试，保护批次号生成、逐条创建、批次统计和领域模型字段映射。
3. 在 app 层新增应用用例服务，将批量付款、批量收款的循环编排从 Controller 下沉到 service 包。
4. 调整 Controller：批量接口只负责入参接收、调用应用服务、响应 DTO 组装和日志输出。
5. 保持 REST 路径、请求 DTO、响应 DTO 字段、领域服务调用语义和数据库结构不变。
