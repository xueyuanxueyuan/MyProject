## 6. 风险与说明

1. 本阶段没有改变 REST 路径、响应 DTO 字段、数据库结构或远程环境。
2. 批次统计目前只在领域批次模型内承载，对外响应仍保持 `pclsh` 和 `items`，避免接口契约漂移。
3. 批次号仍由 Controller 生成，后续可继续下沉到应用用例服务或批次工厂。
4. 批量明细处理仍是逐条调用领域服务，事务边界与部分失败语义还未系统建模。
