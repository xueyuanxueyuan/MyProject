## 2. 改动前现状

| 位置 | 改动前行为 | 分层/语义风险 |
| --- | --- | --- |
| `VoucherController#createVoucher` | Controller 直接从 `Map<String,Object>` 取字段并构造 `VoucherModel` | HTTP 适配层承担用例组装与领域模型构造，Controller 偏厚 |
| `VoucherController` 字段依赖 | 注入 `VoucherDomainService` 和未使用的 `VoucherRepository` | Controller 存在领域仓储依赖痕迹，分层边界不清晰 |
| `VoucherController` 返回类型 | `R<VoucherModel>` | 对外暴露领域模型，不符合 DTO 化规范 |
| `VoucherDomainService#createVoucher` | 仅调用 `model.initialize()` 和 `voucherRepository.save(model)` | 缺少凭证编号、业务受理编号、核算单位、借贷金额平衡等不变量校验 |
| 凭证测试 | 缺少领域服务、应用服务、Controller 单元测试 | 凭证路径缺少分层改造保护与回归证据 |

## 6. 风险与说明

1. 本阶段不改变接口路径、HTTP 方法、请求字段、数据库结构和基础设施 Mapper/Entity。
2. `VoucherApplicationService` 当前沿用既有 `Map<String,Object>` 请求形态，未引入凭证创建请求 DTO；后续如需强化接口契约，可单独设计请求 DTO/Assembler 切片。
3. `VoucherController` 已移除 `VoucherRepository` 和 `VoucherDomainService` 字段依赖。
4. 凭证借贷金额目前按 `BigDecimal#compareTo` 判断相等，忽略小数位 scale 差异（如 `100.0` 与 `100.00` 视为相等）。
5. 基础设施编译过程中存在既有 deprecation warning：`RedisConfig` 中 `Jackson2JsonRedisSerializer#setObjectMapper` 标记为过时；本阶段未处理该既有警告。
6. 仓库中存在大量本轮之前的未跟踪/已修改文件；本阶段未处理这些既有工作区状态。
