# 嘉兴查询统计服务异地冲还贷接口接入设计

- 日期：2026 年 8 月 7 日
- 目标工程：`jiaxing/IdeaProject/capinfo-gjj-busi-jshs`
- 接入模块：`capinfo-gjj-busi-cwhs-cxtj`
- 对照实现：温州业务管理服务 `WbjkServiceImpl`

## 1. 目标与边界

在嘉兴查询统计服务中接入住建部异地冲还贷的三个交易，并复用查询统计服务已存在的住建部通信、流水生成、XML 构造和响应解析能力：

| 交易码 | 嘉兴接口 | 用途 |
| --- | --- | --- |
| `BDC970` | `POST /ydchd/ydchdQyztCx` | 异地冲还贷签约状态查询 |
| `BDC971` | `POST /ydchd/ydchdTzFs` | 异地冲还贷批次通知（含明细） |
| `BDC972` | `POST /ydchd/ydchdMxcx` | 异地冲还贷批次明细查询（返回明细） |

本次仅接入查询和批次通知相关交易；温州的 `BDC969` 是签约写入流程，不属于查询统计服务本次接入范围。

## 2. 温州实现逻辑对照

温州对外入口位于 `YdchdOpenController`，并由 `WbjkServiceImpl` 执行三个交易。三个方法的主流程一致：

1. 从请求头取得收报节点等协议信息，生成结算资料流水；
2. 组装住建部 `ReqHead` 及业务体/明细；
3. 通过 `zjbClient.invokeFront` 发送 XML；
4. 使用 `RespParseHandler` 和 `ParseXml` 解析返回报文；
5. 若协议返回正常但住建部业务状态失败，仍回填响应头、业务体并返回成功响应，由调用方读取业务状态和返回码；
6. Socket 返回空、返回失败标记或 XML 解析异常时，返回失败响应。

字段差异：

- `BDC970`：请求为 `AppBusNum`、`Bak1`、`Bak2`；响应包含签约状态、起止日期、失败原因及保留字段。
- `BDC971`：请求为批次号、收款账户、批次笔数/金额、备注和保留字段；明细包含申请业务号、社保账户、贷款账户、应还金额和还款日期等。
- `BDC972`：请求为批次号和保留字段；响应含批次处理状态、总笔数/金额、成功笔数/金额、清算日期、主机流水及明细。明细额外含实际交易金额、交易状态和失败原因。

## 3. 嘉兴接入方案

### 3.1 对外分层

在 API Feign、Controller 和 Service 三层新增同名方法：

- `ydchdQyztCx(YdchdQyztCxReqDTO)`
- `ydchdTzFs(YdchdTzFsReqDTO)`
- `ydchdMxcx(YdchdMxcxReqDTO)`

所有请求统一携带 `receiveNode`。它只用于生成住建部协议头，不进入业务体；接口校验为非空且最大 6 位。

### 3.2 DTO 与 XML 字段映射

对外 DTO 使用 Java lowerCamelCase，内部复用查询统计服务已有的转换能力，将首字母转换为住建部 XML 精确字段名：

| 对外字段 | XML 字段 |
| --- | --- |
| `appBusNum` | `AppBusNum` |
| `batchNo` | `BatchNo` |
| `tranRefAcctNo` | `TranRefAcctNo` |
| `batchTotalNum` | `BatchTotalNum` |
| `batchTotalAmt` | `BatchTotalAmt` |
| `dueAmt` | `DueAmt` |
| `tranAmt` | `TranAmt` |
| `txStatus` | `TxStatus` |

`BDC971` 请求明细和 `BDC972` 响应明细都固定使用字段名 `fileList`，以复用已有的明细 XML 组装和响应回填处理。

### 3.3 通信与返回语义

新增专用的 `invokeYdchd` 辅助方法，不改动已有组合贷 `invokeZhdk` 的交易方向校验。该方法复用：

- `getJszllsh` 生成流水；
- `buildZjbReqHead` 构造请求头；
- `BuildXml.createReqXmlExact` 生成 XML；
- `zjbInvoke` 调用住建部通道；
- `ParseXml` 与 `RespParseHandler` 解析返回；
- `fillZhdkRespHead` 与既有 DTO 转换工具回填公共响应头和明细。

返回语义与温州保持一致：协议层成功但住建部业务处理失败时，返回 `R.success` 并保留 `txStatus`、`rtnCode`、`rtnMessage` 和业务体；通道空响应、失败标记、缺少响应头或解析异常时返回 `R.fail`。
