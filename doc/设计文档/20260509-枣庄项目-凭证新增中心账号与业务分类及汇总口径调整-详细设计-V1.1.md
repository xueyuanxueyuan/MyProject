# 20260509-枣庄项目-凭证新增中心账号与业务分类及汇总口径调整-详细设计-V1.1

- 适用范围：枣庄项目（资金结算财务核算链路）
- 版本：V1.1（基于 2026-05-09 评审修订）
- 日期：2026-05-09

## 2. 目标与范围
### 2.1 目标
1. 凭证生成时在凭证表新增并落库：`yhzhhm`（中心账号）、`ywfl`（业务分类）。
2. `yhzhhm`：由业务关联键回源 `ywlszb` 获取。
3. `ywfl`：由 `ywlx` 经参数字典 `codeZl1` 映射得到。
4. 凭证汇总改造：按 `yhzhhm + ywfl` 聚合，替代原按 `ywlx` 聚合。

### 2.2 范围
1. 表结构：`cwhs_pz`（凭证主表）、`cwhs_hzpz`（汇总凭证主表）。
2. 代码：凭证生成主链路（含 `ywjzPz` 所在链路）、`JzpzDOMapper.xml#getJzpzhz`。
3. 配置与监控：映射回退、灰度开关、未分类监控。

## 3. 评审结论回写（V1.1变更点）
1. 修正表对象：由错误示例 `cwjz_ywlszb` 修正为 `cwhs_pz`、`cwhs_hzpz`。
2. 修正汇总路径：明确基于凭证聚合，不走业务流水表重算。
3. 修正字典工具：统一使用 `ParamUtil.getCode`。
4. 补充回退：`codeZl1` 映射失败时 `ywfl = ywlx` + `WARN` 日志。
5. 补充测试：增加“汇总凭证摘要名称生成”专项用例。
6. 口径增强：关联键采用“`ywlsh` 优先，`jslsh/sqbid` 兜底”。

## 4. 口径定义
1. 关联键口径：
- 主键：`ywlsh`
- 兜底：`jslsh`、`sqbid`（当 `ywlsh` 缺失或未命中时）
2. 历史数据口径：
- `yhzhhm` 空归并为“其他账号”
- `ywfl` 空归并为“其他分类”
3. 汇总口径：按 `yhzhhm + ywfl` 聚合；不再按 `ywlx` 汇总。

## 6. 凭证生成设计

### 6.1 落位
在凭证生成主入口（评审建议的 `ywjzPz` 链路）完成字段注入与落库。

### 6.2 处理流程
1. 解析业务关联键（优先 `ywlsh`，兜底 `jslsh/sqbid`）。
2. 查 `ywlszb` 获取 `yhzhhm`。
3. 使用 `ParamUtil.getCode` 按 `ywlx` 映射 `codeZl1`，写入 `ywfl`。
4. 映射失败时执行回退规则。
5. 落库 `cwhs_pz`（以及汇总写入路径使用到的 `cwhs_hzpz`）。

### 6.3 伪代码
```java
String yhzhhm = queryYhzhhmByBizKey(ywlsh, jslsh, sqbid);
String ywfl = ParamUtil.getCode("YWLX", ywlx, "codeZl1");
if (isBlank(ywfl)) {
    ywfl = ywlx; // fallback
    log.warn("ywfl mapping fallback, ywlx={}", ywlx);
}

pz.setYhzhhm(defaultIfBlank(yhzhhm, "其他账号"));
pz.setYwfl(defaultIfBlank(ywfl, "其他分类"));
```

### 6.4 异常与回退
1. `yhzhhm` 未命中：写“其他账号”并告警计数。
2. `ywfl` 映射失败：`ywfl=ywlx` 并记 `WARN`。
3. 严格模式开关开启后：关键缺失可改为抛错拦截。

## 7. 字典映射设计
1. 工具：统一 `ParamUtil.getCode`。
2. 目标：获取 `ywlx` 对应 `codeZl1`。
3. 回退：`codeZl1` 为空时，`ywfl=ywlx`。
4. 审计：记录回退次数、回退业务类型清单。

## 8. 汇总与导出改造

### 8.1 汇总SQL落点
- 文件：`JzpzDOMapper.xml`
- 方法：`getJzpzhz`
- 改造：按 `yhzhhm`、`ywfl` 聚合

### 8.2 SQL示意
```sql
SELECT
  NVL(yhzhhm, '其他账号') AS yhzhhm,
  NVL(ywfl, '其他分类') AS ywfl,
  SUM(ywfse) AS totalYwfse
FROM cwhs_pz
WHERE jzrq = #{jzrq}
GROUP BY NVL(yhzhhm, '其他账号'), NVL(ywfl, '其他分类');
```

### 8.3 摘要生成
1. 汇总凭证摘要优先取“业务分类名称”。
2. 若分类名称缺失，回退到“业务类型名称/编码”。
3. 摘要规则统一在汇总组装层封装，避免多处拼接不一致。

### 8.4 导出调整
1. 新增列：中心账号（`yhzhhm`）。
2. 替换列：业务类型 -> 业务分类。
3. 保留辅助列：原业务类型（用于审计追溯，可配置显示）。

## 9. 配置与灰度
1. `voucher.summary.byYwfl`：新汇总口径开关。
2. `voucher.mapping.strictMode`：严格模式开关。
3. `voucher.mapping.fallback.enable`：是否允许 `ywfl=ywlx` 回退。

灰度策略：
1. 首批按机构灰度。
2. 观察未分类占比与回退占比。
3. 稳定后全量放开。
