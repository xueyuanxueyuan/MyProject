# 资金风控双模式并存最终落地方案——专家复审建议稿

日期：2026-10-14。状态：四组 AI 专业视角只读复审后的**实施方案建议**，不是现实专家签字、接口冻结、环境联调或投产批准。继承 `20261013-资金风控双模式并存成对留存对比与报告分析补充设计.md` 及 `20261013-资金风控双模式并存补充设计专家复评.md` 的保留旧链路和 P0 门禁；本稿明确尚未冻结的实施选择。用户确认的目标是两种方式并存、两套结果均留存可比较，同一互斥域最多一套正式生效。

## 1. 复审裁决与边界

模型/量化、Java/DBA、安全/报告、产品/Vue 四个 AI 视角一致建议：**采用双轨候选运行＋不可变对比域＋唯一正式决策投影**；不把通用文本 LLM 当作数值预测训练器或金额权威源。现有私有训练、预测、模板报告和历史入口保持可用；新增 `/api/v1/zjfk/forecast/v2` 仅为比较型接口，不替换旧 API。以下为建议交由业务和责任人签署的目标契约，尚未通过正式组织设计审批。

阶段裁决：A 允许现状调查与签约；B 经隔离环境批准后允许合成 PoC；B/C 独立模块在契约冻结后可分批编码；D 正式保存/优化/调度/回滚的旧链路改造**暂不放行**；E 真实数据出域、灰度及投产**不批准**。允许开发与允许接入正式写入不是同一许可。

## 2. 功能选择与报告配对（R1、R5）

| 操作 | PRIVATE | AI_FORECAST / AI_NARRATIVE | BOTH / 对比 |
| --- | --- | --- | --- |
| 训练 | 原 GRU/LSTM/ARIMA/SVR/MLP 训练任务及历史 | 仅经能力核验的数值时序候选支持适配训练；零样本只登记推理基线；文本 LLM 无训练能力时返回 `UNAVAILABLE` | 独立双任务/版本，不合并旧训练分数；不支持一侧显示原因，不伪造进度 |
| 预测 | 原私有入口保留；新比较任务引用冻结制品 | 经核验的数值预测适配器形成独立运行，文本 LLM 只负责解释 | 单次冻结输入、两个运行 ID；单侧失败可保留成功侧，缺同口径条件禁排名 |
| 报告 | 原模板及历史下载不变 | 冻结事实快照→受限叙述→逐字段校验→人工审核→渲染 | **默认仅两份**：`PRIVATE 预测 × TEMPLATE`、`AI_FORECAST 预测 × AI_NARRATIVE`；每份明确 `forecastRunId + reportMode + reportRunId`，差异分别标明预测差异与写法差异 |
| 历史报告分析 | 原件只读、独立分析记录 | 经授权的摘要/风险提示/事实核验/双报告比较；缺可信快照只标待核查 | 两报告显式选版本及摘要；比较/分析不改正式路由、不覆盖原件 |

默认两份报告同时改变预测来源和生成方式，因此**不能仅凭两份文本断言差异归因于模型**；预测能力对比依据同起点数值回测，写法差异仅描述内容。交叉四组合暂不纳入首批；未来如要测“同预测不同写法”，必须另申请显式两轴组合，禁止按组 ID 或“最新”自动配对。无预测引用的模板报告标 `FACT_ONLY`，不得作为预测差异证据。

前端冻结“操作×模式×能力×任务状态×灰度范围×按钮”矩阵；每次任务固化机构/指标/模式、组与分支 ID，切换机构和乱序回包不覆盖当前页面。明确“候选已留存”“待审批”“正式生效”三种不同徽标；候选保存不调用旧正式保存。比较结果查询和正式路由权限分离，后端再次校验。

## 3. 运行、评估及正式域（R7、R8）

Java 服务端生成不可变 `comparisonGroupId`，一次性冻结 `institutionId, indicatorCode, asOfDate, horizon, timeGrain, currency, unit, dataAvailableAt, datasetSnapshotId, snapshotDigest`。组派发两条独立 `runId`；实际输入不等价则记 `NOT_COMPARABLE` 和每侧输入摘要。运行主表与逐期点明细分离，存制品 ID/摘要、来源、金额精度、口径、起点和状态；失败侧重试追加新运行，旧结果不覆盖。比较关系显式指定两个运行版本，分母为零只给绝对差。

模型评估逐折记录 `originTime, trainEndTime, maxInputAvailableAt, preprocessingDigest, horizon, multiStepMode, baseRunId, derivationPolicyVersion`；折内预处理仅拟合当时可得训练窗。基础预测、余额/净流量/比率派生必须使用同一初值和公式版本。未来值遮蔽与极值注入不改变起点结果；真实标签未成熟只展示分歧，不计算误报/漏报。训练制品使用不可覆盖对象键和摘要，同范围连续两次重训仍能分别复算。

业务/风控在看成绩前签机构/指标分层样本、误差、重大漏报、资源阈值和标签成熟规则；服务端审批资格核对 `metricPolicyVersion` 及签名摘要。阈值版本不匹配、标签不成熟、旧训练分数冒充回测或任一硬门未通过，均不得申请正式生效。

正式记录分 `FORECAST_RUN`（不可变）、`PAIR_COMPARISON`、`FORMAL_DECISION`（追加事件）及旧正式表的唯一当前投影；报告独立存 `REPORT_RUN` 和显式 `REPORT_COMPARISON`。正式互斥域由业务/DBA 签 `机构+指标+预测期+口径/步长` 的实际物理键和空值语义。正式决策、旧保存、优化、任务写入、回滚必须共享目标达梦同域锁、唯一约束、审批及路由代际校验，再在同一短事务更新当前投影；不能单靠查后再写或前端禁用。现有历史值不伪造运行 ID。旧 API 查询保持；灰度域旧无可信运行凭证的正式保存拒绝，非灰度域按已签兼容策略回归；优化默认仅预览，正式变更另走修订审批。目标达梦 DDL、迁移/回滚脚本在 A 阶段由 DBA 签定，不将本稿当作可执行 SQL。

## 4. API、幂等及状态

新增契约按能力查询、训练作业、比较组、组差异、报告作业、报告对比、历史分析、正式决策八类接口分组；现有草案路径见前述补充设计 §4。A 阶段签 DTO、实际 URL、权限码、状态迁移、ID 所有权、金额和版本冲突错误码；旧 `confirm-best` 不视为正式批准。创建组传 `mode, institutionId, indicatorCode, asOfDate, horizon, Idempotency-Key`，服务端返回组 ID 和两侧运行/失败状态；报告创建传明确的 `[{forecastRunId, reportMode}]`，首批 `BOTH` 必须严格对应第2节两份。历史分析 `COMPARE` 两源均传 `{reportType,reportId,contentVersion,expectedDigest}`。正式决策仅接受获批准单一 `runId` 及评估/审批/路由版本凭证。

幂等记录按“调用主体＋接口＋键”唯一，并绑定请求摘要；比较组和每分支有稳定键与权威回执，重复同摘要返回原任务，异摘要冲突。Python 任务已受理但响应超时置 `UNKNOWN/RECONCILE_REQUIRED`；核对对端任务和结果存储、任务清理与跨实例可见性，查无已清理的任务不是“未受理”证据，不允许盲目重新训练/计费。各侧状态 `PENDING/RUNNING/SUCCEEDED/FAILED/RECONCILE_REQUIRED` 独立，组可 `PARTIAL`，比较可 `PAIR_READY/NOT_COMPARABLE`；只有经审批决策才可能 `APPROVED_FORMAL`。

## 5. 报告信任根与安全（R2–R4、R6）

报告两份分别冻结本方预测运行和经批准的事实快照，锁定模板、正文、文件和来源摘要；模板不采信前端 `globalParams/runtimeItemValues` 为事实。确定性规则逐字段比对机构、日期、金额、单位、口径和阈值；报告引用只能证明文内表述，`VERIFIED` 必须另有可信事实快照证据；不符 `CONFLICT`，缺快照 `UNVERIFIABLE`。LLM 只能给引用支持的受限叙述，不得改数、自动预警/调拨或替代双人审核。

历史文件仅通过服务端已授权报告 ID 取原始字节与摘要，在禁出网、低权限、有限资源的解析进程处理；A 阶段核查 DOCX/PDF 类型及大小、解压比、页数、时限，并阻断外链/主动内容。解析器不能验真、加密/扫描件或限制触发返回 `UNSUPPORTED/REVIEW_REQUIRED`；不得把旧下载路径直接作为解析入口。分析结果另存源文件双摘要、片段定位、快照、规则/解析器/提示词/模型版本；任一源更改标 `STALE`，原件不变。

将阅读、提交分析、受控发送、查看结果分权；安全/数据所有者对摘要、风险、核验、双文对比按机构、用途、单/双文、字段**组合**审批，发往第三方前复查完整报文、出口、授权版本和撤权状态。仅合成数据 PoC 无需真实出域授权；真实文件/片段不得因“旧报告可下载”自动取得发送许可。模型失败时仅保留规则层结论并标“不含 AI 解读”。

## 7. 可复审的遗留项与事实边界

复评 R1–R8 的**建议契约**已在本稿给出，但签署、DDL、接口实际字段、供应商支持能力、测试阈值数值与生产批准仍待责任方核实。当前源码仍有 `PredictionResultServiceImpl.savePredictionResults`、`applyOptimization`、`YcjgJob` 两处正式保存；`DocumentServiceImpl` 可接受客户端运行时值；Python `models_v2.py` 创建自身任务 ID 且 `task_service.py` 有文件存储/清理路径；这些均需要 A/D 的真实验证。四视角中一份“本工作区未检得 Python 源文件”的说法经主任务核查不成立，不采用该结论。没有执行编译、回测、达梦竞态或文件解析负例；本稿只提供**可实施的冻结候选方案**，不是上线批准。
