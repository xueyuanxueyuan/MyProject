# 嘉兴一户通多机构配置设计与实施记录

## 已确认口径

按业务 jbjgbh 配置机构身份、证书及密钥。无机构映射时兼容原单机构；有映射时严格匹配，不向全局凭证兜底。

## 设计

- 新增 yht.caps.institutions，以字符串 jbjgbh 为键保留前导零。
- 公共平台地址、超时及加密机连接共用；身份及加解密材料机构隔离。
- 业务请求建立可关闭的线程内机构作用域；后台从原记录恢复，不能修改全局单例凭证。
- 报文头、正文、签名与加解密一致；入站按本地接收机构解析，同步回包校验原机构。
- 原任务查询、短信、重试使用原机构；历史日志按报文方向恢复机构。
- 多机构心跳逐机构执行，禁止取第一个机构兜底。

## 验收计划

1. 旧配置兼容、前导零、多机构缺配置拒绝、对外机构号唯一。
2. 作用域嵌套、异常清理、线程并发隔离。
3. 头体机构一致、不同证书选取、跨机构回包拒绝。
4. 重试、回调、历史日志及心跳核查。
5. 局部测试、差异与编码检查，不发布、不修改真实凭证。
