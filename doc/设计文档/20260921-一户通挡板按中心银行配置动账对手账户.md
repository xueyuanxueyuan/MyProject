# 一户通挡板按中心银行配置动账对手账户

## 已确认口径

按中心账户所属银行选择对手账户，不按个人账户所属银行。保留页面自动动账开关、可编辑接口地址及保存功能；新增独立银行账户配置区。收付动账代码默认 SBDC100，中心账号、金额和流水沿用原交易。

## 实现边界

- 单笔 20601 使用 DbtrBankId；20602 使用 CdtrBankId。
- 批量 40501/40502 使用原请求文件汇总行第六列，将其保存为 BatchState.centerBankId。该列与结算 YhtBatchTradeMessageBuilder 中 reqDTO.getYhlhh() 对应；不用批量明细中的个人银行。
- 中心银行标识精确匹配，每个银行一组对手账号、户名和行号，支持新增、编辑、停用和删除。不会按行号前缀或名称猜测银行。
- 配置持久化到 YHT_MOCK_BANK_ACCOUNT；清历史保留配置。旧统一账户字段仅兼容保存，不参与匹配，不自动给任意银行创建默认映射。
- 缺失中心银行、未配置或停用时记录失败但不发送、不占用发送去重；配置补齐不自动重放历史交易。已发送交易仍受原持久化去重保护。
- 动账地址为空时，从有效的结算接收地址推导同源 /api/v1/ywgl/saveZhbdzt，识别两种原接收路径并保留网关前缀；已有非空地址不覆盖。无法识别路径则保留空值，启用前必须手填。
- 新增管理接口 GET/POST /yht-mock/api/bank-counterparties 与 DELETE /yht-mock/api/bank-counterparties/{bankId}。不修改结算端接口或真实环境地址。
