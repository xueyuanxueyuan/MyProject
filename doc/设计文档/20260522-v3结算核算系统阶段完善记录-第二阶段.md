## 5. 风险与说明

1. 本阶段新增的是 domain 模块最小单元测试基础，尚未补齐 app 层 Controller 测试和 infrastructure 层持久化测试。
2. 收付款 Controller 仍保留“请求 DTO -> 领域模型”的构造逻辑；本轮只抽取响应 DTO 转换，避免一次性重构过大。
3. 付款批量流程中 `FkywModel` 未设置付款人账户是既有设计与第一阶段不变量共同影响点；当前不变量只要求单笔付款校验付款人账户，批量付款暂未强制该字段。
4. 地区策略默认兜底逻辑当前已被测试保护；若后续业务要求未知 HSDWDM 直接失败，需要单独改策略工厂语义并同步测试。
5. Maven 首次拉取测试依赖时产生较长下载日志，最终验证结果以修正后的成功命令为准。

## 6. 下一阶段建议

1. 第三阶段可继续补 app 层 Controller 单元测试，使用 Mock 服务校验接口 DTO、返回结构与异常传播。
2. 可进一步抽取请求 DTO 到领域模型的转换 Assembler/CommandFactory，但建议在 Controller 测试建立后再做。
3. 可为收款模型 `SkywModel.initialize()` 补齐与付款模型类似的不变量测试。
4. 可逐步补充 domain service 查询、空参数、业务不存在等用例，形成核心领域回归保护网。
