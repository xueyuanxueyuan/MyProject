## 2. 本轮改动

### 2.1 收款模块 DTO 化与 Controller 分层收口

改动文件：

- `capinfo-gjj-busi-jshs-v3-app/src/main/java/cn/capinfo/gjj/v3/app/controller/YwglCollectionController.java`

改动要点：

- 单笔收款接口返回类型由领域模型收口为 `R<SkywRespDTO>`。
- 批量收款接口返回类型由领域模型列表收口为 `R<PlskRespDTO>`。
- 收款结果查询接口返回类型收口为 `R<SkywResultRespDTO>`。
- Controller 内部新增私有转换方法：
  - `toSkywRespDTO`
  - `toPlskItemRespDTO`
  - `toSkywResultRespDTO`
- 复用 API 模块已有响应 DTO，未新增 DTO 字段。

### 2.2 付款模块结果查询分层与基础不变量校验

改动文件：

- `capinfo-gjj-busi-jshs-v3-app/src/main/java/cn/capinfo/gjj/v3/app/controller/YwglPaymentController.java`
- `capinfo-gjj-busi-jshs-v3-domain/src/main/java/cn/capinfo/gjj/v3/domain/payment/service/FkywDomainService.java`
- `capinfo-gjj-busi-jshs-v3-domain/src/main/java/cn/capinfo/gjj/v3/domain/payment/model/FkywModel.java`

改动要点：

- `YwglPaymentController` 的结果查询通过 `FkywDomainService.queryResult(ywslbh)` 完成，不再直接注入 `FkywRepository`。
- `FkywDomainService` 新增 `queryResult(String ywslbh)`，统一处理：
  - 业务受理编号为空的参数异常。
  - 付款业务不存在的业务异常。
- `FkywModel.initialize()` 前置调用基础不变量校验：
  - 业务受理编号不能为空。
  - 付款金额必填且必须大于 0。
  - 单笔付款付款人账户不能为空。
  - 收款人账户不能为空。
  - 收款人名称不能为空。

说明：付款子任务执行过程中曾超时，本记录以主进程复核到的当前文件内容和 Maven 编译结果为准。

### 2.3 地区策略工厂安全收口

改动文件：

- `capinfo-gjj-busi-jshs-v3-domain/src/main/java/cn/capinfo/gjj/v3/domain/shared/strategy/region/RegionBusinessStrategyFactory.java`

改动要点：

- 增加默认核算单位代码常量 `DEFAULT_HSDWDM = "000000000000000"`。
- 初始化阶段增加策略配置校验：
  - 策略列表为空时抛出 `BizException`。
  - 策略实例为空时跳过并输出告警日志。
  - 策略支持的 HSDWDM 为空时跳过并输出告警日志。
  - 重复 HSDWDM 注册时输出告警日志，保持后注册覆盖先注册。
  - 默认策略缺失时抛出 `BizException`。
- `getStrategy(String hsdwdm)` 在 HSDWDM 为空或未命中地区策略时返回默认策略。
- 默认策略缺失时通过 `BizException` 明确失败，避免后续空指针。
