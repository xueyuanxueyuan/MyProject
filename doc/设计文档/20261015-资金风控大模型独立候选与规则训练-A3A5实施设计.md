## 五表与关联

目标结构定义见 `doc/数据库脚本/20261015-资金风控大模型候选与规则任务-达梦待执行.sql`，逆序回滚见同日回滚脚本。`zjfk_llm_candidate` 通过 `connection_id` 引用既有连接、状态和当前版本；`zjfk_llm_candidate_version` 按 `(candidate_id, version)` 留存不可变配置与提示词；`zjfk_llm_rule_task` 引用精确版本及旧数据集 ID，但不修改旧数据集；`zjfk_llm_rule_artifact` 按任务 ID 保留规则和评估结果；`zjfk_llm_candidate_event` 留存审核/发布操作凭证。表中不保存供应商明文密钥。

边界：私有模型继续使用原算法 ID、训练接口、任务、结果与发布流程；大模型使用独立 UUID 候选 ID、版本、任务和产物，仅只读引用既有就绪数据集。未来对比功能以独立的关联/对比记录引用两侧结果，不通过修改旧算法 ID 或旧结果表实现。候选状态与正式预测路由隔离，不能仅凭候选创建或任务草稿视为已训练、可预测。

## 接口与状态契约（拟实施）

- `POST /api/v1/zjfk/llm-candidate/list`：返回来源、别名、指标、能力、版本和候选状态；不可返回密钥或未脱敏原始数据。
- `POST /api/v1/zjfk/llm-candidate/save-draft`：新建候选草稿，绑定连接 ID、指标和模型别名；初始版本能力固定为 `UNAVAILABLE`，事务中写入创建事件。此接口不修改已有候选。
- `POST /api/v1/zjfk/llm-candidate/version/detail`：按候选 UUID 与版本号读取不可变版本内容；`POST /api/v1/zjfk/llm-candidate/save-version`：仅当前 `DRAFT` 版本可提交新版本，限制参数白名单及提示词长度，乐观锁递增并在同一事务写入新版本及事件。前端“新建版本”弹窗只保存草稿，不等于能力测试或权重训练；历史任务继续指向创建时的候选版本。
- `POST /api/v1/zjfk/llm-candidate/submit-test`：只从 `DRAFT` 到 `TEST_PENDING`；真实模型合成测试结果须明确状态、时间和来源，模拟结果不得推动 `TESTED`。
- 本轮 `submit-test` 只写入 `TEST_PENDING` 审计事件，**不调用供应商**；`disable` 只允许停用草稿或待测候选。审核、测试通过、候选发布和回滚接口均未实现，不得通过数据库手工改状态代替门禁。
- `POST /api/v1/zjfk/llm-candidate/review`、`/publish-candidate`、`/disable`、`/rollback`：按版本核验状态、身份、能力及审核记录；只在候选域生效，不接入旧正式预测路由；网络不通阶段不允许越过测试门。
- `POST /api/v1/zjfk/llm-rule-task/save-draft` 和 `/list`：仅保存候选版本、数据集引用、截止时间、生成参数及幂等键。无获准的连接与合成测试结果时不启动真实任务、不处理真实资金数据；`UNKNOWN` 任务须先对账，不盲目重试。

“规则与提示词优化”可以产生版本化文本及有限规则 JSON，但不能叫权重训练；`TRAIN/ADAPT` 须另凭供应商训练接口和制品证据确认，不支持则标记 `INFERENCE_ONLY` 或 `UNAVAILABLE`。预测数值仅在第二阶段经规则执行器、回测与业务批准后使用，不执行生成的代码、SQL 或脚本。
