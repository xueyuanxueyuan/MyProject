## 独立运行约束

独立 JAR 表示可单独构建和被依赖，不表示 java -jar 可运行或免平台依赖。旧静态示例接口原样保留，既有固定流水/示例路径等行为不在此次拆包中改变。正式业务推荐使用实例 upload/download。真实住建部联调不作为本次本地验证的一部分。
