# 资金风控第三方大模型详细设计（合并复审稿）

日期：2026-10-13。状态：待评审设计，未开发、未联调、未完成生产数据、供应商合同或模型精度验收。本稿独立描述目标方案，整合 `20261012-资金风控第三方大模型详细设计-评审稿.md`、`20261013-资金风控第三方大模型详细设计-专家修订增补稿.md` 与两轮专家审查意见；原文件保持不变。若后续设计以本稿为准，应先经业务、安全、风控及技术评审确认，而非自动替代现有接口契约。

## 1. 目标、边界和前置结论

- 保留 Java API/BUSI/APP、达梦、Vue、Python 时序训练与预测、poi-tl 报告模板。第三方 LLM 仅产生有证据的报告叙述草稿；资金预测金额、派生指标、阈值和财务公式由原确定性链路计算。LLM API 推理不等于训练；微调是另需立项和数据审批的项目。
- 不自动资金调拨、处理凭证、修改风险阈值、覆盖原始指标或发布无人复核的报告。所有新功能默认关闭；旧接口的请求/响应结构保持兼容，但灰度范围内的正式预测写入必须执行新审批门禁，不能保留绕行语义。
- 公网方案仅能传已签署出域许可的最小字段；获批准的内网隔离方案另核查模型许可、算力和运维。合同、数据分类和环境证据缺失时，新的 LLM 链路仅允许固定合成数据 PoC，不以“去掉姓名”代替出域批准。既有内网链路基线核查和获授权的内网历史数据回测与“新功能真实数据试点”分开审批；未经核实的旧 Python 出口不得推定为可信内网。
- DeepSeek 等供应商、模型名、价格、接口能力、数据条款在部署前以当时官方资料及实际合同重新确认；本设计不保证任何供应商具有数据删除、无训练使用或幂等提交能力。

## 3. 架构和职责

Vue 仅请求业务动作；BUSI 层执行身份、机构、用途和审批校验；出域网关从不可变报告快照生成专用字段 DTO；Python 只接收获准的时序输入；评估器进行同口径回测；正式预测解析器按已批准路由选择制品；事实校验器核对 LLM 叙述；人工签核后通过快照专用渲染器生成 DOCX。任何前端字段、提示词或模型返回均不得直接写入金额、公式结果和风险处置。

`AiModelGateway` 固定配置版本和提示词版本，限制供应商域名/地址、协议、TLS 验证、网络 ACL、模型、用途、token、超时、并发及预算；业务请求不得自填 URL/Key，也不开放搜索、工具调用、文件上传和 SQL。连接检查仅发送固定合成文本。请求由服务端记录指纹与审批版本；429、网络瞬断及特定 5xx 在可证明幂等前提下有界退避；空内容、schema 错误、越权数据或事实冲突不得盲重试。原始提示词、业务报文、密钥和供应商原始报错不得返回前端或写普通日志。

网关对实际连接目标及每次 DNS 解析、重定向和代理出口执行目标地址白名单校验；不允许凭请求 URL 绕过内网/元数据地址限制，不能满足实际连接目标约束则禁用第三方出域。机密系统只授予网关最小读取权限，密钥轮换、吊销及在途请求处置须有运维演练记录；这些限制须在目标网络实测后启用真实数据。

## 4. ID、快照和数据时间契约

`trainingRecordId=zjfk_model_training.id`，`modelId=zjfk_model.id`；`candidateId`、`artifactId`、`evaluationId`、`routeId`、`datasetSnapshotId`、`predictionSnapshotId`、`reportSnapshotId`、`draftId` 各自独立。旧比较 API 的 `modelIds` 不得被改释为 `candidateId`。候选绑定不可变 `artifactId/artifactDigest + trainingRecordId + algorithmVersion + datasetSnapshotId`，制品重训或摘要变化只能产生新候选版本和新评估。

数据集快照含机构、指标、数据来源、单位、口径版本、截至日、行数、内容摘要、权限范围及加密存储引用。每条特征/标签记录业务发生时间 `eventTime`、历史实际可获取时间 `availableAt`、预测起点 `asOf`、标签形成时间及历史修订版本。构造每个历史折时逐字段选择 `availableAt <= asOf` 的最新可见版本，无可见版本则按事先冻结的缺失规则处理；训练标签只能使用训练截止时已形成且可用的版本。仅记录修订号不足以重现历史：须冻结按上述规则选择的逐折输入值及摘要，或提供能够按历史可用时点重取的不可变逐版本记录；新补录和事后更正不得覆盖旧折。预测 Python 请求的数据必须由冻结的 `predictionSnapshotId/snapshotDigest` 产生，派生指标和结果必须绑定相同摘要，执行期间不得重新查询替换。

报告快照冻结模板 ID/文件版本、机构/期间、有效参数、各 SQL 数据项的实际结果、公式与默认值计算结果、来源、数据等级、字段口径及 `snapshotDigest`。预览、出域映射、草稿、编辑、复核与渲染均引用同一个 `reportSnapshotId`；仅正文修改不使数据快照过期，但必须产生新正文版本并重新校验。模板、快照、字段口径或提示词版本发生影响校验的变化则旧草稿 `EXPIRED`，新草稿重新发起。取数/公式失败立即终止，不调用 LLM，也不生成掩盖错误的无 AI 报告。

## 5. 供应商版本、审批和出域

配置字段至少含 `providerCode, endpointRef, modelName, allowedPurpose, allowedDataLevel, credentialRef, timeout, tokenLimit, budget, contractEvidenceRef, policyVersion, version, validFrom/To`，密钥仅由服务端机密系统解析。状态 `DRAFT -> SECURITY_APPROVED -> CONTRACT_APPROVED -> ENABLED`，申请人与每名审批人身份分离；业务数据等级还须有对应字段出域授权，配置启用不代表全部数据都可发。配置或合同关键能力变化生成新版本并重新审批；撤销必要授权后立即停止新的真实数据发送。

专用 `OutboundIndicatorDTO` 仅列经批准的指标编码、周期、数值、单位、来源版本、截至时间及质量状态，不复用 CSV/Base64、报告 `dataModel`、客户信息、银行账号、SQL、数据库连接或内部风控策略。字段级许可须版本化约束数据等级、用途、机构范围、聚合粒度、期间组合及有效期；最终序列化报文再次按完整字段组合拒绝式校验，不以逐字段单独通过替代组合审查。每次发送依次核查：操作者及机构 → 用途/周期 → 快照和字段分类 → 合同/配置状态 → 允许字段及敏感值 → 摘要 → 出域审计；拒绝仅留字段编码、规则版本、授权编号、任务及拒绝原因，不记录敏感值。统一出口须将撤权和发送前最终授权核验/发送许可作为同一版本栅栏的互斥操作：排队或建连但尚未取得发送许可的请求在撤权后停止；取得许可且报文已发出的请求记为在途并对账，不能承诺撤回报文。每次重试重新申请发送许可；撤权后未发任务停止，已发送任务只做内部状态/账单对账，不再自动重发；审计同时记录授权版本、准入、发送许可和实际发送时间，并以并发用例验证先后顺序。

发送许可不得视作跨线程/跨队列的长期令牌：报文真正写入出口前必须在同一授权版本栅栏下再验一次；已取得许可但尚未开始发送时遇撤权，取消发送并审计 `CANCELLED_BEFORE_SEND`。仅能证明发送已开始的请求进入在途对账；若目标网关无法提供可验证的“开始发送”边界及撤权顺序，则真实数据第三方出口不得启用。并发负例须覆盖“许可后、发送前撤权”。

供应商合同证据需由安全、法务、采购确认数据留存、是否用于训练、处理地域、子处理者、删除和退出、事件通知、费用及模型变更。真实资金汇总、敏感策略是否允许出域须有字段级业务/安全/法务签署矩阵，未签署等同禁止。旧 Python 服务的实际目的地址、出口网络、是否跨安全域列入阶段 0 验证；现有训练 CSV 不得重定向到第三方 LLM 网关。

## 6. 时序训练任务、回测与候选批准

新增持久化任务记录 `taskId, actorId, apiCode, idempotencyKey, requestHash, businessType, businessId, snapshotId/digest, status, version, attemptCount, leaseOwner, leaseToken, leaseUntil, externalSubmissionStatus, externalRequestId, failureCode`。worker 以 `version+leaseToken` 条件领取/续租/完成；租约过期不等于外部调用未执行。发送外部训练请求前，数据库原子登记唯一提交权并重新确认租约和授权；当前 Python 请求尚未证明提供预置幂等键和按键查询，因此提交超时/响应丢失进入 `UNKNOWN/RECONCILE_REQUIRED`，不可由接任 worker 自动重提。只有真实 Python 契约具备预置键幂等及查询能力且联调证实后才能启用自动恢复。内部任务状态 `PENDING/RUNNING/RETRY_WAIT/RECONCILE_REQUIRED/SUCCEEDED/FAILED`，外部提交状态 `NOT_SUBMITTED/SUBMITTING/CONFIRMED/UNKNOWN` 独立存储。

崩溃点对账：提交权登记前可按条件更新重新领取；已登记 `SUBMITTING` 但无法证明未发送（包括发送前崩溃）、请求超时或响应丢失均转 `UNKNOWN/RECONCILE_REQUIRED`，禁止自动重提；已有可信 Python 任务 ID 才按其查询，无法查询由获授权运维与 Python 责任人核对对端日志/账单并登记处置人、证据和决定。只有对端按请求唯一标识提供覆盖完整接收时窗的权威未接收证明，或经等效可验证协议证明报文未离开本端，方可人工重置；日志/账单查无记录不等于未提交，证据不足持续保持 `RECONCILE_REQUIRED`，不得重发。已提交则绑定对端任务继续查询；失租 worker 任何回写均拒绝。以上为设计要求，自动化程度须以真实接口联调结果为准。

同口径比较冻结 `datasetSnapshotId/digest + institutionSet + indicatorCode + unit + horizon + foldDefinition + evaluationWindow + metricContractVersion + riskThresholdVersion/thresholdDigest + alertLabelVersion`。启动评估时由服务端读取并持久化阈值/标签版本和摘要，将其纳入不可变 `evaluationDigest`；后续路由审批不能另选新阈值搭配旧评估。按预测起点滚动切分，规定特征观察窗、标签形成期及 purge/embargo；每折独立拟合填补/缩放/特征选择。共同有效样本掩码在运行候选前由数据规则冻结；每候选对全部预期折记录成功或失败、覆盖率及异常剔除，不能按成功预测自行缩小对比总体。朴素季节基线、已有 Python 模型及新候选使用相同快照、时间窗、步长和标签。WAPE 分母为零标记不可计算，不伪造 0。

仅训练/验证折可用于候选和阈值选择；选定的模型、超参、阈值及验收标准先冻结，锁定测试窗仅对该冻结方案验收一次，不以测试结果从多个候选中重新择优；不达标后的新方案须换用未接触的新测试窗，不能靠新建同窗 `evaluationId` 声称独立。最低有效折数、覆盖率、MAE/WAPE、预警召回、误报容忍及业务权重，以及按机构/指标/步长相对现有可用模型与季节基线的不劣或改进门槛，均由业务/风控在测试窗验收前签署；相对对照使用相同共同掩码并披露样本不足限制。不达标或尚未签署只展示描述性结果，状态 `INELIGIBLE`，不得生成正式路由。LLM 报告质量另测事实一致、证据可溯源、敏感泄漏、退稿、费用及延迟，不参与数值模型评分。

## 7. 正式预测路由、影子与兼容切换

候选从 `EVALUATING -> REVIEW_PENDING -> SHADOW -> CANARY -> ACTIVE`，无效可转 `REJECTED/ROLLED_BACK`。启用范围明确为机构、指标、步长、起始时间及开关版本；未启用范围的旧预测行为不被本设计隐式改变。启用范围的所有正式写入路径，包括旧 `generateBasicPrediction`、`savePredictionResults`、定时任务及其他直接持久化入口，均通过服务端 `ForecastRouteResolver` 与快照/审批验证；不能只在新 API 校验、旧入口继续最佳模型或 GRU 静默兜底。上线前列出并封闭全部写入调用点，旧 API 仅保持请求兼容。回滚也需配置版本和范围审计，不能绕过正式闸门。

预测运行 ID 在服务端创建时绑定 `routeId/routeVersion + artifactDigest + predictionSnapshotDigest + scope` 并一次性消费；正式保存、回滚和新路由生效共用机构/指标/步长范围互斥键，正式保存短事务持锁完成当前路由版本、回滚栅栏、运行范围及未使用状态校验与结果写入。先完成的保存不可被事后回滚倒改，先完成的回滚必须使旧版本尚未落库的在途预测失效；仅经批准的有效备用路由可另起新运行，找不到则拒绝写入，不恢复隐式 GRU 或旧直写。灰度切换须覆盖旧入口、定时任务、无运行 ID、重复运行 ID 及回滚交错的拒绝和审计验证。

候选批准为两次独立签核：提交时服务端创建 `routeApprovalId` 并固定 `evaluationDigest + artifactDigest + thresholdDigest + routeScopeDigest`；两签均携带该审批单 ID 和 `expectedVersion`，第一签进入 `PENDING_SECOND_APPROVAL`，不同身份的第二签用预期版本原子更新到 `APPROVED`，并逐项核对 `riskThresholdVersion/thresholdDigest/alertLabelVersion` 与评估中固定的值相等；两签之间任一摘要或授权变化即失效；只有完成第二签且生效时段未冲突才可进入 `CANARY/ACTIVE`。路由保存 `institutionId, indicatorCode, horizon, candidateId, evaluationId, artifactDigest, riskThresholdVersion, effectiveFrom/To, mode, state, routeVersion`。同机构、指标、步长的正式有效时段不得重叠，目标达梦环境必须验证范围锁/串行化策略及双并发审批负例；普通唯一键不足以保证区间互斥。

第二签生效与路由区间检查须处于同一数据库事务：先按固定的机构、指标、步长锁定路由互斥键，再检查含 `CANARY/ACTIVE` 的所有交叠有效期，最后条件更新审批版本并写入路由；锁获取失败或重叠则整笔回滚，不得先批准后补查。目标达梦是否支持所选互斥键及隔离级别须双连接并发实测，未验证时仅视为设计方案。

影子预测独立存储，标识 `mode=SHADOW`、`predictionSnapshotId/digest`、评估/路由/阈值版本，不写正式结果、预警处置或调拨；同一时间点和阈值规则下与正式结果配对，先记录金额、风险等级与触发分歧。只有同期实际结果及标签达到可用时间后，才复算影子/正式双方相对真实标签的漏报与误报；未成熟样本标记 `PENDING_LABEL`，不得将两模型分歧冒充误报或用于灰度放行。阈值或标签口径改变必须新评估和签核。GRU 回退只在制品已批准、机构/指标/步长/口径一致且有效期内，作为显式版本化备用路由调用并审计原因；否则拒绝本次正式预测，仅可显示明确标记过期的历史审核结果。

## 8. 报告草稿、事实校验及文件补偿

AI 报告流程 `DATA_READY -> DRAFTING -> VALIDATING -> REVIEW_PENDING -> APPROVED -> RENDERING -> RENDERED`，异常/拒绝/过期分为 `FAILED/REJECTED/EXPIRED`。出域网关只收到经过许可的快照字段，模型返回固定结构：标题、摘要、逐条发现文本及 `evidenceId`、风险等级、局限；不得自行提供金额字段、模板变量或决策性自动建议。服务端先做 JSON/schema/长度/枚举，再查每条事实性或因果断言的证据、金额与比例的 `BigDecimal` 单位/舍入口径、日期、机构和敏感/注入内容。合法 JSON 不等于事实可靠；无法定位证据的“风险已解除”等无数字结论也不能发布。

合法人工编辑生成新的 `contentVersion/contentDigest`，原草稿与修改差异加密保存；旧验证结果立即失效，对当前正文版本重新跑校验并保存 `validatedContentDigest + snapshotDigest + validationVersion`。审批与渲染都要核对校验结果指向当前正文哈希及原快照；数值事实不一致不允许靠人工审批绕过。编辑人与审批人不同，审批动作带 `expectedVersion`，记录审批事件、操作者角色、意见、时间、版本和文件哈希；已发布 DOCX 不可覆盖，更正生成新版本。

渲染短事务冻结已批准快照/草稿并建任务，事务外按适配器能力上传，短事务关联 `reportId + fileRef + fileDigest`；上传或关联未确认绝不返回成功。对象存储若能使用可查询客户端幂等键，可按键恢复；若采用仅在上传响应中返回附件 ID、无法按客户端键查询的文件服务，则必须先实测可靠回执或增加可查询标识，否则响应丢失只进入 `RECONCILE_REQUIRED` 人工对账，不宣称自动恢复。无法关联的文件记孤儿事件，按已签署保留/清理策略处置。AI 叙述失败且 SQL/公式结果完整，可明确标识回退非 AI 报告；原取数失败禁止回退生成。

文件服务责任方须提供可查询上传标识或可验证的人工定位与回执契约，逐项演练“上传成功但回执丢失”“回执成功但数据库关联失败”，记录文件摘要、报告关联和孤儿处置；不能可靠定位时不开放真实数据 AI 报告渲染。

## 9. API 请求/响应与逻辑表

统一新增 `/api/v1/zjfk` 下独立领域路径，不复用旧 API 的 `modelId` 或旧报告 DTO。新状态变更接口携带 `Idempotency-Key`；同主体、接口、键和请求指纹的重放返回原任务，不同指纹返回冲突；版本不匹配拒绝。幂等记录持久化 `actor_id, api_code, idempotency_key, request_hash, result_ref`，唯一键为前三者；它替代原稿“业务类型+请求指纹唯一”的新任务约束，不更改旧接口。灰度范围内的旧保存 DTO 缺少运行/快照标识，服务端不能仅凭“有有效路由”认可客户端提交的数值；必须关联服务端已持久化、一次性使用且绑定制品与快照的预测运行 ID，否则拒绝正式保存，现有旧接口请求结构兼容不等于可绕过来源验证。所有接口服务端按机构和业务范围校验授权，审批人不能审批自己的申请或修改。

| 动作 | 请求关键字段 | 服务端响应/约束 |
| --- | --- | --- |
| `POST /ai/provider/saveDraft`、`/approve`、`/healthCheck` | 配置草稿字段；审批传 `profileId, expectedVersion, evidenceRef`；健康检查只传配置 ID | 返回配置版本/状态；审批各步独立角色，不返回密钥；检查仅合成文本 |
| `POST /forecast/evaluations/start`、`GET /forecast/evaluations/{id}` | `candidateIds, datasetSnapshotId, snapshotDigest, institutionId, indicatorCode, horizon, evaluationWindow` | 返回 `evaluationId, PENDING`；查询返逐折预测、实际、覆盖率、可比性及阈值版本 |
| `POST /forecast/routes/submit`、`/firstApprove`、`/secondApprove`、`/rollback` | 提交传 `candidateId, evaluationId, artifactDigest, thresholdDigest, scope, effectiveFrom/To, expectedVersion`；返回 `routeApprovalId`；两次签核传 `routeApprovalId, expectedVersion`；回滚传 `routeId, routeVersion, expectedVersion` | 第二签前不生效；逐项核对评估阈值并返回 `routeId, routeVersion, state`；回滚检查旧制品仍可用 |
| `POST /forecast/experiments/predict`、`GET /forecast/experiments/{id}` | 获准的机构、指标、预测点、步长、候选 | 返回试验任务/独立影子结果 ID；不写正式表 |
| `POST /document/aiDraft/create`、`GET /document/aiDraft/{id}` | 创建只提交 `templateId, institutionId, period, templateParams, profileId, promptVersionId`，不提交 `draftId/reportSnapshotId` | 服务端取数并创建快照，返回 `draftId, reportSnapshotId, snapshotDigest, status`；查询仅授权机构 |
| `POST /document/aiDraft/review`、`/render` | 已返回的 `draftId, reportSnapshotId, snapshotDigest, expectedVersion`；审阅提交动作与意见，渲染提交已批准正文版本 | 审阅后返回新版本；渲染异步返回任务 ID，只有 `RENDERED` 才返回报告 ID 和文件引用 |

逻辑表：供应商配置/批准证据、提示词版本、AI 任务和幂等记录、数据集及预测/报告快照、候选/制品、回测主明细、路由/双签事件、影子结果、报告草稿及校验版本、渲染任务和审计事件。关键唯一性包括“评估+候选+折次+预测期”“主体+接口+幂等键”“机构+指标+步长+路由版本”；有效期不重叠需目标达梦事务级范围锁或串行化方案实测。`BaseDO` 字段、达梦类型/序列、金额精度、机构授权、索引及回滚脚本以目标库审议为准，本稿不是可执行 DDL。

## 10. 前端、存储与可观测性

前端供应商页按角色展示脱敏配置及各级批准状态；训练页展示快照、时间窗、算法和任务对账状态；评估页展示折次、共同样本、失败折、阈值版本和可比性；预测页区分正式、影子、过期及回退审计；AI 报告单独呈现 `create -> get/status -> edit/validate -> review -> render -> get/status`，审批前展示当前正文哈希和事实校验结论。旧非 AI 模板入口不混用新请求 DTO；前端按钮隐藏不是权限。重试同一业务意图复用幂等键，重新发起意图生成新键，冲突时重新读取最新版本。

快照、草稿原文/差异、审批事件、报告文件、孤儿记录及备份须按数据等级分别确定加密、访问角色、保留期、到期删除、备份删除和审计元数据范围；具体期限由单位批准，未明确不得落真实数据。普通日志不存密钥、Prompt 原文、供应商原始报文及个人或客户数据。按供应商/机构/用途监控调用量、P50/P95、错误/空输出、token/成本、预算、校验失败、退稿率、预测偏差/漂移、任务积压及对账异常；预算超额停止新调用，价格与模型变更重新验收。

业务连续性须先签署达梦、快照、审批事件、制品及文件服务的恢复顺序、RPO/RTO 和跨系统一致性检查；切换代际号必须由恢复后唯一权威存储持久化，旧主与旧 worker 的租约、路由签核、正式预测写入均凭代际号条件更新，旧代际一律拒绝。切换期间仅允许单一正式写入主节点；无法证明旧主隔离及唯一写主时冻结正式写入。恢复后先冻结路由新写入，核对租约、外部提交 `UNKNOWN`、报告文件和孤儿记录，再人工解除栅栏。供应商及子处理者删除义务、内部备份/孤儿清理期限、例外审批和可追溯的删除证明须由数据所有者及安全/法务签署后实施。
