# 一户通挡板达梦持久化改造

## 已批准范围

使用已有达梦 DM8 实例，独立 YHT_MOCK 用户及同名 Schema。按配置、动账配置、接口记录、协议、交易、批次、场景、动账幂等分表；不把整个快照或整对象 JSON 塞入数据库。保留页面及业务接口，不修改交易状态推进逻辑。

## 事务与安全边界

- MockStoreService 保留业务契约，所有持久化读写使用 JDBC 和事务，不保留运行快照、不回退 JSON。
- 控制表固定行提供跨实例写锁、递增编号和迁移指纹。业务变更、编号、配置更新、历史清理在一个事务内提交；锁仅覆盖数据库操作，不覆盖网络发送。
- 动账幂等按原键唯一，UNKNOWN 先提交后发送；失败或未知不得当作未发送重新处理。
- 数据读取返回独立对象，更新必须明确保存；对现有调用方检查是否依赖内存引用副作用。
- 清除历史只删除记录、协议、交易、批次；保留规则、配置、动账幂等和迁移凭据，避免清理后重复动账。该行为收紧原清理接口，页面文字同步说明。

## 历史迁移

- 专用命令行模式，关闭 HTTP 与 SVS 入口，不提供匿名在线导入接口。
- 显式指定 JSON 或备份文件，源文件只读；严格解析，校验主键、重复编号、map键值和未知字段。任何异常整体回滚。
- 仅向未使用的新库导入；同文件 SHA-256 重复执行返回已迁移，不重复插入；不同文件或已有数据拒绝覆盖。
- 导入配置、各类状态、接口记录、场景和动账幂等记录，保留历史时间与结果内容，计数及导入指纹事务内记录。
- 不自动发送历史回调、不自动推进 PROC、不重放 UNKNOWN 动账。

## 脚本与配置

- DBA 参数化脚本创建表空间/用户；schema-dm.sql 建表索引与控制行，不含密码和破坏性 DROP。
- 应用默认达梦驱动，URL、账号、密码均由环境提供；启动校验 schema 版本。SQL 不自动执行。
- 实例初始化(dminit)不属于应用建库脚本；数据文件路径和权限由 DBA 确认。

## 验收与限制

先新增数据库回归测试并确认失败，再实现。使用 H2 Oracle 模式对存储契约、事务、长文本、跨实例幂等、迁移回滚测试；它不等同于达梦兼容性实测。额外提供真实 DM8 验证入口，只有执行真实 DM8 后才能声称达梦验证通过。保留已有功能测试和前端回归。未授权不建库、不连接线上、不发布。
