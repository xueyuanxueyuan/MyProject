## 二、拟签订的一期合同（限合成环境）

### 1. 数据边界和提供商

- 候选连接记录拟分 `ProviderConnection`（providerCode、协议类型、经安全批准的目标 ID、模型别名、凭证托管引用、超时、配额、所属机构/环境、启停及审计）、`CandidateArtifact`（不可覆盖版本/能力快照/摘要）、`CandidateReleaseEvent`（审批链、目标环境、代际、撤销）及 `CapabilityTestRun`（合成用例 ID/请求摘要/响应格式/延时/费用元数据/状态）。不把 `apiKey`、真实 Endpoint 输入到旧模型表或前端/审计日志；物理表名/字段、达梦 DDL、密钥引用形态待 DBA/安全签定。
- 首批提供商和连接方式由采购、安全与模型负责人确认；未获批准时**只能使用合成模拟适配器**，不得把模拟通过作为“第三方已接通”。禁止客户端自选任意 URL、代理或真实客户资金数据；供应商 API 的训练、私有化及留存能力均标“待核验”。
- 受控能力枚举：`TEXT_NARRATIVE`、`NUMERIC_ZERO_SHOT`、`NUMERIC_ADAPT` 和 `UNAVAILABLE`；训练操作枚举 `TRAIN/ADAPT/ZERO_SHOT/INFERENCE_ONLY/UNAVAILABLE`，两者映射由模型负责人签署。不能将提示词编辑当作训练，也不能将文本调用结果直接写金额/正式路由。

### 2. API 与生命周期边界

| 用途 | 建议契约与测试状态 | 不可越过的边界 |
| --- | --- | --- |
| 候选能力查询/配置 | 仅读/管理获准的 providerCode、modelAlias、版本、能力、禁用原因；返回 `secretConfigured` 布尔值而非密钥；新接口与旧 `/api/v1/zjfk/model` 并存 | 后端按机构及角色二次授权，灰度关闭默认只显旧模型 |
| 合成连接与功能测试 | 请求只有服务端合成用例 ID、候选版本及 `Idempotency-Key`；响应 `testRunId/status/formatValid/latency/usage/limitation`；服务器从批准的模板取合成输入 | 不接受前端传客户数据、SQL、任意报告或自定义完整报文；状态 `UNKNOWN` 对账后再处置 |
| 候选发布 | `DRAFT→TESTED→REVIEWED→CANDIDATE_ACTIVE→DISABLED/ROLLED_BACK`；发布事件追加留痕、权限及当前版本比对 | `CANDIDATE_ACTIVE` 仅供一期测试/二期比较，**绝不等同 `APPROVED_FORMAL`** |
| 训练与模型对比 | 私有继续走旧接口；第三方训练能力缺失显示不支持，`ZERO_SHOT` 可登记基线；比较只比较合成接口质量、格式、时延与费用 | 不调用旧 `confirm-best` 为新候选审批；不以合成测试评定财务预测精度 |

API URL、DTO、错误码、版本并发、幂等 TTL、达梦唯一索引和角色权限码**暂不冻结**；A1 签署后先锁定这些再让 A2/A3 启动代码。安全要求白名单出站、TLS、凭证托管、发送前授权版本校验、预算/限流/熔断、脱敏审计；若真实出域不被批准则本期仅模拟或受批准内网连接。

### 候选接口与输入控制

| 建议操作（尚未实现） | 请求与返回的最小契约 | 服务端必须保证 |
| --- | --- | --- |
| `POST /api/v1/zjfk/candidate-models/page` | 筛选来源/能力/状态；返回候选 ID、版本、状态、禁用原因、`secretConfigured` | 机构范围来自鉴权会话；绝不返回凭证、目标地址和原始调用数据 |

### 逻辑数据与状态约束（非达梦 DDL）

| 对象 | 建议字段 | 必须验证的约束 |
| --- | --- | --- |
| `ProviderConnection` | `connectionId, institutionId, environment, providerCode, approvedTargetId, modelAlias, secretRef, timeoutMs, quotaPolicyId, enabled, rowVersion` | 密钥仅保存托管引用；环境与机构不得由前端自报；目标映射白名单 |
| `CandidateArtifact` | `candidateId, connectionId, immutableVersion, capabilitySnapshot, trainingMode, artifactDigest, status, rowVersion` | 版本/摘要不可原位覆盖，与旧模型算法 ID 和训练制品隔离 |
| `CapabilityTestRun` | `testRunId, candidateId, candidateVersion, syntheticCaseId, requestDigest, idempotencyKeyDigest, status, formatValid, latencyMs, usage, limitation` | 按经签定的范围做幂等唯一约束；仅保存合成与脱敏证据 |

状态建议 `DRAFT→TESTED→REVIEWED→CANDIDATE_ACTIVE`，各阶段可禁用；回滚只追加事件并指向已审核历史版本。改动配置或能力快照会使旧测试证据失效。旧私有训练继续可用；第三方 `TEXT_NARRATIVE` 为 `UNAVAILABLE`（不伪装训练），`NUMERIC_ZERO_SHOT` 只记推理基线，`NUMERIC_ADAPT` 须核实供应商训练接口与许可后才能启用。合成比较只评格式、时延、失败与费用，不宣称真实资金预测精度。

权限建议拆为“候选查询、配置、合成测试、审核、候选发布/回滚”，逐操作校验机构和角色、默认灰度关闭；前端隐藏按钮不是后端鉴权。具体权限码、达梦类型/唯一索引/回滚、密钥托管形态和版本并发策略仍需签定，不得直接据此运行迁移。
