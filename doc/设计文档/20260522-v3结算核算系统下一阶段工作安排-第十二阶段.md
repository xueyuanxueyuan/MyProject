## 4. 第十二阶段建议主题

第十二阶段建议优先执行：账户模块应用服务抽取与 Controller 分层收口。

选择账户模块的原因：

1. 账户是付款、收款、转账、凭证、对账联动的基础资源，优先治理可降低后续模块耦合。
2. 当前 `AccountController#queryAccounts` 直接调用 `AccountRepository`，分层问题明确，边界比策略拆分和批次持久化更小。
3. `AccountDomainService` 当前能力很薄，只包含注册，没有查询用例和不变量校验，适合作为下一轮 TDD 小步改造。
4. 改造可沿用第十、十一阶段的“Controller -> ApplicationService -> DomainService/Repository 接口”模式，验证路径清晰。
