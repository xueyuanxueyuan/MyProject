## 1. 阶段目标

1. 延续第八阶段建议，将单笔付款、单笔收款的应用编排从 Controller 下沉到 app 层应用用例服务。
2. 保持 REST 路径、请求 DTO、响应 DTO 和领域服务接口不变。
3. 使用 TDD 先新增单笔应用服务测试，验证请求 DTO 到领域模型转换、领域服务调用、返回模型语义。
4. 调整 Controller 单笔接口只负责 HTTP 入参、日志和响应 DTO 组装；领域模型构造与领域服务调用委派给应用服务。

## 6. 风险与说明

1. 本阶段不改变接口路径、请求体字段、响应体字段、数据库结构和领域服务接口。
2. Controller 仍保留领域服务依赖用于结果查询接口；本阶段仅治理单笔收付款创建路径，未扩大到查询路径。
3. 请求 DTO 到领域模型转换仍位于 app assembler，未将 API/app DTO 下沉到 Domain。
4. 批量收付款的应用服务编排保持第七阶段后的现状，本阶段未修改批次号生成、批次统计和批量明细循环语义。
