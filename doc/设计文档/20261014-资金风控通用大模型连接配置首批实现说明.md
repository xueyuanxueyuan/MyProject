# 资金风控通用大模型连接配置首批实现说明

日期：2026-10-14。根据验收方最新要求，模型管理页面允许操作员录入供应商、HTTPS 协议基址、模型名称及 API 密钥；本说明覆盖先前 A1 草案中“页面只填目标 ID、不填地址和密钥”的交互假设。旧算法类型、私有训练、预测和报告接口不变；这次实现仅是独立连接配置和固定合成文本连接测试，不代表数值资金预测、训练或正式模型发布。

## 2026-10-15 现行配置与验收口径

- 经用户明确批准，模型服务地址不再通过配置文件批准。页面填写 `provider=internal-qwen`、`baseUrl=http://172.20.106.5:8000/v1`、`modelName=Qwen3.6-27B`，内网私有 IPv4 连接密钥留空；每条连接有允许测试开关，默认为开。后端仍拒绝回环、链路本地、元数据等非私网地址及带查询、用户信息、片段或完整 `/chat/completions` 的基址。公网仅接受 HTTPS 域名，测试前检查其 DNS 地址不为私网；不跟随 HTTP 重定向。
- 点“合成测试”时填写本次 `top_k=50`、`max_tokens=2048`、`temperature=0.2`；如需模拟客户 curl，另填可选 `User-Agent: Apifox/1.0.0 (https://apifox.com)`。后台从页面保存的连接读取模型名，发送固定无业务数据提示和 `stream=false`，不会发送 PACS 文本。模型连接和测试参数均不写进本地 YAML；YAML 的 `zjfk.llm.master-key` 仅用于公网 API 密钥加密，内网免密不需要。
- 页面可录入任意 RFC1918 私有 IPv4/端口，**这会授权后端向该私网地址发起固定 POST**。上线前必须通过网络出口策略控制应用可访问的内部服务，检查统一认证权限、DNS 重绑定、代理、费控、限流和审计；仅靠应用层格式校验和 DNS 预检查不足以替代网络隔离。TSP 部署清单仍未更改，正式环境需部署新代码、执行必要的数据库迁移并联调；本地调整不会自动影响部署实例。

## 已实施边界和待续

- 按项目现有分层：请求参数 `LlmModelConfigReqDTO` 位于 `capinfo-gjj-busi-zjfk-api` 的 `mxgl/dto/req`；Controller 不声明请求内部类；`mxgl/service/LlmModelConfigService` 仅定义服务接口，业务实现位于 `mxgl/service/impl/LlmModelConfigServiceImpl`，连接地址校验及密钥加解密位于与 `service` 同级的 `mxgl/security/LlmConnectionSecurity`。原接口路径和 JSON 字段不变。
- 持久化按现有 `mxgl/domain/dao/mapper` 及 `resources/mapper/mxgl` 结构新增 `LlmConnectionMapper.java`、`LlmConnectionMapper.xml` 与 `LlmConnectionDO`；服务实现不再内联 `JdbcTemplate` SQL。XML 所有用户来源的值均采用 MyBatis `#{}` 参数绑定，不使用 `${}` 文本替换；公开列表 SELECT 不含 `api_key_cipher`，仅合成测试按候选 ID 查询密文。`id/version` 乐观锁及停用条件保持不变。
- 新接口 `/api/v1/zjfk/llm-config/list|save|disable|test` 使用服务端操作员白名单；保存新连接、乐观版本更新和停用，默认标候选/停用；无密钥回显、无正式业务路由或启用入口。界面在现有算法类型管理页面顶部通过“配置大模型”按钮打开弹窗，默认展示新增连接表单，也可切换至已有连接列表进行编辑、停用或合成测试；关闭弹窗即卸载表单并清理未保存的密钥。原私有模型算法类型操作保持不变。
- 合成测试按 OpenAI Chat Completions 兼容格式发送固定英文提示；公网密钥连接附带 `Authorization: Bearer`，内网免密连接不带认证头。本地配置可附带示例生成参数及 `User-Agent`，只返回 HTTP 状态、响应格式是否有效和耗时；不接受用户输入测试文本，不返回供应商原始响应。真实供应商“兼容”程度仍须针对其合同和 API 实测。
- 单节点按操作员设 30 秒连接测试冷却时间；多实例部署仍须在网关或共享限流器实施全局限流、并发额度与费用预算。生产放开出口前须验证 DNS/代理限制、响应体读取超时与 TLS 策略，应用层白名单不能单独作为 SSRF 防护。
- 本批没有提供真实训练、数值预测、报告、供应商选择路由、审批发布、机构级数据隔离或完整审计事件；下一批在专用权限和机构范围、数据安全/DBA 评审后扩展。首次投用前必须验证服务端授权、旧私有模型回归、合成测试零正式写入和外部网络负例。
