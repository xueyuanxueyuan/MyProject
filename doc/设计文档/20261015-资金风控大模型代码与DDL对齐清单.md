## 2. `snapshot_hash` 来源问题（关键）
- 设计意图：规则任务绑定"冻结数据集快照"摘要，保证可复现、可审计。
- 现状：`rule_task` 写 `NULL`；`DatasetDO`（`zjfk_dataset`，继承 MyBatis-Plus `BaseDO`）**无 content hash / digest 字段**，无法提供摘要。
- 建议二选一，否则绑定形同虚设：
  - (a) 在 `saveRuleDraft` 时由服务端基于 `dataset_id + cutoff_time + record_count + last_value_data` 等计算 `SHA-256` 写入；或
  - (b) 给 `zjfk_dataset` 增加数据指纹列并在 `DatasetDmService` 中维护，再回填 `snapshot_hash`。

## 3. 状态机 / 接口缺口（属 A4 / A5 未实现，非字段错配）
- 候选状态机：`DRAFT→TEST_PENDING`（已做）；`TEST_PENDING→TESTED→REVIEWED→CANDIDATE→DISABLED/回滚`（A4 未做）。设计稿明确 `review` / `publish-candidate` / `rollback` / `disable` 中前三者未实现。
- 规则任务状态机：`DRAFT→…→SUCCEEDED/FAILED`（A5 执行器未做）；`UNKNOWN` 须先对账、不盲目重试（设计稿要求）。
- 能力 `TRAIN` / `ADAPT` 须凭真实供应商训练接口 + 制品证据确认，否则只能 `INFERENCE_ONLY` / `UNAVAILABLE`。
