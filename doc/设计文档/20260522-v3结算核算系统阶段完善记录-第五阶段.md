## 5. 风险与说明

1. 本阶段没有改变 REST 路径、响应 DTO 类型、领域服务调用顺序或持久化逻辑。
2. 批量收付款批次号仍由 Controller 生成，本阶段只抽取单笔/批量明细请求到领域模型的转换；批次聚合模型留待后续阶段。
3. Assembler 当前位于 app 模块，承担接口 DTO 与领域模型边界转换职责，符合 DTO 不下沉到 Domain 的约束。
4. `YwglPaymentController` 仍负责批量循环编排；后续可在应用服务或批次聚合阶段继续瘦身。
