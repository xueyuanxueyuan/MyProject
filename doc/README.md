## 维护约定

1. 不再把命令流水、逐次操作截图/日志、临时对比文件长期散落在 `doc/操作记录/`。
2. 阶段性记录应在阶段结束后提炼为设计、评审、需求分析或数据库脚本说明；原流水外置到 `.doc-archive/`。
3. Agent 优先读取 `doc/README.md`、`doc/项目规范/`、当前任务相关的需求/设计/评审文档，不应全量遍历历史流水。
4. 若需要找回历史流水，先查 `doc/归档索引/` 中的清单，再到 `.doc-archive/` 定位原文。
