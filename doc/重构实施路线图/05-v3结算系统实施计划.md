# v3 结算系统实施计划

> 项目：capinfo-gjj-busi-jshs-v3（结算系统 3.0）
> 目标：在保留原项目不变的前提下，新建一套架构优化后的结算系统
> 核心原则：接口兼容（Feign 路径不变）、领域驱动、策略化、消除冗余

---

## 一、项目结构

```
capinfo-gjj-busi-jshs-v3/
├── pom.xml (parent)
├── capinfo-gjj-busi-jshs-v3-common/           # 公共模块：枚举、工具、统一DTO
│   └── pom.xml
├── capinfo-gjj-busi-jshs-v3-api/               # API层：FeignClient接口 + DTO
│   └── pom.xml
├── capinfo-gjj-busi-jshs-v3-domain/            # 领域层：领域服务 + 策略接口 + 模型
│   └── pom.xml
│       ├── payment/       # 付款领域
│       ├── collection/    # 收款领域
│       ├── transfer/      # 转账领域
│       ├── account/       # 账户领域
│       ├── recon/         # 对账领域
│       ├── voucher/       # 凭证领域
│       └── shared/        # 共享内核
├── capinfo-gjj-busi-jshs-v3-infrastructure/   # 基础设施层：DAO、外部Feign适配、消息
│   └── pom.xml
├── capinfo-gjj-busi-jshs-v3-app/               # 应用层：Controller、配置、启动类
│   └── pom.xml
└── capinfo-gjj-busi-jshs-v3-gateway/           # 网关层：统一路由（替代gm-agg代理）
    └── pom.xml
```

## 二、阶段划分

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| **Stage 1** | 父POM、公共模块、骨架搭建 | 基础 |
| **Stage 2** | API层：FeignClient接口 + DTO（兼容V1路径） | DTO+接口 |
| **Stage 3** | 领域层：收款/付款/账户领域 + 地区策略 + 渠道策略 | 核心业务 |
| **Stage 4** | 基础设施层：DAO + MyBatis + 外部Feign适配 + 统一降级 | 持久化 |
| **Stage 5** | 应用层：Controller（统一路由）+ 配置 + 启动类 | 入口 |
| **Stage 6** | 网关层：统一路由（替代原gm-agg） | 路由 |
| **Stage 7** | 编译验证 | 验证 |
