# 技能入口统一模板

## 1. 目标
- 统一不同 AI 工具中“技能入口文件”的最小骨架。
- 让入口文件只负责触发发现、最小要求、主源指向和本地补充。
- 详细方法、完整流程和长案例统一保留在技能主源，而不是重复写进各工具入口。

## 2. 适用范围
- 适用于需要为某个工具生成技能入口、副本技能说明或桥接技能文档的场景。
- 当前工作区中的 `.trae/skills/*/SKILL.md` 可以使用本模板。
- 其他工具若存在等价的技能入口机制，也可以复用本模板。

## 3. 标准骨架
```md
---
name: skill-name
description: 用一句话说明何时调用该技能。
---

# 技能标题

一句话说明本技能在当前工具链中的定位。

## 适用场景
- 什么时候应优先调用该技能
- 用户常见表达、触发词或典型任务

## 核心要求
- 3-6 条最小必须遵守的要求
- 只保留入口级规则，不复制主源长正文

## 主源位置
- `doc/技能库/<skill-name>/SKILL.md`
- 如有辅助资料，再补 1-3 条必要路径

## 使用提示
- 说明与本地规则、其他技能、工具链或入口文件的衔接方式
```

## 4. 可选附加段
- `## 中文口令`：仅在技能高度依赖中文触发语时保留
- `## 标准流程`：仅在存在固定步骤且入口必须提示时保留
- `## 专项细则`：仅在存在高风险约束、稳定成功路径或平台限制时保留
- `## 平台差异`：仅在不同工具下存在明显入口字段差异时保留

## 5. 不应保留的内容
- 重复统一主规则全文
- 重复技能主源中的长篇案例、长原理、完整背景叙事
- 与当前工具链无关的上游说明
- 只为凑长度而保留的背景介绍

## 6. 通用要求
- 优先使用简体中文书写标题、段落名和正文说明
- 入口正文优先控制在 20-60 行；复杂技能可更长，但长案例应下沉到主源
- 若工具支持 frontmatter，则使用标准 `---` 包裹；若不支持，可省略 frontmatter，但保留等价字段
- 本地桥接技能需明确写清：谁是主源、谁是本地补充、何时仍显式调用
- 同一技能若存在多个工具入口副本，内容应以技能主源为准，入口文件之间尽量保持结构一致
