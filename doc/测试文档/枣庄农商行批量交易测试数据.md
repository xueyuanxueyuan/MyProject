## 五、数据说明

### 5.1 账号编码规则

| 账号前缀 | 用途 | 示例 |
|---------|------|------|
| 622320454000001 | 代收账户（公积金缴存） | 6223204540000010001 |
| 622320454000002 | 代扣账户（费用代扣） | 6223204540000020001 |
| 622320454000003 | 代付账户（提取收款） | 6223204540000030001 |

### 5.2 协议号规则

格式：`ZZRC-PROT-XXX`
- ZZRC：枣庄农商行缩写
- PROT：协议标识
- XXX：序号（001-999）

### 5.3 枣庄农商行行号

| 名称 | 行号 |
|------|------|
| 枣庄农村商业银行股份有限公司 | 402454000013 |

## 六、验证命令

```bash
# 提交批量收款
curl -s -X POST http://localhost:8082/api/v1/ywgl/yht/yht/batch/submit \
  -H "Content-Type: application/json" \
  -d @collect_data.json | python3 -m json.tool

# 提交批量扣款
curl -s -X POST http://localhost:8082/api/v1/ywgl/yht/yht/batch/submit \
  -H "Content-Type: application/json" \
  -d @deduct_data.json | python3 -m json.tool

# 提交批量付款
curl -s -X POST http://localhost:8082/api/v1/ywgl/yht/yht/batch/submit \
  -H "Content-Type: application/json" \
  -d @pay_data.json | python3 -m json.tool

# 查询批次状态
curl -s -X POST http://localhost:8082/api/v1/ywgl/yht/yht/batch/status \
  -H "Content-Type: application/json" \
  -d '{"batchNo": "MOCK-BATCH-XXX", "tranCode": "40502", "queryType": "BBNO"}' | python3 -m json.tool

# 查看挡板统计
curl -s http://localhost:9999/yht-mock/api/stats | python3 -m json.tool
```
