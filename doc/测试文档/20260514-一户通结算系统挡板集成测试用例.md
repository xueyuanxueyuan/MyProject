### 1.1.1 合成测试数据约定（无真实档案时的最小合规集）

下列取值用于满足当前结算一户通链路校验与挡板行为，**不代表真实生产档案**；具备档案后应替换为库表中的权威编码。

| 符号 | 示例取值 | 长度 | 依据 |
|------|-----------|------|------|
| **JBGH18**（业务经办机构 / 批量接口经办机构） | `370400000000000001` | 18 | `YhtProtocolRequestValidator` 等要求机构编号长度为 18；前缀 `370400` 为枣庄市行政区划代码，末位 `…001` 为合成序号 |
| **DSJGBM**（代收机构编码，`DbqyReqDTO` / 批量里的 `dsjgbm`） | `0001` | 4 | `YhtFeeMappingServiceImpl` 静态费项映射键：`0001`→`FEE001,FEE002`；`0002`→`FEE003–005`；`0003`→`FEE006`。联调默认取 `0001` |
| **CORP**（企业客户号 / `CorpNo`） | `1111` | - | 与配置项 `yht.caps.corp-no`、挡板示例一致 |

**注意**：`JBGH18` 与 `DSJGBM` 语义不同——前者走机构编号校验，后者仅用于解析费项列表；**勿把行政区划 6 位码当作 `dsjgbm` 填入**。

### 1.2.1 复测结论快照（2026-05-15）

以下为与本文档口径（合成机构码、`dsjgbm=0001`、`ywqd=0103`）一致的自动化复测摘要；**完整请求/响应原文**见同目录 HTML：**`doc/测试文档/20260515-一户通结算挡板接口测试报告.html`**。

| 现象 | 说明 |
|------|------|
| 挡板 `GET …/stats`、`DELETE …/logs` | ✅ 服务可达 |
| 挡板 `POST …/gateway`（`caps.999`） | ✅ `ProcMsg=探测成功`，网关 dispatch 正常 |
| `getQyztcxMessage` | 签名开启时：测试证书为 **RSA** 需 `SmCryptoUtil` 走 `SHA256withRSA`；配置项为 `yht.caps.switch-config.enable-sign`（对应 Java 字段 `switchConfig`）；证书路径建议 `classpath:cert/yht-test.p12` |

### 1.4 挡板异步应答自动推送（CAPS 主动下行）

规范中 **同步应答**（如 102/202/304/602）仍由 `POST /yht-mock/api/gateway` 的 **HTTP 响应体** 返回；**异步应答/回执**（如 107/205/306/308）由 CAPS 平台在受理后 **主动 POST** 至机构 `receive` 地址。

挡板 `yht-mock-server` 已支持 **自动生成并推送** 下列异步报文（默认开启，可在 `application.yml` 或运行时接口调整）：

| 机构发起（请求） | 挡板同步返回 | 挡板自动推送（默认延迟后） |
|-----------------|-------------|---------------------------|
| caps.101 | caps.102 | caps.107 批量结果回执 |
| caps.201 | caps.202 | caps.205 实时交易回执 |
| caps.305 | caps.900 受理确认 | caps.306 协议签约管理应答 |
| caps.307 | caps.900 受理确认 | caps.308 撤销结果通知 |

**配置项**（`yht-mock-server/src/main/resources/application.yml`）：

```yaml
yht.mock.callback:
  auto-push-enabled: true
  default-target-url: http://localhost:8082/api/v1/ywgl/yht/yht/receive
  delay-ms: 800
  push-caps-107: true
  push-caps-205: true
  push-caps-306: true
  push-caps-308: true
```

**运行时查看/修改**：

```bash
curl -s http://localhost:9999/yht-mock/api/callback-config | python3 -m json.tool
# 仍支持手动补发：POST http://localhost:9999/yht-mock/api/trigger-callback
```

网关日志字段 `callbackTriggered=true` 表示已调度自动推送（推送结果以结算 `receive` 日志为准）。

### 1.5 架构说明

```
前端 → YwglController (/api/v1/ywgl)
         |
         |--[ywqd=0103]--> YhtYwService → YhtService → CapsHttpClient → 挡板(/yht-mock/api/gateway)
         |
         |--[ywqd=0101]--> WbjkService (银企直联)
         |
         |--[ywqd=0102]--> WbjkService (住建部结算平台)

挡板 → trigger-callback → 结算系统回调接口 (/api/v1/ywgl/yht/yht/receive)
```

**关键路由逻辑**：YwglController 通过 `Jsqd.YHT.code`（`"0103"`）判断是否路由到一户通通道。

| 枚举值 | code | 含义 |
|--------|------|------|
| Jsqd.YQZL | 0101 | 银企直联 |
| Jsqd.ZJBJSPT | 0102 | 住建部结算平台 |
| **Jsqd.YHT** | **0103** | **一户通** |
