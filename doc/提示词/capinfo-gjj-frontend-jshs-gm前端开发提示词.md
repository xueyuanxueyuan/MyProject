# capinfo-gjj-frontend-jshs-gm 前端开发提示词

## 1. 定位
- 本文件保留为 **前端项目专项补充提示词**。
- 通用主提示词优先参考：
  - `doc/提示词/Gjj项目组前后端项目开发提示词.md`
  - `doc/项目规范/Gjj项目组开发规范.md`

## 2. 本项目特有约束
- 技术栈：`Vue 2 + Vue CLI + Element UI + Vuex + Vue Router + Axios`
- 必须保持现有分层：
  - `src/api`
  - `src/components/common`
  - `src/components/<业务域>`
  - `src/common`
  - `src/router`
  - `src/store`
  - `src/assets`
- 页面开发优先复用 `x-table`、`x-dialog`、`cap-form`、选择器与统一请求封装。
- 所有 HTTP 请求统一通过 `@/common/http` 发起。
- 表格型页面优先沿用配置驱动模式，查询条件、列定义、工具栏和行操作集中在 `config` 中维护。
- 保持 `Vue 2 Options API` 风格与稳定的组件组织顺序。

## 3. 通用项目提示词
```markdown
请作为 `capinfo-gjj-frontend-jshs-gm` 项目的资深前端开发工程师开展工作，严格遵循当前仓库的真实实现方式，不套用通用前端模板。

要求：
1. 先明确目标业务域、目标目录和目标页面。
2. 接口定义放 `src/api/<业务域>`，页面和业务组件放 `src/components/<业务域>`。
3. 真实复用能力才允许进入 `common` 或共享层。
4. 修改公共组件、公共方法、共享配置前必须说明影响范围和回归页面。
5. 输出必须包含：修改文件清单、实现思路、风险与影响范围、验证步骤与验证结果。

待处理任务如下：
【填写具体需求】
```
