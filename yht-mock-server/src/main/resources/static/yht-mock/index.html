随机模拟交易失败

            
开启后，对任意判定为成功的交易按设定概率随机返回失败（用于压测与异常模拟）。与下方账号校验规则叠加生效：账号规则判定失败时优先返回规则失败，规则判定成功后再按本开关随机失败。

            

                
                

                    
                    
                

            

            

                

                    
                    
                

            

            

                
                
            

            
交易成功自动动账通知

            
默认关闭。启用后调用结算系统模拟动账接口并触发后续处理。与 CAPS 回调开关独立，保存配置后生效。对手账户兜底开启时，所有动账通知统一使用下方默认兜底账户，不再按中心账户所属银行判断是否配置了对手账户。

            

                

                

                

                

                

                

                

            

            
收款为正金额、付款为负金额。结果在接口记录中查看 MOVEMENT / saveZhbdzt；结果不明不自动重试，避免重复动账。清除历史数据保留动账去重记录。

            

            

            
银行对手账户配置

            
按中心账户所属银行标识精确匹配（不是个人账户银行）。单笔付款取 DbtrBankId，单笔收款取 CdtrBankId，批量取请求文件汇总行第六列。未配置或停用时仅记录失败，不发送动账通知。

            

                

                

                

                

                

                

            

            

                
                
                
            

            
每个中心银行配置一组对手账户，保存立即生效；请将同一组对手账号、户名、行号配置到结算系统。清除历史数据不删除本配置。
