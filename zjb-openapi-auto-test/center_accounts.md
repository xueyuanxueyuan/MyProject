## 使用说明

- 调用示例（工行→农行，5 元）：
  ```bash
  python zjdb_runner.py --mode run --city jiaxing --from-bank 工行 --to-bank 农行 --amount 5
  ```
- `--from-bank` / `--to-bank` 支持银行简称（如 `工行`）或银行代码（如 `102000`）。
- `zhxxId` 自动取转出银行的专户 id（工行=52）；`skyhlhh` 自动取转入银行联行号。
- 可用 `--zjdblx`（默认 `dbzz`）、`--from-account-name`/`--to-account-name`、`--from-lhh`/`--to-lhh` 覆盖。
- 户名列中的乱码为后端数据库实际存储内容（系统按账号查库回写），非录入错误。
